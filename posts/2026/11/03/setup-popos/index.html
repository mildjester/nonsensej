Pop!_OSの初期設定

投稿日: 2026年11月03日

PopOS

環境

  • Pop!_OS 24.04 LTS

概要

UbuntuベースのLinuxデスクトップとして「Pop!_OS」というものが最近流行り始めているようなので使ってみました。

初期設定手順

OSインストール

公式ページからインストーラーをダウンロードして、USBにブートメディアとして書き込む。
ダウンロードページ

PC起動時に作成したUSBから起動してインストールする。

日本語入力設定

  • 参考： Pop!_OSで日本語入力を快適に行うための環境設定 - Qiita

以下のコマンドでmozcを使えるようにする。

sudo apt update
sudo apt install fcitx5 fcitx5-mozc fcitx5-config-qt
  • fcitxの設定画面では日本語で絞り込まず、mozcで検索したほうが良い。
  • Fcitxの設定画面でmozcの設定ができる。変換/無変換キーへのIMEオン/オフ割当もそこでできる。
  • PC起動時はなぜか日本語入力できない。タスクバーの入力アイコンから再起動をすると日本語が入力できるようになる。

デュアルブート時の時刻ずれ解消

以下コマンドで解消される。

sudo timedatectl set-local-rtc 1

なぜか、たまに再度狂ってしまう時がある。再度上記を実行すれば治る。恒久対処法は探し中。

タッチパッド無効化

Pop!_OSの設定からはタッチパッドが無効化できないようだったのでコマンドから実施。

echo 'SUBSYSTEM=="input", KERNEL=="event[0-9]*", ENV{ID_INPUT_TOUCHPAD}=="1", ENV{LIBINPUT_IGNORE_DEVICE}="1"' | sudo tee /etc/udev/rules.d/99-disable-touchpad.rules
sudo udevadm control --reload-rules
sudo udevadm trigger

戻したい場合は上記コマンドで生成したファイルを削除する。

sudo rm /etc/udev/rules.d/99-disable-touchpad.rules

Claude Desktopインストール

  • 参考： Claude Desktop が Linux に対応：Ubuntu と Debian 向け公式アプリ（ベータ版）

署名キーをダウンロードする。

sudo curl -fsSLo /usr/share/keyrings/claude-desktop-archive-keyring.asc https://downloads.claude.ai/claude-desktop/key.asc

aptリポジトリを登録

echo "deb [arch=amd64,arm64 signed-by=/usr/share/keyrings/claude-desktop-archive-keyring.asc] https://downloads.claude.ai/claude-desktop/apt/stable stable main"  | sudo tee /etc/apt/sources.list.d/claude-desktop.list

パッケージをインストール

sudo apt update && sudo apt install claude-desktop

asdfインストール

リリースページより圧縮ファイルをダウンロードする。
https://github.com/asdf-vm/asdf/releases

ダウンロードしたファイルを解凍してPATHが通っている場所へ配置する。

tar xf asdf-v0.20.2-linux-amd64.tar.gz
sudo mv asdf /usr/local/bin/.

asdfでgolangインストール

プラグイン追加

asdf plugin add golang

インストールできるバージョンを確認

asdf list all golang

確認したバージョンから欲しいバージョンをインストール

asdf install golang 1.27.1
asdf set golang 1.27.1

ターミナル環境の整備

ほぼ以下記事通りでTilix & fish & fisherman環境を構築。
terminator + fish + fishermanの導入

シェルをfishに切り替えたタイミングで~/.config/fish/config.fishにasdfやgolangの設定を追記する。

if test -z "$ASDF_DATA_DIR"
  set -gx ASDF_DATA_DIR $HOME/.asdf
end
if test -e $ASDF_DATA_DIR/shims
  fish_add_path --global --move $ASDF_DATA_DIR/shims
end

### asdf golang (GOROOT/GOPATH/GOBIN をプロンプト表示ごとに現在のバージョンへ追従)
if test -e $ASDF_DATA_DIR/plugins/golang/set-env.fish
  source $ASDF_DATA_DIR/plugins/golang/set-env.fish
  asdf_update_golang_env
  if set -q GOBIN
    fish_add_path --global $GOBIN
  end
end

使ってみた感想

  • 動作はキビキビしていて使いやすい。
  • マルチディスプレイできる。type-c 1本で2画面映すタイプのモバイルディスプレイも対応。
  • 起動時に日本語入力ができないのでMozcを再起動しないといけないのが面倒。
  • デュアルブートだからか、時刻もたまに狂うのが不便。Windows起動後に狂ってるかもしれない。
