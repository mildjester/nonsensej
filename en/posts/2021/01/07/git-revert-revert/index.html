Accessing Child Component Properties with TypeScript + Vue.js

posted: 2021-01-07

Vue.js
Typescript

With TypeScript + Vue.js, when accessing a child component’s properties from a parent component,
implementing it the same way as in plain JavaScript may cause an error.

For example, suppose you write the following.

# template
<HogeChild ref="hogeChildRef" />

# script
import HogeChild from "〜対象ファイルパス〜";

@Component({
  components: {
    HogeChild
  }
})

export default class HogeParent extends Vue {
  changeChildFlg(): void {
    this.$refs.hogeChildRef.someFlg = true;
  }
}

Then the following error may occur.

Property 'someFlg' does not exist on type 'Vue | Element | Vue[] | Element[]'.
  Property 'someFlg' does not exist on type 'Vue'.Vetur(2339)

In this case, when using TypeScript, you also need to specify the type when referencing the child component.
Changing the part that references the child component as follows makes it work.

  changeChildFlg(): void {
    const hogeChildRef = <HogeChild>this.$refs.hogeChildRef;
    hogeChildRef.someFlg = true;
  }

I don’t know exactly under what conditions this occurs,
but my impression is that writing Vue.js inside TypeScript is fine, while writing TypeScript inside Vue.js causes the error.
