Initial Setup of Pop!_OS

posted: 2026-11-03

PopOS

Environment

  • Pop!_OS 24.04 LTS

Overview

Pop!_OS, an Ubuntu-based Linux desktop, seems to be getting popular lately, so I gave it a try.

Initial Setup Steps

Installing the OS

Download the installer from the official page and write it to a USB drive as boot media.
Download page

Boot the PC from the USB drive you created and install the OS.

Setting Up Japanese Input

  • Reference: Pop!_OSで日本語入力を快適に行うための環境設定 - Qiita (Japanese)

Enable Mozc with the following commands.

sudo apt update
sudo apt install fcitx5 fcitx5-mozc fcitx5-config-qt
  • In the Fcitx configuration screen, search for “mozc” rather than filtering by “Japanese”.
  • Mozc can be configured from the Fcitx configuration screen. You can also assign IME on/off to the Henkan/Muhenkan keys there.
  • For some reason, Japanese input does not work right after the PC boots. Restarting it from the input icon in the taskbar makes Japanese input available.

Fixing Clock Drift When Dual Booting

The following command fixes it.

sudo timedatectl set-local-rtc 1

For some reason, the clock occasionally goes off again. Running the command above again fixes it. I’m still looking for a permanent solution.

Disabling the Touchpad

There didn’t seem to be a way to disable the touchpad from the Pop!_OS settings, so I did it from the command line.

echo 'SUBSYSTEM=="input", KERNEL=="event[0-9]*", ENV{ID_INPUT_TOUCHPAD}=="1", ENV{LIBINPUT_IGNORE_DEVICE}="1"' | sudo tee /etc/udev/rules.d/99-disable-touchpad.rules
sudo udevadm control --reload-rules
sudo udevadm trigger

To revert, delete the file created by the command above.

sudo rm /etc/udev/rules.d/99-disable-touchpad.rules

Installing Claude Desktop

  • Reference: Claude Desktop が Linux に対応：Ubuntu と Debian 向け公式アプリ（ベータ版） (Japanese)

Download the signing key.

sudo curl -fsSLo /usr/share/keyrings/claude-desktop-archive-keyring.asc https://downloads.claude.ai/claude-desktop/key.asc

Register the apt repository.

echo "deb [arch=amd64,arm64 signed-by=/usr/share/keyrings/claude-desktop-archive-keyring.asc] https://downloads.claude.ai/claude-desktop/apt/stable stable main"  | sudo tee /etc/apt/sources.list.d/claude-desktop.list

Install the package.

sudo apt update && sudo apt install claude-desktop

Installing asdf

Download the archive from the releases page.
https://github.com/asdf-vm/asdf/releases

Extract the downloaded file and place it in a directory on your PATH.

tar xf asdf-v0.20.2-linux-amd64.tar.gz
sudo mv asdf /usr/local/bin/.

Installing Go with asdf

Add the plugin.

asdf plugin add golang

Check the available versions.

asdf list all golang

Install the version you want from the list.

asdf install golang 1.27.1
asdf set golang 1.27.1

Setting Up the Terminal Environment

I set up a Tilix + fish + fisherman environment, mostly following the article below.
Installing terminator + fish + fisherman (Japanese)

After switching the shell to fish, add the asdf and Go settings to ~/.config/fish/config.fish.

if test -z "$ASDF_DATA_DIR"
  set -gx ASDF_DATA_DIR $HOME/.asdf
end
if test -e $ASDF_DATA_DIR/shims
  fish_add_path --global --move $ASDF_DATA_DIR/shims
end

### asdf golang (update GOROOT/GOPATH/GOBIN to the current version on every prompt)
if test -e $ASDF_DATA_DIR/plugins/golang/set-env.fish
  source $ASDF_DATA_DIR/plugins/golang/set-env.fish
  asdf_update_golang_env
  if set -q GOBIN
    fish_add_path --global $GOBIN
  end
end

Installing AWS CLI

  • Reference: Installing or updating to the latest version of the AWS CLI
curl -fsSL https://awscli.amazonaws.com/v2/install.sh | bash

Installing VSCode

It can also be installed from the store, but that version isn’t great. Downloading and installing it from the official page is more stable.
https://code.visualstudio.com/

Impressions

  • It runs snappily and is easy to use.
  • Multi-display works. It even supports mobile displays that show two screens over a single USB Type-C cable.
  • Japanese input doesn’t work at boot, so having to restart Mozc every time is a hassle.
  • The clock occasionally goes off, perhaps because of dual booting, which is inconvenient. It might be getting messed up after booting into Windows.
