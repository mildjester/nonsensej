Preventing gulp-uglify from Mangling Variable/Function Names

posted: 2020-04-15

javascript
node

References

  • github mishoo/UglifyJS2

I couldn’t find much information on this, so here’s a note.

When you minify JS files with gulp-uglify, the variable and function names you define are also mangled into single letters and so on.
That’s fine for variables and functions only called within the minified file, but sometimes you want to call them from outside as well, especially functions.

To keep variable and function names, just pass options like the following when running gulp-uglify.

(gulpfile.js example)

var gulp = require('gulp');
var uglify = require('gulp-uglify');

var uglify_option = {
    keep_fnames: true,  // Specify to keep function names
    mangle: false       // Specify to keep variable names
}
gulp.task("default", function() {
    return gulp.src('src/*.js')
      .pipe(uglify(uglify_option))
      .pipe(gulp.dest('dest'));
});
