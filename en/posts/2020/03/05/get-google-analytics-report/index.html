Getting Recent Page View Counts from Google Analytics

posted: 2020-03-05

PHP
GoogleService

Environment

  • PHP 7.3
  • google/apiclient 2.4

Reference

https://developers.google.com/analytics/devguides/reporting/core/v3/quickstart/service-php?hl=ja (Japanese)

When showing a promotional message like “XX people viewed this in the last 24 hours” on a product page, some services apparently just use random numbers, but I didn’t like that idea, so I tried fetching actual view data from Google Analytics and displaying it.
Note that Google Analytics only lets you specify dates, such as “from yesterday to today,” so you can’t show viewer counts for an exact time window like “within the last 10 minutes.”

Creating a GCP Service Account

First, create a service account on the following page.
*If you haven’t created a Google Cloud Platform (GCP) project yet, click “Create Project” to create one first.
https://console.developers.google.com/iam-admin/serviceaccounts?hl=ja

Select the project in which to create the service account from “Select a project,”
then click “+ Create Service Account.”

The service account creation screen opens. Fill it in as follows and click “Create.”

Field Value
Service account name Any name you can recognize
Service account ID A unique ID (filled in automatically when you enter the service account name)
Service account description A description that makes sense to you

Next, the service account permissions screen opens; just click “Continue.”

On the following screen, leave “Grant users access to this service account” as is.
Under “Create key,” click “Create Key,” select JSON as the key type, and click “Create.”
A JSON file will be downloaded; keep it somewhere safe.

Click “Done” on the service account creation screen to finish.
Back on the service account list, the email address of the service account you created is shown; make a note of it.

Enabling the Google Analytics API

Go to the following page and enable the Google Analytics API.
https://console.developers.google.com/apis/api/analytics.googleapis.com/overview

Configuring Google Analytics

Add the service account you just created to Google Analytics.
Add the service account’s email address as an account user or property user.
The “Read & Analyze” permission alone (the default) is fine.

Creating the Script

This assumes PHP and Composer are already set up.

First, install the Google Analytics API package.

composer require google/apiclient

Next, create the following PHP script.

<?php
require_once __DIR__ . '/vendor/autoload.php';

$analytics = initializeAnalytics();
$profile = getFirstProfileId($analytics);
$results = getResults($analytics, $profile);
printResults($results);

/**
 * Initialize the Google Client
 */
function initializeAnalytics()
{
  $KEY_FILE_LOCATION = {{Path to the JSON file obtained when creating the GCP service account}};
  // e.g. $KEY_FILE_LOCATION = __DIR__ . '/config/hogehoge.json';

  $client = new Google_Client();
  $client->setApplicationName("Hello Analytics Reporting");    // Feel free to change this to any name
  $client->setAuthConfig($KEY_FILE_LOCATION);
  $client->setScopes(['https://www.googleapis.com/auth/analytics.readonly']);
  $analytics = new Google_Service_Analytics($client);

  return $analytics;
}

/**
 * Get the profile
 */
function getFirstProfileId($analytics) {
  $accounts = $analytics->management_accounts->listManagementAccounts();

  if (count($accounts->getItems()) > 0) {
    $items = $accounts->getItems();
    $firstAccountId = $items[0]->getId();

    $properties = $analytics->management_webproperties
        ->listManagementWebproperties($firstAccountId);

    if (count($properties->getItems()) > 0) {
      $items = $properties->getItems();
      $firstPropertyId = $items[0]->getId();

      $profiles = $analytics->management_profiles
          ->listManagementProfiles($firstAccountId, $firstPropertyId);

      if (count($profiles->getItems()) > 0) {
        $items = $profiles->getItems();

        return $items[0]->getId();

      } else {
        throw new Exception('No views (profiles) found for this user.');
      }
    } else {
      throw new Exception('No properties found for this user.');
    }
  } else {
    throw new Exception('No accounts found for this user.');
  }
}

/**
 *  Set query conditions and fetch the data
 */
function getResults($analytics, $profileId) {
  $from = '1daysAgo';                          // Fetch data from yesterday
  $to    = 'today';                            // through today
  $metrics = "ga:pageviews";                   // Fetch page view counts
  $option = [
    "dimensions" => 'ga:pagepath',             // Fetch view counts per page path
    "sort" => "-ga:pageviews",                 // Sort by view count. The minus sign makes it descending
    // "filters" => "ga:pagepath%3D@/article",    // Uncomment to narrow down to page paths containing "/article"
  ];

  return $analytics->data_ga->get(
        'ga:' . $profileId,
        $from,
        $to,
        $metrics,
        $option
  );
 }

/**
 * Output the results
 */
function printResults($results) {
  echo 'page url,previews' . PHP_EOL;
  foreach ($results as $result){
    echo $result[0] . ',' . $result[1] . PHP_EOL;
  }
}

Running this PHP script gives you view counts per page.
Then just extract the view count for the relevant page from the results and display it on the page.

If you narrow down the page URL with filters in the source above, you can get the view count for just the page you want,
but the Google Analytics API takes a few seconds to respond, so fetching view counts for each page individually isn’t practical.
It’s better to fetch the pages in order of most views as above, store them in a cache, and basically read from the cache.
(e.g. update the cache once a minute)

About the Values to Set

This page lists the values you can set for metrics and dimensions.
Use it as a reference if you want to fetch something other than page views.
https://ga-dev-tools.appspot.com/dimensions-metrics-explorer/

For other details, see the official page here.
https://developers.google.com/analytics/devguides/reporting/core/v3/reference
