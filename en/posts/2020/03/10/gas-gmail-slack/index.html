I used to connect Gmail to Slack with IFTTT and Zapier,
but recent security changes on the Gmail side broke the integration,
so I decided to use Google Apps Script (GAS) instead.

What the GAS script does is:
“Check mail every 5 minutes, and if there are unread messages, forward them to Slack and mark them as read.”

Getting a Slack Webhook URL

Get the URL used to post notifications to Slack via the API (not limited to GAS).
With this, you can also build your own bots.

You can add Incoming WebHooks to your Slack team from this page.
(Slack login required)
https://slack.com/apps/A0F7XDUAZ-incoming-webhooks

You’re done once you have a URL in the form https://hooks.slack.com/services/AAAAAAA/BBBBBBB/CCCCCCC.

By the way, unrelated to GAS,
I’ve written a library for sending messages from PHP via webhooks.

Creating the Google Apps Script

First, open your GAS page.
https://script.google.com/u/0/home?hl=ja

Click “New project”.

The code editor opens; write the following in “Code.gs”.
Adjust the “initial settings” section at the top to match your environment.

// Initial settings
const HOOK_URL = 'https://hooks.slack.com/services/AAAAAAA/BBBBBBB/CCCCCCC'; // The Webhook URL you obtained
const SEND_CHANNEL = 'general'; // Slack channel to send Gmail contents to

function main() {
  // Search condition: unread mail in the inbox received within the last 10 minutes
  var after = parseInt(((new Date()).getTime() - 10 * 60 * 1000) / 1000);  // Get the time 10 minutes ago as UNIX time
  var searchTarget = 'in:inbox is:unread after:' + after;

  GmailApp
  .search(searchTarget)
  .forEach(function (thread) {
    thread.getMessages().forEach(function (message) {
      send(message);
    });
    thread.markRead();
  });  
}

function send(message) {
  var sendText = '【件名】\n' + message.getSubject()
               + '\n【本文】\n' + message.getPlainBody();
  
  var jsonData = {
    "icon_emoji": ':mailbox:',
    "channel" : SEND_CHANNEL,
    "username" : message.getFrom(),
    "text" : sendText
  };

  var options = {
    "method" : "post",
    "contentType" : "application/json",
    "payload" : JSON.stringify(jsonData)
  };

  UrlFetchApp.fetch(HOOK_URL, options);
}

After writing the above, save it with “Ctrl + s” or by clicking the floppy disk icon in the top menu.
You’ll be asked for a project name when saving; give it any name you like.
(e.g. Gmail2Slack)

Setting Up Automatic Execution

Configure the script you created to run automatically.
Click the clock icon in the top menu.

The triggers page for the script opens; click “Add Trigger”.

The add trigger dialog opens; enter the following and click “Save”.

Item Value
Choose which function to run main
Choose which deployment should run Head
Select event source Time-driven
Select type of time based trigger Minutes timer
Select minute interval Every 5 minutes

A screen to choose the Google account to link opens; select the account whose Gmail should be read.
An alert saying “This app isn’t verified” appears; click “Advanced > Go to {your app name}” at the bottom.
Then the permission screen opens; click “Allow”.

Gmail is now checked every 5 minutes and forwarded to Slack.

Additional Notes

About the Content Sent to Slack

Only the subject and body are sent to Slack.
If you want other information as well, change the contents of “sendText” in the script.
See here for the values you can get:
Class GmailApp (official documentation)

Note that posting the entire email body to Slack can get quite long.
If you only want Slack to give a “you’ve got this kind of mail” notification,
it’s better to truncate the body to a reasonable number of characters.

For example, to truncate at 150 characters:

var sendText = '【件名】\n' + message.getSubject()
             + '\n【本文】\n' + message.getPlainBody().substr(0, 150); // Truncate at 150 characters

About the Name and Icon Shown in Slack

By changing “username” and “icon_emoji” in “jsonData”,
you can change the name and icon of the Slack notification.

About the Timer Interval

The script checks “unread mail received within the last 10 minutes, every 5 minutes”.
Since it runs every 5 minutes, something like 6 minutes would also work, but I’ve left a generous margin.
If you receive a large amount of mail, processing may get heavy, so adjust the timing as appropriate.
