Running AWS CodeDeploy from GitHub Actions

posted: 2020-03-15

AWS
git

It looked like AWS commands could easily be run from GitHub Actions, so I tried it out.
The only thing this CI does is “run CodeDeploy when master is pushed.”

AWS CodeDeploy Configuration

The steps are covered in this article.
Deploying to EC2 with AWS CodeDeploy

AWS IAM Configuration

The steps are covered in this article.
CircleCI isn’t used here, so refer only to the “IAM preparation” steps.
Running AWS CodeDeploy from CircleCI

Registering Keys in GitHub Secrets

Register the IAM user’s “Access key ID” and “Secret access key” obtained in the previous step in GitHub Secrets.

First, open “Settings > Secrets” of the target GitHub repository and click “Add a new secret”.

On the Secrets screen, set the following two.

Name Value
AWS_ACCESS_KEY_ID IAM access key ID
AWS_SECRET_ACCESS_KEY IAM secret access key

GitHub Actions Configuration

Open the “Actions” tab on the GitHub page of the repository you want to deploy,
and click “Set up a workflow yourself”.

The editor for .github/workflows/main.yml opens, so write the following.

name: AWS Code Deploy

on:
  push:
    branches: [ master ]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Run AWS CodeDeploy
      with:
        args: deploy create-deployment --application-name "※APP_NAME※" --deployment-group-name "※GROUP_NAME※" --github-location repository="※REPO※",commitId="${{ github.sha }}"
      env:
        AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
        AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
        AWS_DEFAULT_REGION: ※REGION※

*Updated 2020/11/20
I previously wrote main.yml based on the following, but as of November 2020 it no longer worked, so I switched to the above.
AWS Cli install action

Replace the following parts to match your own environment.

String to replace Value to set
※APP_NAME※ Application name configured in CodeDeploy
※GROUP_NAME※ Deployment group name configured in CodeDeploy
※REPO※ GitHub repository to deploy (“username/repository” format)
※REGION※ AWS region to run CodeDeploy in (e.g. ap-northeast-1)

Once written, commit it.
After committing, the GitHub Action runs for that commit, so check that it completes successfully.

The setup is now complete.
AWS CodeDeploy now runs and deploys every time the master branch is updated.

Perhaps because this CI only deploys, each run finished in under a minute.
Actions is free for up to 2,000 minutes per month for private repositories (as of March 2020), so that should allow about 2,000 releases.
