How to Prevent JavaScript Input Events from Firing During IME Composition

posted: 2020-03-20

javascript

When checking the contents of a text box with JavaScript as the user types,
the keydown event also fires during uncommitted IME input, causing lots of unnecessary processing,
and the textInput event isn’t supported by some browsers.
Here is how to handle that situation.

JavaScript has a “compositionstart” event fired when IME input starts and a “compositionend” event fired when IME input is committed.
Using these, we create a flag that indicates whether IME input is in progress.

Specifically, do the following.

<input type="text" id="hoge" />

<script>
// Wrapped in an object for now, but writing it inline is fine too
var inputEventHandler = {
  compFlg : false, // IME composition in progress flag

  initialize : function(){
    let targetElm = document.getElementById('hoge');

    targetElm.addEventListener('keydown', function() {
      // Depending on the browser, this may fire before or after compositionend, so delay slightly with setTimeout
      setTimeout(function(){
        if (self.compFlg) {
          return;
        }
        console.log('ここで何か処理を実行する');
      }, 10)
    });

    targetElm.addEventListener('compositionstart', function() {
      self.compFlg = true;
    });

    targetElm.addEventListener('compositionend', function() {
      self.compFlg = false;
    });
  }
}
inputEventHandler.initialize();
</script>
