Autocomplete in JavaScript Without a Library

posted: 2020-10-25

javascript

I implemented an autocomplete from scratch using JavaScript.

Normally the quickest way to implement autocomplete is with a library, but I had a chance to build one myself from scratch, so here are my notes.

Requirements

  • Support PC (Chrome, IE, Safari), Android (Chrome), and iPhone (Safari).
  • Show prefectures containing the entered keyword as options.
  • Clicking an option selects it.
  • On PC, options can also be selected with the cursor keys and the Enter key.

The fourth one is the key point.

Implementation

A working version is available here.
Demo

Assume the HTML is as follows.
When text is entered in the text box, options are displayed inside the ul tag.

<input type="text" id="keyword" placeholder="都道府県名を入れてください" autocomplete="off"/>
<ul id="outputBox"></ul>

The JavaScript is as follows.

// List of prefectures
const prefectureList = ['北海道','青森県','岩手県','宮城県','秋田県','山形県','福島県',
              '茨城県','栃木県','群馬県','埼玉県','千葉県','東京都','神奈川県',
              '新潟県','富山県','石川県','福井県','山梨県','長野県','岐阜県',
              '静岡県','愛知県','三重県','滋賀県','京都府','大阪府','兵庫県',
              '奈良県','和歌山県','鳥取県','島根県','岡山県','広島県','山口県',
              '徳島県','香川県','愛媛県','高知県','福岡県','佐賀県','長崎県',
              '熊本県','大分県','宮崎県','鹿児島県','沖縄県'];

// Store the input/output elements in variables
const inputElm = document.getElementById('keyword');
const outboxElm = document.getElementById('outputBox');

/**
 * On text input in the text box
 */
inputElm.addEventListener('compositionend', function(e) {
    // Skip the Tab key since it moves focus to the next element
    if (e.key == 'Tab') {
        return;
    }

    outboxElm.innerHTML = '';
    let _this = this;
    setTimeout(function(){
        // Extract prefectures containing the entered text
        prefectureList.forEach(function(prefecture){
            if (prefecture.indexOf(_this.value) != -1) {
                let liElm = document.createElement('li');
                liElm.setAttribute('tabindex', '0');

                // Set a click event on the displayed option
                liElm.onclick = function() {
                    // When an option is clicked, reflect it in the text box
                    inputElm.value = this.innerHTML;
                    outboxElm.innerHTML = '';
                }

                // Add the option containing the keyword to the ul
                let txtNode = document.createTextNode(prefecture);
                liElm.appendChild(txtNode);
                outboxElm.appendChild(liElm);
            }
        });
    }, 10);
});

/**
 * Key handling while the text box has focus
 */
inputElm.addEventListener('keydown', function(e) {
    // When the down key is pressed, focus the first option
    if (e.key == 'ArrowDown' || e.key == 'Down') {
        let firstElm = outboxElm.getElementsByTagName('li')[0];
        if (firstElm) {
            firstElm.focus();
        }
        e.preventDefault();
    }
});

/**
 * Key handling or Enter while an option has focus
 */
outboxElm.addEventListener('keydown', function(e) {
    var currentElm = document.activeElement;

    // When the down key is pressed, focus the next option
    // Depending on the browser, it is either ArrowDown or Down
    if (e.key == 'ArrowDown' || e.key == 'Down') {
        if (currentElm.nextElementSibling) {
            currentElm.nextElementSibling.focus();
        }
        e.preventDefault();
    }
    // When the up key is pressed, focus the previous option
    // Depending on the browser, it is either ArrowUp or Up
    if (e.key == 'ArrowUp' || e.key == 'Up') {
        if (currentElm.previousElementSibling) {
            currentElm.previousElementSibling.focus();
        }
        e.preventDefault();
    }
    // When Enter is pressed, behave the same as clicking the current option
    if (e.key == 'Enter') {
        currentElm.click();
    }
});

This implements the basic behavior.

Note that this alone does not update the options when the keyword is deleted with Backspace or Delete.
If needed, use the keydown event or similar to handle character deletion.
