Exporting All Route53 Records to CSV

posted: 2020-08-21

AWS

Environment

  • Linux Mint 20 Ulyana
  • aws-cli/2.0.41
  • jq 1.6

I needed to list the contents of Route53 for an account with a large number of hosted zones and records registered.
I tried to do it in a one-liner, but couldn’t get the output I wanted, so I made it a shell script.

Installing the required software

AWS CLI

Install AWS CLI if you don’t have it.
https://docs.aws.amazon.com/cli/latest/userguide/install-cliv2.html

Initial AWS CLI configuration is here
https://docs.aws.amazon.com/cli/latest/userguide/cli-configure-quickstart.html

jq

jq is a tool for formatting JSON.
On Linux Mint, you can install it with the following command.

apt install jq

Creating a script to retrieve the Route53 contents

Create a shell script that retrieves the Route53 contents in JSON format with AWS CLI and outputs them to CSV while formatting with jq.
The script is as follows.

#!/bin/bash

# Output the CSV header
echo '"HostedZone","DomainName","DomainType","TTL","Value"'

# Get the list of hosted zones
HostedZones=`aws route53 list-hosted-zones --output json --query 'HostedZones'`
HostedZonesLen=`echo $HostedZones | jq length`

for i in $( seq 0 $(($HostedZonesLen - 1)) ); do
    Zone=`echo $HostedZones | jq .[$i]`
    ZoneId=`echo $Zone | jq -c -r '.Id'`
    ZoneName=`echo $Zone | jq -c -r '.Name'`

    # Get the list of records in the hosted zone
    Records=`aws route53 list-resource-record-sets --hosted-zone-id $ZoneId --output json --query 'ResourceRecordSets'`
    RecordsLen=`echo $Records | jq length`

    for i in $( seq 0 $(($RecordsLen - 1)) ); do
        record=`echo $Records | jq .[$i]`
        name=`echo $record | jq -c -r '.Name'`
        type=`echo $record | jq -c -r '.Type'`
        ttl=`echo $record | jq -c -r '.TTL'`
        data=`echo $record | jq -c -r '.AliasTarget.DNSName // ""'`

        # If AliasTarget's DNSName is not set, get the Values from ResourceRecords
        if [ -z "$data" ]; then
            data=`echo $record | jq -c -r '.ResourceRecords[].Value'`
        fi

        # data may contain double quotes, so escape them
        data=${data//\"/\"\"}

        # Output the CSV body
        echo "\"${ZoneName}\",\"${name}\",\"${type}\",\"${ttl}\",\"${data}\""
    done
done

Brief explanation

Get the hosted zone information in JSON format with AWS CLI.

aws route53 list-hosted-zones --output json --query 'HostedZones[]'

Loop over the retrieved hosted zones one by one.
The following command gets the records of the hosted zone in JSON format.

aws route53 list-resource-record-sets --hosted-zone-id $ZoneId --output json --query 'ResourceRecordSets'

Then, at key points, the jq command extracts the needed information from the JSON.

Note

The AWS CLI query option has the same effect as extracting with the jq command.
In other words, both of the following commands give the same result.

aws route53 list-resource-record-sets --hosted-zone-id $ZoneId --output json --query 'ResourceRecordSets'
aws route53 list-resource-record-sets --hosted-zone-id $ZoneId --output json | jq '.ResourceRecordSets'
