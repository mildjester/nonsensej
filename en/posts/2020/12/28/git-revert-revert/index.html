If You Revert in git as a Temporary Undo, Revert the Revert

posted: 2020-12-28

git

Hopping between many projects, I fairly often run into “I accidentally merged into master/develop” cases.
In those cases, I’ve basically dealt with it by doing a git revert on master/develop.
But a common pattern is forgetting to revert the revert afterward.

Forgetting it when you know a revert of the revert is needed can’t be helped,
but I remembered that on a project I used to help with, someone asked “Huh? Why is that needed?”, so I wrote this post.

First, suppose this source is on the master branch.

Now suppose you want it to return not only $hoge but also a value called $fooo.
You create a branch “feature/fooo”, make the change, and merge it into master.

Then you notice you forgot to write the method that returns $fooo, so you revert on master.

You add the method to “feature/fooo” and merge it into master.
It looks like the class variable and constructor changes are still there.

*Note that no conflict occurs here.

Here is the resulting source.
Only the last added method is included; the class variable and constructor changes are not.

This won’t behave as intended.

A common misconception is that revert “cancels the target commit”.
Revert doesn’t cancel a commit; it “creates a new commit that undoes the changes of the target commit”.
The reverted commit doesn’t cease to exist.

So unless you revert the revert commit itself, the changes made by the revert commit remain.

To summarize the steps:

Bad Pattern

  1. Merge the working branch into master.
  2. Revert on master.
  3. Continue making changes on the working branch.
  4. Merge the working branch into master.

Good Pattern

  1. Merge the working branch into master.
  2. Revert on master.
  3. Merge master into the working branch. (missing from the bad pattern)
  4. Revert the revert on the working branch. (missing from the bad pattern)
  5. Continue making changes on the working branch.
  6. Merge the working branch into master.

So unless you’re throwing away the reverted changes, revert the revert.
