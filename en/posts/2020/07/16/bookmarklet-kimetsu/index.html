Giving GitHub's Contribution Graph Tanjiro's Pattern

posted: 2020-07-16

bookmarklet
javascript

I’ve never actually watched Demon Slayer (Kimetsu no Yaiba), but I still see the kimono of its protagonist Tanjiro all the time.
Whenever I see that pattern, I think it looks a bit like GitHub’s contribution graph.

So let’s turn the GitHub contribution graph into Tanjiro’s kimono pattern.

For an explanation of bookmarklets and how to make them, see:
How to Make a Bookmarklet

Creating the Bookmarklet

First, write a script that changes the colors of the contribution graph cells.

// Get the contribution graph cell elements
var kusaElmList = document.getElementsByClassName('day')

for (var i=0; i<kusaElmList.length; i++){
  var kusa = kusaElmList[i]

  if (i % 2 == 0){
    // Even cells are green
    kusa.setAttribute('fill','#2A7')
  }else{
    // Odd cells are black
    kusa.setAttribute('fill','#000')
  }
}

Turn this into a bookmarklet.

javascript:for(var t=document.getElementsByClassName("day"),e=0;e<t.length;e++){var l=t[e];e%2==0?l.setAttribute("fill","#2A7"):l.setAttribute("fill","#000")}

Here’s the result.

The colors look right, but the gaps still bother me.
So let’s modify it to fill the gaps too.

// Get the contribution graph cell elements
var kusaElmList = document.getElementsByClassName('day');

for (var i=0; i<kusaElmList.length; i++){
  var kusa = kusaElmList[i];

  // Adjust the size and shape of the cells
  kusa.setAttribute('width','15');
  kusa.setAttribute('height','15');
  kusa.style.rx=0;
  kusa.style.ry=0;

  if (i % 2 == 0){
    // Even cells are green
    kusa.setAttribute('fill','#2A7')
  }else{
    // Odd cells are black
    kusa.setAttribute('fill','#000')
  }
}

Turn this into a bookmarklet.

javascript:for(var t=document.getElementsByClassName("day"),e=0;e<t.length;e++){var l=t[e];l.setAttribute("width","15"),l.setAttribute("height","15"),l.style.rx=0,e%2==(l.style.ry=0)?l.setAttribute("fill","#2A7"):l.setAttribute("fill","#000")}

Here’s the result.

Looks good.
