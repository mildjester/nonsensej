How to Make a Bookmarklet

What Is a Bookmarklet?

For details, see here
ウィキペディア (Japanese)

Simply put, you save JavaScript in a browser bookmark instead of a URL,
and click that bookmark whenever you want to run the JavaScript.

For example, if you register javascript:alert('hoge'); as a bookmark,
clicking that bookmark does the same thing as clicking <a href="javascript:alert('hoge');">hoge</a>.

There are many ways to make one, but here I’ll introduce how to create one using uglify-js.

Writing the JavaScript

First, create a js file and write whatever JavaScript code you want to run.
As an example, we’ll make a script that counts the number of div tags on the page.

Write the following code in a file named sample.js.

var divElms = document.getElementsByTagName('div');
alert('divの数は' + divElms.length + 'です！');

Minifying the JavaScript with uglify-js

Minify the sample.js you created using uglify-js.

First, install uglify-js so the command is available.
If you don’t have npm installed, install it first.

$ npm install -g uglify-js      # Add sudo if needed for your environment

Next, minify the JavaScript.
You can minify it with the following command.
*See the official page for each option

$ uglifyjs -c -m --toplevel -- sample.js

The minified script is output as follows.

var e=document.getElementsByTagName("div");alert("divの数は"+e.length+"です！");

Prefixing this minified script with javascript: gives you a bookmarklet.

Registering the Bookmarklet in the Browser

Add a new page to your browser bookmarks and enter javascript:{generated minified script} in the URL field.
In Chrome, it looks like this.
(Any name is fine as long as you can recognize it)

Now, while any page is open, clicking the registered bookmark runs the script.
