Upgrading to Ubuntu 20.04

posted: 2020-05-17

ubuntu

The long-awaited Ubuntu 20.04 LTS is out, so I upgraded from 19.10.
Here’s what happened along with the upgrade.

Apps That Disappeared

After upgrading, the following installed apps disappeared, so I reinstalled them.

  • shutter (screenshot tool)
  • MySQL Workbench

shutter

I referred to this page:
https://www.debugpoint.com/2020/04/shutter-install-ubuntu/

Here are the steps I took:

sudo apt update
sudo apt upgrade
sudo add-apt-repository ppa:linuxuprising/shutter
sudo apt install shutter

MySQL Workbench

There seem to be ways to install it by fiddling with commands, but I simply downloaded the deb from the official page and installed it.
https://dev.mysql.com/downloads/workbench/

The command-line method seems to just install the same deb you can download above anyway.

HDMI-Related Issues

*Added 2020/6/1
I found a fix and wrote about it in this post:
Booting Ubuntu 20.04 with an HDMI Cable Connected to a ThinkPad

My work PC is a ThinkPad T480, and when I tried to boot with a cable plugged into the HDMI port, it got stuck on the logo screen.

Ubuntn20.04にしてからマルチディスプレイで起動する事が出来なくなった。ずっとこの画面のまま動かない。

起動後にケーブル繋いだら普通にマルチにできる。 pic.twitter.com/Ke1ZLBLXv4

— djiroy (@mildjester) May 16, 2020

I also have a Thunderbolt-to-HDMI cable connected to the PC’s Thunderbolt port, and booting with that plugged in caused no problems.
Looking into it, several people have reported the same issue, so it’s probably a bug in Ubuntu 20.04.
https://bugs.launchpad.net/ubuntu/+source/linux/+bug/1874194

Also, plugging or unplugging a display cable after logging into Ubuntu messed up the position of the menu bar.
This happens with both the HDMI port and the Thunderbolt port.

So I boot my PC with the following steps:

  1. Unplug the HDMI cable and power on the PC.
  2. Once Ubuntu starts and the login screen appears, plug in the HDMI cable.
  3. Log in.
