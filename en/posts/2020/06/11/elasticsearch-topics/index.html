Elasticsearch Usage Notes

posted: 2020-06-11

Elasticsearch

I found usage notes from when I was using Elasticsearch a few years ago, so I’m turning them into a post.
In the examples below, Elasticsearch stores product information that includes a product ID (product_id).

Query to Search for a Single Document by ID

Simply specify the product_id.

{
  "query": {
    "match": {
      "product_id": "123"
    }
  }
}

Query to Search for Multiple Documents by ID in a Specified Order

Search for multiple documents. The order of results is also specified with weight.
Documents with a larger weight are ranked higher.

{
  "query": {
    "function_score": {
      "query": {
        "bool":{
          "should":[
            {"match": {"product_id": "123"}},
            {"match": {"product_id": "323"}},
            {"match": {"product_id": "223"}}
          ]
        }
      },
      "functions": [
        {
          "filter": { "product_id": { "product_id": "123" } },
          "weight": 3
        },
        {
          "filter": { "product_id": { "product_id": "323" } },
          "weight": 2
        },
        {
          "filter": { "product_id": { "product_id": "223" } },
          "weight": 1
        }
      ]
    }
  }
}

*Note
should works like OR.

Query to Delete Multiple Documents by ID

Simple.

{
  "query": {
    "bool":{
      "should":[
        {"match": {"product_id": "123"}},
        {"match": {"product_id": "223"}},
        {"match": {"product_id": "323"}}
      ]
    }
  }
}
