Booting Ubuntu 20.04 on a ThinkPad with an HDMI Cable Connected

posted: 2020-06-01

ubuntu

Environment

ubuntu 20.04 LTS

References

  • ubuntu bug forum
  • ubuntu wiki

In my previous post, I wrote that after updating Ubuntu to 20.04 I could no longer boot the PC with an HDMI cable plugged in.
There were reports that rewriting the Linux kernel would make it work, but I didn’t want to do that, so I left it alone.

As of 2020/6/1, there seems to be no official fix from Ubuntu yet, but on the Ubuntu bug report forum someone posted on 5/29 that “disabling quiet splash made it work!”
I tried it and it did work, so here are the steps.

Changing the grub Settings

Edit the grub settings with the following command.

$ sudo gedit /etc/default/grub

The config file opens in a text editor. Comment out the quiet splash line.
After commenting it out, save and close.

~snip~
GRUB_DEFAULT=0
GRUB_TIMEOUT_STYLE=hidden
GRUB_TIMEOUT=10
GRUB_DISTRIBUTOR=`lsb_release -i -s 2> /dev/null || echo Debian`
#GRUB_CMDLINE_LINUX_DEFAULT="quiet splash"    <- comment out this line with #
GRUB_CMDLINE_LINUX=""
~snip~

Applying the grub Settings

Apply the grub settings with the update-grub command below.
It takes a while, so wait for it to finish.

$ sudo update-grub
Sourcing file `/etc/default/grub'
Sourcing file `/etc/default/grub.d/init-select.cfg'
Generating grub configuration file ...
Linux イメージを見つけました: /boot/vmlinuz-5.4.0-33-generic
Found initrd image: /boot/initrd.img-5.4.0-33-generic
Linux イメージを見つけました: /boot/vmlinuz-5.4.0-31-generic
Found initrd image: /boot/initrd.img-5.4.0-31-generic
Found Windows Boot Manager on /dev/nvme0n1p1@/EFI/Microsoft/Boot/bootmgfw.efi
Adding boot menu entry for UEFI Firmware Settings

That’s it.
From the next boot, the OS starts without problems even with HDMI plugged in.

Note that since quiet splash is disabled, the loading screen with the Lenovo and Ubuntu logos shown at startup/shutdown no longer appears.
Instead, the current progress scrolls by rapidly as text, so don’t be surprised.
(It looks like the old-school Linux startup/shutdown screen.)
