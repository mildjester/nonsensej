Set up Ubuntu 20.04 on WSL2 in Windows 10.

Updating Windows 10

To use WSL2, you need Windows version 1903 or later, build 18362 or higher.
To check your version, press “Win + R” to open “Run”,
enter winver and click “OK”.

Ideally you can update via Windows Update, but sometimes the update doesn’t arrive.
In that case, use the Update Assistant.
https://www.microsoft.com/en-us/software-download/windows10

Installing WSL2

Open PowerShell as administrator and run the following.

dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

Once you’ve run these, restart once.

After restarting, open PowerShell as administrator again and run the following command.

wsl --set-default-version 2

If you see a message saying a kernel update is required,
update the kernel by following the page below and then run it again.
https://docs.microsoft.com/en-us/windows/wsl/wsl2-kernel

Installing Ubuntu

Search for “Ubuntu” in the Microsoft Store and install Ubuntu 20.04.
Then launch Ubuntu; initial setup runs, so configure your account and so on.

By default, apt fetches from overseas mirrors, so change it to a Japanese mirror with the following command.

sudo sed -i -e 's|archive.ubuntu.com|ftp.riken.go.jp/Linux|g' /etc/apt/sources.list

At this point Ubuntu is usable on WSL2.
However, by default the Ubuntu storage is placed on the C drive, so I’d like to move it to the D drive.

Use “LxRunOffline”, a tool that moves WSL installations.
First, download the archive from GitHub and extract it. (LxRunOffline-vX.X.X-mingw.zip)
https://github.com/DDoSolitary/LxRunOffline/releases

Next, create a folder to place WSL in.
In this example, create D:\wsl.

Open PowerShell as administrator and grant permissions on the folder you just created with the following command.

icacls D:\wsl /grant $env:USERNAME":(OI)(CI)(F)"

In the same PowerShell, move to the folder where you extracted LxRunOffline and run the following commands.

net stop LxssManager
.\LxRunOffline.exe move -n Ubuntu-20.04 -d d:\wsl\Ubuntu-20.04
net start LxssManager

Ubuntu installation is now complete.
To uninstall, run the following commands.

wsl -t Ubuntu-20.04
.\LxRunOffline.exe ui -n Ubuntu-20.04

*Note

Even without moving the WSL2 location, the D drive is mounted at /mnt/d/, so you can still use the D drive.
However, accessing Windows directories under /mnt/ is slow, so changing the WSL location is recommended.

Accessing Servers Running in Ubuntu from Windows as localhost

When you start a web server in Ubuntu (e.g. with Docker), you may not be able to access it from a Windows browser via http://localhost.
To connect as local, create a file named .wslconfig directly under your Windows home directory (C:\Users\hogeUser)
with the following content.

[wsl2]
localhostForwarding=True

Also, this may not work if Windows Fast Startup is enabled, so disable it.
Open “Settings > System > Power & sleep > Additional power settings > Choose what the power buttons do”,
and uncheck “Turn on fast startup (recommended)”.

Changing the DNS Server Used by Ubuntu

In WSL, the DNS server used for name resolution is configured automatically and written to /etc/resolv.conf.
By default, even if you edit this file, it gets rewritten every time WSL starts.

As is, name resolution occasionally fails inside Ubuntu,
so stop resolv.conf from being auto-updated and point it to Google’s DNS server “8.8.8.8”.

First, to stop the auto-update, add the following to /etc/wsl.conf (create the file if it doesn’t exist).

[network]
generateResolvConf = false

*This setting is also mentioned in the auto-generated resolv.conf.

Restart WSL in this state to apply the setting.
Either restart the PC or run wsl --shutdown from PowerShell or similar on the Windows side.

Access WSL again and configure DNS in /etc/resolv.conf.
If /etc/resolv.conf is a symbolic link to /run/..., remove the link with the unlink command.

Edit /etc/resolv.conf and set nameserver as follows.

nameserver 8.8.8.8

The DNS server used for name resolution in WSL (Ubuntu) is now Google’s DNS server.

Allowing Permission Changes on Windows Folders from Ubuntu

From Ubuntu, Windows folders are available under /mnt/ so you can read them,
but by default you can’t change permissions with chmod.

If you want to change permissions on Windows folders/files, create /etc/wsl.conf with the following content.

[automount]
options = "metadata"

*Note
Accessing Windows files from Ubuntu is extremely slow,
so I generally don’t recommend handling Windows files from Ubuntu.
