Changing the Key Layout on Windows 10

Let’s change the Windows key layout to be more Mac-like.

Make CapsLock Ctrl

I never use CapsLock, so I’ll assign it to the Ctrl key.
CapsLock is in the same position as the Mac’s Ctrl key, so it should be easier to use for people coming from a Mac.

To change it, use “Ctrl2Cap”.
https://docs.microsoft.com/en-us/sysinternals/downloads/ctrl2cap

The installation steps are as follows.

  1. Download and extract the ctrl2cap ZIP file.
  2. Launch PowerShell with administrator privileges and move to the folder extracted in step 1.
  3. Run .\ctrl2cap.exe /install.

If “Ctrl2cap successfully installed.” is displayed, the installation succeeded.
After restarting the PC, CapsLock works as Ctrl.

Toggle the IME ON/OFF with the Henkan/Muhenkan Keys

Make the keys on either side of the space bar toggle the IME ON/OFF, Mac-style.
The setup steps are as follows.

  1. Open Settings.
  2. Search for “Japanese IME settings” in Settings and open it.
  3. Open “Key and touch customization”
  4. Turn on “Assign your preferred functions to each key”.
  5. Assign the Muhenkan key to “IME-Off”.
  6. Assign the Henkan key to “IME-On”.
