Setting Up a Development PC on Windows 10

posted: 2020-09-04

Windows

WSL2 and Windows Terminal on Windows 10 looked good,
so I set up a development environment.

For the larger tasks, see the following:

  • Changing the Windows key layout
  • Using Ubuntu on WSL2
  • Installing Windows Terminal

Stopping Windows from Maximizing Automatically

By default, Windows 10 automatically maximizes a window when you drag it to the edge of the screen.
This feature often gets in the way, so disable it.

Open “Settings > System > Multitasking” and turn off “Snap windows”, and you’re done.

Installing Docker

Download Docker Desktop for Windows from the following.
https://hub.docker.com/editions/community/docker-ce-desktop-windows

Run the downloaded installer to install it.
During installation there is an “Enable WSL 2 Windows Features” checkbox; be sure to check it.

Now the docker command is available on the Ubuntu side as well.
If you installed Docker before WSL2, you can enable Docker on WSL from “Settings > Resources > WSL INTEGRATION”.

Installing Visual Studio Code

Download and install it from the following.
https://azure.microsoft.com/en-us/products/visual-studio-code/

If you manage source code with git on the Ubuntu side, you need to connect from Windows to Ubuntu.
To do so, install the “Remote - WSL” extension.
(It is probably recommended the first time you launch Visual Studio Code.)

Installing MySQL Workbench

MySQL Workbench requires “Visual C++ 2019”.
If it isn’t installed, download and install it from the following.
https://support.microsoft.com/en-us/help/2977003/the-latest-supported-visual-c-downloads

Download and install MySQL Workbench from the following.
https://dev.mysql.com/downloads/workbench/
