Installing Windows Terminal

posted: 2020-09-04

Windows

Setting up Windows Terminal to use Ubuntu.

Installing Windows Terminal

Just search for “Windows Terminal” in the Microsoft Store and install it.

Making Ubuntu the default in Windows Terminal

Launch Windows Terminal and open Settings.
settings.json opens, so find the guid for Ubuntu under “profiles > list”.

{
    "guid": "{07b52e3e-de2c-5db4-bd2d-ba144ed6c273}",  ← this
    "hidden": false,
    "name": "Ubuntu-20.04",
    "source": "Windows.Terminal.Wsl"
},

Set the guid you found as “defaultProfile”.

"defaultProfile": "{07b52e3e-de2c-5db4-bd2d-ba144ed6c273}",   ← put it here

Specifying the starting directory

When Windows Terminal starts, it opens in the Windows home directory.
When using Ubuntu, I want it to start in the Ubuntu home directory, so I change it.

Add startingDirectory to the Ubuntu settings in settings.json.
To start from /home/hogeuser in Ubuntu, configure it as follows.

{
    "guid": "{07b52e3e-de2c-5db4-bd2d-ba144ed6c273}",
    "hidden": false,
    "name": "Ubuntu-20.04",
    "source": "Windows.Terminal.Wsl",
    "startingDirectory": "//wsl$/Ubuntu-20.04/home/hogeuser"  ← add this
},

Specifying the font

I use fish as the shell in Ubuntu, and depending on the fish theme you may need to change the font.
For how to install fish, see here

Add fontFace to the Ubuntu settings in settings.json.
If you want to change the font size, also add fontSize.

To change the font to “Cascadia Code PL” and the font size to 11, it looks like this.

{
    "guid": "{07b52e3e-de2c-5db4-bd2d-ba144ed6c273}",
    "hidden": false,
    "name": "Ubuntu-20.04",
    "source": "Windows.Terminal.Wsl",
    "startingDirectory": "//wsl$/Ubuntu-20.04/home/hogeuser",
    "fontFace": "Cascadia Code PL",  ← add this
    "fontSize": 11  ← add this
},
