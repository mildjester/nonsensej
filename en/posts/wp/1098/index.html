[Linux Mint] OS Installation and Setup

posted: 2018-04-07

LinuxMint

■Environment

Linux Mint 18.3 cinnamon 64bit

Getting the OS

Download the ISO image from the official site.
https://linuxmint.com/download.php

If you have no particular preference, “Cinnamon 64bit” is apparently recommended, so I went with that.

There is no download mirror in Japan, so I chose Taiwan, which seemed close.
*For some reason Korea returned a 404 (as of 2018/03/09)

Installing the OS

Burn the downloaded ISO to a DVD or similar, insert it into the PC you want to install on, and boot it.
A desktop appears with an icon called InstallLinuxMint; double-click it.

Then just follow the on-screen instructions to proceed with the installation.
I used the following settings. (Only the noteworthy parts)

  • Language: I deliberately chose English　*Added 2018/4/18: application fonts end up looking like Chinese characters, so Japanese seems better.
  • Installation type: I wanted a clean install, so Erase disk and install Linux Mint
  • Keyboard layout: Japanese-Japanese was fine for a Lenovo keyboard

If you want to dual-boot with Windows, free up disk space on the Windows side beforehand,
and select Install Linux Mint alongside Windows Boot Manager as the installation type.
If it doesn’t dual-boot after installation, disable Secure Boot in the BIOS settings.

Update Manager Settings

Click Update Manager in the taskbar at the bottom right. (The shield-like icon)

For now, select Let me review sensitive updates and click OK.

It asks “Do you want to switch to a local mirror?”, so click OK.

Select one of the mirrors in Japan.

Click Refresh to update the list, then click Install Updates.

When the update completes, several more packages that can be updated are shown,
so update them as needed.

Changing the System Font

The default font wasn’t very good, so I changed it.
*This applies only if you chose English as the language during installation.
　If you install in Japanese from the start, you get a normal font.

First, open “SystemSettins > Font”.

You can change to any font you like in Font Selection there.
Personally, I liked Takao Ex Gothic Regular.

Changing Home Directory Names to English

If you install Linux Mint in Japanese, the directories directly under your home directory have Japanese names.
Japanese directory names are inconvenient when using the CLI, so change them to English with the following command.

env LANG=C xdg-user-dirs-gtk-update

After running the command above, it asks “May I rename the directories? (Japanese -> English)”, so choose Yes.
After logging in again, it asks “May I rename the directories? (English -> Japanese)”,
so check “Don’t ask me again” and choose No.

Additional Installation and Setup for Japanese Input

If you install Linux Mint in Japanese, Japanese input works from the start,
but some Japanese input software seems to be missing, so install it additionally.

Open System Settings > Input Method and install “Japanese”.

Next, open the “Language” tab and click “Install / Remove Languages” under Language Support.

An installation window opens; select Japanese and click “Install language packs”.

Next, open “Fcitx Configuration” from the menu.

In the input methods, there is “Keyboard - Japanese” above Mozc,
which gets in the way, so remove it.

That’s it.

Installing Basic Software

Basic development set

$ apt update  
$ apt install vim git

Slack

Slack can also be installed from the “Software Manager”,
but for some reason Japanese input doesn’t work with that version, so it’s better to download the Deb from the official site and install it.
https://slack.com/intl/ja-jp/downloads/linux (Japanese)

Shutter

An app that lets you insert arrows and comments into images, like Skitch on the Mac.
The design isn’t as rich as Skitch, but it’s good enough for adding comments to images.
You can’t edit unless you install libgoo-canvas-perl.

$ apt install shutter libgoo-canvas-perl

Chromium

The OSS version of Google Chrome.
Functionally, it’s almost the same as Chrome.
Installing chromium-browser-l10n localizes it into Japanese.

apt install chromium-browser chromium-browser-l10n

Changing Panel Settings

(This step was added when I did this on Linux Mint 19.1 MATE)
I couldn’t find an item in the settings menu to change the panel (the toolbar at the bottom of the desktop),
but it turns out you can change it by right-clicking the panel and selecting “Properties”.

You can also change the panel size, or shrink the panel width and center it (Mac-style)
