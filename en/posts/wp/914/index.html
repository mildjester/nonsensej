Setting Up a PHP Development Environment in Visual Studio Code

posted: 2017-12-18

PHP
VSCode

■Environment

Visual Studio Code 1.19.0
Linux Mint 18.3 cinnamon 64bit
macOS High Sierra 10.13.1
(The steps should be basically the same on both Linux and Mac)

■Getting Visual Studio Code

Download Visual Studio Code (hereafter VSCode).
https://code.visualstudio.com/

[Mac]
Extracting the downloaded zip gives you an application file (.app); move it to the Applications directory.

[Linux Mint]
Just run the downloaded deb file and follow the on-screen instructions.

■Changing the Font

Change the font used in VSCode to “Ricty Diminished”, a font designed for programming.

First, install the font itself on your PC.
See this post for the steps.

Once the font is installed, configure VSCode.
First, open “Code > Preferences > Settings” from the menu.

Then add the following line to the settings file:

"editor.fontFamily": "'Ricty Diminished'",

The font is now Ricty Diminished.

■Installing Extensions

After launching VSCode, select View > Extensions from the top menu.
Alternatively, select the square icon at the bottom of the icons on the left.

A search box appears, where you can search by keyword and install extensions.
Below are the ones I tried.

Project Manager

An extension for managing projects.
Saving the currently open workspace as a project
makes switching between projects easy.
It doesn’t seem possible to keep multiple projects open at once like in NetBeans or Eclipse.

■Usage
Open View > Command Palette from the top menu and type Project Manager in the search bar to show the Project Manager commands.

(The Command Palette can also be opened with Command + Shft+P)

The main commands are as follows.

Command Description
Save Project Save the current workspace as a project
Edit Project Edit saved projects
List Project to Open Show the list of saved projects and open the selected one

ftp-simple

An extension for uploading and downloading files and directories to and from a server.
It supports SFTP as well as FTP.

■Usage
Type “ftp-simple” in the Command Palette to see the candidates.
The Command Palette works the same as in “Project Manager” above, so I’ll skip it.

The main commands are as follows.

Command Description
Config Configure the server connection
Save Upload files/directories to the server
Download Download files/directories from the server
Diff Show the differences between local and server
Delete Delete files/directories on the server

PHP IntelliSense

An extension that adds PHP highlighting and completion.
Just install it.

Path Intellisense

An extension that auto-completes directory paths as you type them.
Just install this one too.

Bracket Pair Colorizer

Matching brackets get the same color, making it easy to see what is enclosed by which brackets.
It makes the editor a bit too colorful, so some people may dislike it.
Just install this one too.

■Settings

Language Settings per File Extension

If you use non-standard file extensions, highlighting and completion may not work.
In that case, open the file and click “Plain Text” at the bottom right.

*If another language is already associated, that language will be shown instead.

This opens the language selection.
To apply it to all files with the same extension, click “Configure File Association for ‘.xxx’” below the search bar.

Once you set the language here, highlighting and so on for that language will be applied from then on.
