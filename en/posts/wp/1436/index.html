Calculating TPS from Access Logs with grep

posted: 2018-07-05

Apache
Nginx

■Environment

Amazon Linux AMI release 2013.03
grep 2.6.3

A command to calculate TPS from web server access logs.
It works for both Apache and Nginx.

If the time format in the access log looks like 05/Jul/2018:12:34:56,
the following command outputs TPS.
*Adjust it to match the time format in your logs.

grep -o "05/Jul/2018:[0-9]\{2\}:[0-9]\{2\}:[0-9]\{2\}" access_log | sort | uniq -c

However, running this on 24 hours of access logs produces a huge number of lines,
so in that case it’s better to narrow down the hour.
The following example narrows it to logs from the 12:00 hour.

grep -o "05/Jul/2018:12:[0-9]\{2\}:[0-9]\{2\}" access_log | sort | uniq -c

Also, by changing the regex, you can get TPM (per minute) instead of TPS (per second).

grep -o "05/Jul/2018:[0-9]\{2\}:[0-9]\{2\}" access_log | sort | uniq -c
