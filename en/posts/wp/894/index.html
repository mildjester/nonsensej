[git] A Script to Delete Both Local and Remote Branches

posted: 2017-12-12

git

Deleting both the local and remote branch every time I removed a merged branch was tedious, so I made a script for it.

The remote is limited to origin.
Here’s an example named git_del_br.sh.

#!/bin/bash  
set +eu  
  
if [ $# -eq 1 ]; then  
    # delete local branch  
    loBrCheck=`git branch | grep "^[ ]*${1}\$"`  
    if [ ${#loBrCheck} -gt 0 ]; then  
        echo "delete local branch."  
    git branch -D $1;  
    fi  
  
    # delete remote branch  
    reBrCheck=`git branch -a | grep "^[ ]*remotes/origin/${1}\$"`  
    if [ ${#reBrCheck} -gt 0 ]; then  
        echo "delete remote branch"  
        git push --delete origin $1;  
    fi  
else  
    echo  
    echo "##################################"  
    echo " Usage: git_del_br.sh [branch name]"  
    echo "##################################"  
    echo  
fi
