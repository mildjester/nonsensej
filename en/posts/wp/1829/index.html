Installing Linux Mint 19.1 MATE from a USB Drive

posted: 2018-12-20

LinuxMint

I needed to rebuild my PC, so I tried installing the latest version of Linux Mint.
I prepared the installation on a Mac, writing the image to a USB drive and installing from it.

Downloading the OS Image

This time I chose “Linux Mint 19.1 “Tessa” - MATE (64-bit)”.
You can download it here (I just picked a nearby mirror such as Taiwan).
https://linuxmint.com/edition.php?id=263

Creating the Installation Media (USB)

First, insert the USB drive into the Mac and run diskutil list in the terminal.
This tells you the disk number of the USB drive (check NAME and SIZE).
In my case, the USB drive was /dev/disk2.

$ diskutil list
/dev/disk0 (internal):  
   #:                       TYPE NAME                    SIZE       IDENTIFIER  
   0:      GUID_partition_scheme                         121.3 GB   disk0  
   1:                        EFI EFI                     314.6 MB   disk0s1  
   2:                 Apple_APFS Container disk1         121.0 GB   disk0s2  
  
/dev/disk1 (synthesized):  
   #:                       TYPE NAME                    SIZE       IDENTIFIER  
   0:      APFS Container Scheme -                      +121.0 GB   disk1  
                                 Physical Store disk0s2  
   1:                APFS Volume Macintosh HD            70.2 GB    disk1s1  
   2:                APFS Volume Preboot                 69.6 MB    disk1s2  
   3:                APFS Volume Recovery                1.6 GB     disk1s3  
   4:                APFS Volume VM                      1.1 GB     disk1s4  
  
/dev/disk2 (external, physical):  
   #:                       TYPE NAME                    SIZE       IDENTIFIER  
   0:      GUID_partition_scheme                        *2.0 GB     disk2  
   1:       Microsoft Basic Data MINT19_1                2.0 GB     disk2s1

Format the target disk.
HOGEHOGE below is the name of the USB drive after formatting,
so use any name you like.

$ diskutil eraseDisk MS-DOS HOGEHOGE /dev/disk2

When formatting is done, unmount the disk and write the ISO image.
(The dd command takes quite a while.)

$ diskutil unmountDisk /dev/disk2  
Unmount of all volumes on disk2 was successful  
$ cd ~/Downloads   # Replace with the location where you downloaded the ISO image  
$ sudo dd if=linuxmint-19.1-mate-64bit.iso of=/dev/rdisk2 bs=32m  
dd: /dev/rdisk2: short write on character device  
dd: /dev/rdisk2: Input/output error  
60+1 records in  
60+1 records out  
2029518848 bytes transferred in 907.854818 secs (2235510 bytes/sec)

*Note
The disk specified with of is rdisk2 rather than disk2 (with an r prefix).
This apparently makes the process faster.
Also, the best value for bs (buffer size) depends on your environment.
If you’re not sure, 32m should be fine.

Once the dd command completes, eject the disk, and the installation media is ready.

Installing the OS

Insert the USB drive into the PC where you’ll install Linux Mint, boot it, and open the BIOS settings.
How to open the BIOS settings depends on the manufacturer, so check yours.

In the BIOS boot order settings, set the USB drive first and close the BIOS settings.
When the BIOS settings screen closes, the PC reboots and you can start Linux Mint.

The Linux Mint running at this point is a temporary environment inside the OS image,
so run the installer on the desktop to install the OS onto the HDD or SSD.

The OS installation is now complete.
