[Mac] Installing asdf for Language Package Management (fish Environment)

posted: 2017-08-19

Mac

■Environment

macOS Sierra 10.12.6
fish 2.5.0

■Steps

It can apparently be installed with Brew too, but following the official page’s steps seems better.
Official page: https://github.com/asdf-vm/asdf

First, clone asdf from github and add it to the fish config.

$ git clone https://github.com/asdf-vm/asdf.git ~/.asdf --branch v0.3.0  
$ echo 'source ~/.asdf/asdf.fish' >> ~/.config/fish/config.fish  
$ mkdir -p ~/.config/fish/completions; and cp ~/.asdf/completions/asdf.fish ~/.config/fish/completions

Install the applications asdf needs with brew.
The following is roughly what’s listed on the official site.

$ brew install coreutils automake autoconf openssl libyaml readline libxslt libtool unixodbc

Some languages also require additional applications.
See each language’s github page for details
https://github.com/asdf-vm/asdf-plugins

[Memo]
As of October 2017, installing the latest version of icu4c breaks PHP builds, so it’s apparently better to install an older version
Reference: https://github.com/phpbrew/phpbrew/issues/899

Add a language to be managed by asdf.

$ asdf plugin-add {any name} {github repository}  
===== (e.g.) asdf plugin-add go https://github.com/kennyp/asdf-golang

For the repository to set above, see the following
https://github.com/asdf-vm/asdf-plugins
If you get an error here, a required application may be missing,
so check the error message and install it with brew.

View the list of installable versions.

$ asdf list-all {the name from before}  
===== (e.g.) asdf list-all go

Install the desired version from those listed above,
and configure it for use.

$ asdf install {the name from before} {version}  
===== (e.g.) asdf install go 1.8.4  
$ asdf global {the name from before} {version}  
===== (e.g.) asdf global go 1.8.4

That completes the setup.

For other commands, see the official page. It’s so well organized you hardly need a cheat sheet.
https://github.com/asdf-vm/asdf
