Setting Up a Docker Environment on Mac

posted: 2017-05-08

Mac
Docker

■Environment

macOS Sierra 10.12.4

Installing Docker

Click “Get Docker for Mac (Stable)” on the official page (here)
and download the Docker dmg.

Running the downloaded dmg prompts you to drag and drop “Docker.app” into “Applications”;
do as it says.

Docker has now been added to Launchpad; click it to start.
Setup runs on first launch, so you’ll be asked for your Mac password.

Setup runs for a while, and when “Docker is now up and running!” appears, setup is complete.
Open a terminal and run the following command; it should return the Docker version.

docker version

If there are no problems, click “Got it” to close the Docker window.
Docker keeps running in the background after the window is closed,
so a whale icon is shown in the status bar.

Initial Settings

By default, Docker starts automatically when you log in to your Mac.
If you don’t normally need Docker running, click the whale in the status bar
and uncheck
Preferences > General > Start Docker when you log in.
(e.g. if you only want Docker when testing)
In that case, start Docker from Launchpad when you need to use it.

You can also change other things in Preferences, such as directories shared with Docker containers,
so adjust the settings as needed.
