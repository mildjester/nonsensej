php-mcrypt Fails to Install via brew

posted: 2016-09-20

Mac
PHP

■Environment
OS X El Capitan(10.11.6)
Homebrew 0.9.9

I got an error when installing php-mcrypt with brew,
so here are notes on the error and how I dealt with it.

First, the error:

# brew install homebrew/php/php70-mcrypt  
~snip~  
/usr/local/opt/php70/bin/phpize: line 61: /usr/local/Library/Homebrew/shims/super/sed: No such file or directory  
/usr/local/opt/php70/bin/phpize: line 62: /usr/local/Library/Homebrew/shims/super/sed: No such file or directory  
/usr/local/opt/php70/bin/phpize: line 63: /usr/local/Library/Homebrew/shims/super/sed: No such file or directory  
Configuring for:  
PHP Api Version:  
Zend Module Api No:  
Zend Extension Api No:  
/usr/local/opt/php70/bin/phpize: line 155: /usr/local/Library/Homebrew/shims/super/sed: No such file or directory  
autoheader: error: AC_CONFIG_HEADERS not found in configure.in  
~snip~

In short, “/usr/local/Library/Homebrew/shims/super/sed”, used by phpize, doesn’t exist.
After some investigation, it turned out that in my environment the Homebrew path was
“/usr/local/Homebrew/Library/Homebrew”
rather than
“/usr/local/Library/Homebrew”
in the first place. (What is this hierarchy?)

phpize sets the above path in a variable called $SED,
so I fixed it by rewriting the path to match my environment.

SED="/usr/local/Homebrew/Library/Homebrew/shims/super/sed"
