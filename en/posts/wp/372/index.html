[Corporation] Notes on Filing National Taxes with e-Tax

posted: 2017-02-07

法人事務

I filed the national tax return for my (dormant) corporation with e-Tax, so here are my notes on the steps.
Even if your company isn’t dormant, the steps should be mostly the same.
*For eLTAX (local taxes), see this post.

■What You Need

  • Windows PC
  • IC card reader
  • PDFs of documents to attach to the tax return, such as financial statements

■Steps

1. Preparing to Use e-Tax

The digital certificate doesn’t have to be the corporation’s; the representative’s personal one is fine.
The My Number Card includes a digital certificate, so using that is probably the quickest.

Follow the procedure here:
http://www.e-tax.nta.go.jp/hojin.html (Japanese)

2. Creating the Filing Data in the e-Tax Software

The e-Tax software and the user identification number entered when launching it can also be obtained in step 1.

*Note
User identification numbers issued in the past apparently stay valid (?) as long as you keep using them,
but if you only use it about once a year, it may have expired. (Mine had.)
If you’re told your user identification number is invalid, do step 1 again.

Create the return from “Create > Returns/Applications > New” (作成＞申告・申請等＞新規作成) in the left menu.
[First: the tax return]
Select the following and click “Next”:
Procedure type: Return (申告)
Tax item: Corporate tax / local corporate tax (法人税・地方法人税)
Form year: the one that fits your business

If it isn’t there, install it additionally from the menu shown when e-Tax starts.
Also note that even if it’s installed, the corporate forms apparently won’t appear if you entered a personal user identification number.

Create the following:
[Final return of an ordinary corporation (blue form)]

  • Schedule 1(1): Return of income for each business year
  • Schedule 2: Statement for determining family corporations, etc.
  • Schedule 4: Statement on calculation of income
  • Schedule 7(1): Statement on inclusion of loss carryforwards or disaster losses in deductible expenses
  • Corporate business overview statement

*Note
The screen for choosing which forms to create uses checkboxes, but you can’t select more than one.
Create Schedule 1 first, then add the other documents afterward.

[Second: attachments to the tax return]
Select the following and click “Next”:
Procedure type: Return (申告)
Tax item: Corporate tax / local corporate tax (法人税・地方法人税)
Form year: the one that fits your business

Create the following:
[Image attachments (corporate tax return)]

  • Attachment transmittal form
    -> Attach PDFs of the financial statements, cash book, and general ledger

3. Signing in the e-Tax Software

Sign the data created above from “Signable list > Digital signature” (署名可能一覧へ＞電子署名) in the left menu.
Use the digital certificate obtained in step 1 for the signature.

4. Sending from the e-Tax Software

From “Sendable list > Send” (送信可能一覧へ＞送信) in the left menu, first link the two documents created in step 2.
Select the document in the lower area that can’t be sent on its own (the attachment you created) and click “Link” (紐付け).
The link screen appears; select the tax return and click “OK”.

With the link done, select the sendable document in the upper area (the tax return you created) and click “Send”.
Then enter the PIN for your user identification number, and the submission is complete.

That completes filing with e-Tax.
