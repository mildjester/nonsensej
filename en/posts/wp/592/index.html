Setting Up a Mastodon Instance with Only Heroku

posted: 2017-04-28

Mastodon seems to be popular lately,
so I tried setting up a Mastodon instance using only Heroku without spending any money.

Notes

  • These steps don’t use S3 (storage), so icons, headers, etc. are not saved.
  • I’m building this as an instance just for myself.
  • I stuck to “Heroku only”; it could be combined with other free tools, but I didn’t do that.

■Steps (Creating the Instance)

If you don’t have a Heroku account, create one.
You can create an account here.

Click the “Deploy to Heroku” button on Mastodon’s official Heroku page.

Heroku’s new app screen opens; enter the following.

  • AppName: the name of the app to create
  • LOCAL_DOMAIN: {the AppName above}.herokuapp.com
  • S3_ENABLED: false
  • SINGLE_USER_MODE: true

Once you’ve entered the above, click the “Deploy” button.

In my case a screen asking for credit card information appeared here, but that may have been because I was already using Heroku and had used up the free tier.
If you’ve just signed up for Heroku, nothing may appear.

When the deploy finishes, turn “worker” ON in the “Resources” screen of the Heroku dashboard.
Clicking the pencil icon on the right lets you toggle it ON/OFF.

That completes creating the Mastodon instance.

■Steps (Registering an Account)

Normally you’d register an account and click the link in the email sent to the registered address
to complete registration, but since we haven’t configured a mail server this time,
we’ll forcibly proceed by looking at the DB.

First, click “Heroku Postgres :: Database” in the “Resources” screen of the Heroku dashboard.
This takes you to the PostgreSQL management screen; click “View Credentials”
and note the “Heroku CLI” entry (heroku pg:psql…).
*This is the Heroku CLI command you’ll use later.

Access “{AppName}.herokuapp.com” in a browser and the account creation screen opens;
register an account as usual.

Next, install the Heroku CLI.
The installation steps are summarized here.

If PostgreSQL isn’t installed on your local PC, install it.
On a Mac you can install it with the following command.

brew install postgresql

Once PostgreSQL is available, connect to the Heroku DB
and look up the token for email address confirmation.

# In your local PC's terminal, run the "Heroku CLI" command you noted  
heroku pg:psql postgresql-fitted-xxxxxx --app {AppName}  
# You're now in DB mode; select the token from the DB  
select email, confirmation_token from users;

The command above displays the token; access the following URL including it in a browser.
https://{AppName}.herokuapp.com/auth/confirmation?confirmation_token={the token you found above}

This completes the email address confirmation, and you can start using Mastodon.
