[AWS] Notes on Tasks After Launching a New EC2 Instance

posted: 2017-11-12

AWS

Environment

AWS EC2
Amazon Linux

Security Group Settings

Configure the allowed sources for SSH and HTTP.
By default, only SSH from the source used when launching the EC2 instance is allowed.

SSH into the Launched EC2 Instance

Connect via SSH as follows.
Login account: ec2-user
Private key: the pem file downloaded when launching the EC2 instance
*Set the pem file’s permissions to 400 after downloading.

Become root and Change the Password

$ sudo su -  
# passwd

Set the Clock to Japan Time (as root)

# cp -p /usr/share/zoneinfo/Japan /etc/localtime  
# service rsyslog restart  
# service crond restart

*After changing localtime, log timestamps and cron execution times won’t be in Japan time unless you restart rsyslog and crond.
