Sending CircleCI Notifications to Slack

posted: 2018-10-14

CircleCI

CircleCIの結果をSlackに通知する (Japanese)

This assumes the following basic Circle CI setup has been completed.
Running Unit Tests on Pull Requests with Circle CI

With only the steps above, Circle CI notifications arrive by email,
so we’ll change them to arrive in Slack.

Slack Setup

First, install the Circle CI app in Slack.
https://my.slack.com/apps/A0F7VRE7N-circleci

Clicking Install shows a screen for selecting the channel to notify.
Choose any channel you like.

The next screen explains what to do in the Circle CI settings.
It shows the Webhook URL (the URL used to send notifications) to set in Circle CI, so take note of it.

Below that explanation there are also fields for changing the name and icon used for notifications; change them if you like.

Circle CI Setup

On the project’s screen, click Settings (the gear icon) to open the settings screen.
From the left menu, open “NOTIFICATIONS > Chat Notifications”,
enter the Webhook URL you noted on the Slack screen into “Webhook URL”, and click “Save”.

Clicking “& Test Hook” here sends a test notification to the configured channel.
It’s a good idea to run it to confirm the setup worked.

If you receive “Hello from CircleCI” as shown above, the setup is complete.
