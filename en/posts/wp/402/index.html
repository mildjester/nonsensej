[WordPress] Speeding Up SyntaxHighlighter Evolved

posted: 2017-02-10

Wordpress

After installing the WordPress plugin “SyntaxHighlighter Evolved”,
page rendering became very slow, so I sped it up.

〜〜〜 Added 2017/2/11 〜〜〜
Switching plugins might be quicker.
I tried switching to “WP Code Highlight.js”, and rendering is fast with no problems.
I also like its padding and such better.
〜〜〜 End of addition 〜〜〜

■Environment
CentOS 7.3
Wordpress 4.7.2
SyntaxHighlighter Evolved 3.2.1
*This assumes you have permission to operate the server where WordPress is installed.

“SyntaxHighlighter Evolved” supports many languages,
but it includes languages I never actually write, so I’ll stop the plugin
from loading the ones I don’t need.

Specifically, edit the PHP file inside the plugin and comment out the lines that seem to load
settings for unneeded languages.

# cd /{wordpressが配置されているディレクトリ}/wp-content/plugins/syntaxhighlighter  
# vim syntaxhighlighter.php

The lines to comment out are the following, starting around line 114.

wp_register_script( 'syntaxhighlighter-brush-○○○',〜〜〜　$this->agshver );

The “○○○” part above contains the language name, so comment out the lines for languages you don’t need.

Also, though I’m not sure how much it helps, I commented out the themes I don’t use as well.
The relevant lines are the following, starting around line 149.

wp_register_style( 'syntaxhighlighter-theme-○○○',〜〜〜　$this->agshver );

The “○○○” part above contains the theme name.

The languages and themes commented out above
are also stored in arrays further down, so comment them out there too.

The array for languages is around line 162.

$this->brushes = (array) apply_filters( 'syntaxhighlighter_brushes', array(  
    'as3'           => 'as3',  
    'actionscript3' => 'as3',  
    'bash'          => 'bash',  
    'shell'         => 'bash',  
    以下略

The array for themes is around line 243.

$this->themes = (array) apply_filters( 'syntaxhighlighter_themes', array(  
    'default'    => __( 'Default',      'syntaxhighlighter' ),  
    'django'     => __( 'Django',       'syntaxhighlighter' ),  
    'eclipse'    => __( 'Eclipse',      'syntaxhighlighter' ),  
    'emacs'      => __( 'Emacs',        'syntaxhighlighter' ),  
    'fadetogrey' => __( 'Fade to Grey', 'syntaxhighlighter' ),  
    'midnight'   => __( 'Midnight',     'syntaxhighlighter' ),  
    'rdark'      => __( 'RDark',        'syntaxhighlighter' ),  
    'none'       => __( '[None]',       'syntaxhighlighter' ),  
) );

After commenting out the parts above as appropriate, page rendering got somewhat faster.
