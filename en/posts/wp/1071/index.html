docker-compose Cheat Sheet

posted: 2018-01-29

Docker

Environment

macOS High Sierra 10.13.2
docker-compose 1.18.0

■Frequently used commands

Create and start all services defined in the yaml

docker-compose up -d

*The -d option starts them in the background.
　Containers that need building will also be built.

Check the currently running containers

docker-compose ps

Stop and remove all currently running containers

docker-compose down

■Commands for operating individual services

Create a container for a specific service

docker-compose create {サービス名}

Start a container for a specific service

docker-compose start {サービス名}

Do create and start in one go

docker-compose run -d {サービス名}

Stop a container for a specific service

docker-compose stop {サービス名}

*When running the create or run command, services linked to the specified service via depends_on etc. are started as well.
