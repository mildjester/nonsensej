How to Set Up Digest Authentication

posted: 2016-01-20

Apache

How to add digest authentication to a web server running Apache.
■Environment
CentOS Linux release 7.2.1511 (Core)
Apache/2.4.6

Check whether Apache supports digest authentication.
If the following command outputs a result, it’s supported.

# grep digest /etc/httpd/conf.modules.d/ -r  
conf.modules.d/00-base.conf:LoadModule auth_digest_module modules/mod_auth_digest.so

Create an ID and password set for digest authentication.
Below, “Sample Auth” is the realm name and “sampleuser” is the ID to set. Change them as needed.
“/etc/httpd/conf/.hpass” is the file to be generated; both the path and file name are up to you.

# htdigest -c /etc/httpd/conf/.htpass 'Sample Auth' sampleuser  
Adding password for sampleuser in realm Logical Dice Auth.  
New password:　←Enter the password to set  
Re-type new password:　←Enter the password again

Then configure it in the Apache config file.
In the example below, digest authentication is shown when content under “/var/www/html/sample”
is accessed from a web browser.
For AuthUserFile below, specify the file generated above.

<Location "/sample/">  
   AuthType Digest  
   AuthName "Sample Auth"  
   AuthUserFile "/etc/httpd/conf/.htpass"  
   Require valid-user  
</Location>

Now reload (restart) the Apache configuration, and digest authentication will be enabled.
