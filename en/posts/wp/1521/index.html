Checking Akamai Response Headers in Chrome

posted: 2018-09-26

Chrome

Background

The company I’m currently helping uses Akamai to cache pages.
For more about Akamai, see here.
https://www.akamai.com/jp/ja/ (Japanese)

When developing web pages, you sometimes want to know whether the page you’re viewing
is served from Akamai’s cache.

Google Chrome’s developer tools show the usual response headers,
but Akamai’s response headers are special, so you can’t see them there.

You can also call curl with options,
but checking pages that require login means setting cookies and so on.
https://qiita.com/rasaka/items/fc96cd3b8f73a02477cb (Japanese)

Solution

In such cases, the Chrome extension “CDN Headers & Cookies”
lets you easily see Akamai’s response headers.
https://chrome.google.com/webstore/detail/cdn-headers-cookies/obldlamadkihjlkdjblncejeblbogmnb

It’s easy to use.

① Add It to Chrome from the Store

② Open the Page You Want to Check

③ Click the Yellow Icon in the Chrome Toolbar

④ Open the Response Headers Tab and Check the Status

The meaning of each status is explained in the Akamai community.
https://community.akamai.com/customers/s/article/Akamairxdxn3?language=en_US
