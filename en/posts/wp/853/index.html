[CentOS] Sending Slack Notifications on Intrusion Detection

posted: 2017-12-12

CentOS

■Environment

CentOS 7.4
AIDE 0.15.1

Install the intrusion detection tool AIDE and send its scan results to Slack.

Installing AIDE

yum install -y aide

Configuring AIDE

vim /etc/aide.conf

The settings for monitored directories start around line 95.
The settings are written as follows.

/{DIR_PATH}/ {CHECK_METHOD} #Include in monitoring  
!/{DIR_PATH}/ #Exclude from monitoring

Write the target directory path in the “DIR_PATH” part above,
and the check method in “CHECK_METHOD”.

The check methods are described before line 95 of the config file, so refer to that.
For AIDE 0.15.1, “CONTENT_EX” seems to be a safe choice for now.

Once the monitoring targets are configured, initialize the AIDE database.
*This command takes quite a while.

aide -i

Setting Up Automatic Monitoring

Create a script that runs an AIDE scan and sends the result to Slack.
Let’s say we name it /opt/aide_scan.sh.

vim /opt/aide_scan.sh

The shell script contents are as follows.

#!/bin/bash  
set +e  
  
##### Settings  
## AIDE  
LOGFILE="/var/log/aide/aide.log"  
AIDEDIR="/var/lib/aide"  
## Slack  
URL="https://hooks.slack.com/services/AAAAAAAA/BBBBBBBB/CCCCCCCC"  
TO="#aide"  
EMOJI=":cop:"  
NAME="AIDE-COP"  
  
##### Run AIDE Scan  
/usr/sbin/aide  -u > $LOGFILE  
cp $AIDEDIR/aide.db.new.gz $AIDEDIR/aide.db.gz  
x=$(grep "Looks okay" $LOGFILE | wc -l)  
if [ $x -eq 1 ]; then  
    MSG="OKだよ"  
else  
    MSG="侵入検知！詳細は[${LOGFILE}]を見てね"  
fi  
  
##### Send To Slack  
payload="payload={\"channel\": \"${TO//\"/\\\"}\", \"username\": \"${NAME//\"/\\\"}\", \"text\": \"${MSG//\"/\\\"}\", \"icon_emoji\": \"${EMOJI}\"}"  
curl -m 30 --data-urlencode "${payload}" $URL -A 'zabbix-slack-alertscript / https://github.com/ericoc/zabbix-slack-alertscript'

The script settings are as follows.

Item Description
LOGFILE Log file where AIDE scan results are written.
AIDEDIR AIDE’s directory. Match it to the settings in aide.conf.
URL URL of Slack’s “Incoming WebHooks”. See here for details.
TO Slack channel to send the message to
EMOJI Emoji displayed in Slack
NAME Name displayed in Slack

Run the script once a day with cron.
Here is an example cron entry.

0 10 * * * /bin/sh /opt/aide_scan.sh > /dev/null 2>&1

AIDE will now check for intrusions once a day.
