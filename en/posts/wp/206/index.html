[PHP] Changing the Highlight of the Variable Under the Cursor in Eclipse

posted: 2016-03-08

PHP
Eclipse

Sometimes the color of the variable under the cursor gets weird.
Changing the following setting fixes it.

■Environment
Mac (OS X El Capitan 10.11.3)
Eclipse Luna Service Release 2 (4.4.2)

[Menu Location]
Preferences → General → Editors → TextEditors → Annotations

[Settings]
PHP elements ‘ write’ occurences: highlight color where the variable under the cursor is written
PHP elements ‘ read’ occurences: highlight color where the variable under the cursor is read

I wrote this for PHP, but it’s probably about the same for other languages.

* Even after making the change above, the colors in already-open source files don’t seem to change.
　To see the new colors, reopen the source file after changing the setting.
