Creating a Contact Form in WordPress

posted: 2018-01-17

Wordpress

Environment

Wordpress 4.9.1
Contact Form 7 4.9.2
WP Mail SMTP 1.2.2

Create a contact form on a WordPress static page
and send an email when someone submits an inquiry.
An external mail server is used here.

Steps

■Installing the Plugins

Install and activate the following plugins.

  • Contact Form 7
  • WP Mail SMTP

* Be careful: there is a similar plugin called “Contact Form7” (no space before the 7).

■Configuring the Contact Form

On the installed plugins screen, select Settings for “Contact Form 7”.

The form list is displayed, and a form called “Contact form 1” has been created automatically. Select “Edit”.

Here you can edit the form name and contents.

Each tab contains the following.

  • Form
    • Configure the form contents displayed on the web page. Adding an asterisk makes a field required.
  • Mail
    • Settings for the email sent when the form is submitted. The sender is configured later in “WP Mail SMTP”, so you don’t need to set it here.
  • Messages
    • Messages displayed on screen when the form is submitted
  • Additional Settings

You can apparently do more detailed customization too, but I’ll skip it here.

Also, note down the “Shortcode” shown on the form list screen, since you will embed it in a static page at the end.

■Configuring the Mail Server

On the installed plugins screen, select Settings for “WP Mail SMTP”.

* You can also select “Settings > WP Mail SMTP” from the left menu.

Enter the From Email and From Name as appropriate, and choose the mailer that fits your environment.
If you’re not sure about the mailer, choose “Other SMTP” (the usual method where you specify the mail server’s hostname, etc.).

Detailed settings that depend on the chosen mailer then appear below. Fill them in and click “Save Settings” to finish.

■Creating the Static Page

Just put the shortcode you noted down in the “Configuring the Contact Form” step into a static page.
Decorate it as needed, e.g. wrap it in a div tag or add a header.

That completes the contact form.
