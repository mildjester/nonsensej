[Mac] Installing Archive Software (Windows-Compatible)

posted: 2017-10-13

Mac

■Environment

macOS Sierra 10.12.6

Files compressed on Windows sometimes can’t be opened properly on a Mac,
and files compressed on a Mac sometimes can’t be opened properly on Windows.

In those cases, using the following software on the Mac side solves the problem.

Windows → Mac Archive Exchange

Extracting with software called “The Unarchiver” works properly.
It also helps when archives downloaded from OneDrive don’t extract correctly.

It’s available on the Mac App Store, so search for it and install it.
To use it, just open the archive you want to extract with “The Unarchiver”.

Mac → Windows Archive Exchange

Compressing with software called “WinArchiver Lite” produces archives that extract properly on Windows.
This one is also available on the Mac App Store.

To use it, open the files/directories you want to compress with “WinArchiver Lite”,
or launch “WinArchiver Lite” and drag & drop the files/directories you want to compress onto its window,
and a Windows-compatible archive is created.
