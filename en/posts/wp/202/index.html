posted: 2016-03-08

CentOS

Checklist When cron Doesn’t Run

 

(1) Is the cron process (crond) running?
↓ It is running
(2) Is the crontab entry correct?
↓ It is correct
(3) If cron calls a script, are the script’s execute permissions appropriate?
↓ They are appropriate
(4) Is there any hint output in /var/log/cron?
↓ If anything, nothing is output at all
(5) Is the rsyslog process running?

 

When cron didn’t run in a Docker environment, (5) was what got me.
It seems that if rsyslog isn’t running, not only are no logs written, but cron jobs aren’t executed at all.
