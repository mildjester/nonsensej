Basic Setup of Google Tag Manager

posted: 2018-11-26

GoogleService

These are my notes from switching from Google Analytics to Google Tag Manager.
It is assumed that you already have a Google Analytics account.

Creating an Account

First, create an account on the Google Tag Manager page
https://tagmanager.google.com
Enter any account name, select Japan as the country, and click “Continue”.

Next you’ll create a container, so
enter any container name and select where it will be used (web page, mobile app, etc.).
Here we’ll assume Web is selected.

After you agree to the terms, the tags to embed in your HTML are displayed.
A tag for <head> and a tag for <body> are generated, so
embed each one in the corresponding place.

Google Tag Manager is now ready to use.

Setting Up Event Tracking

Let’s set up click tracking.

Open the Google Tag Manager dashboard and click the “New Tag” link.
A tag is something like an item to be detected.

The tag configuration screen opens, where you specify the tag’s name and type.
For now, configure it simply as shown below.

There is a “Google Analytics Settings” field; select “New Variable”.
A field for the tracking ID appears, so enter your Google Analytics tracking ID.
Once everything is entered, click “Save” to close it.

Next, scroll down to configure the trigger.
A trigger is the condition for detecting an event.

Click the plus icon to create a new trigger.

Set the trigger’s name and details.
Basically, the settings shown below are fine.
If the clicked element has an ID, “Click ID” is fine, but
if it has no ID and only a class or similar,
select “Click　Classes”.

When everything is done, click “Save” to close the trigger configuration screen,
then click “Save” on the tag configuration screen as well.

Finally, click “Submit” on the Google Tag Manager top screen and you’re done.
