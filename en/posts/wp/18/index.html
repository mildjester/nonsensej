Building a Mail Server (Part 2, dovecot)

posted: 2015-08-08

CentOS

■Environment
CentOS 7
dovecot 2.2.10

This assumes Part 1 (postfix) has already been completed.

Install the required packages

yum -y install dovecot

Edit the main config file (vi /etc/dovecot/dovecot.conf)

protocols = imap pop3  
listen = *

Edit the auth config file (vi /etc/dovecot/conf.d/10-auth.conf)
This time I use password-file authentication

#disable_plaintext_auth = yes  
auth_mechanisms = plain login digest-md5 cram-md5  
#!include auth-system.conf.ext  
!include auth-passwdfile.conf.ext

Edit the mail config file (vi /etc/dovecot/conf.d/10-mail.conf)

mail_location = maildir:~/Maildir

Edit the master config file (vi /etc/dovecot/conf.d/10-master.conf)

unix_listener /var/spool/postfix/private/auth {  
  mode = 0666  
  user = postfix  
  group = postfix  
}

Edit the SSL config file (vi /etc/dovecot/conf.d/10-ssl.conf)

ssl_cert = </etc/pki/sample/sample.crt  
ssl_key = </etc/pki/sample/sample.key  
ssl_ca = </etc/pki/sample/sampleCA.crt

Generate a CRAM-MD5 hashed string of the auth password.

doveadm pw -s CRAM-MD5  
Enter new password: (enter the password you want to set)  
Retype new password: (re-enter the password you want to set)  
{CRAM-MD5}256f41a2b646bf66ae494370947623fd7a1f496442c81a0fdd9c2b1d994eb816

Check the target account’s information.
The part from the account name through the home directory will be used later.

grep demouser1 /etc/passwd  
demouser1:x:1000:1000::/home/demouser1:/sbin/nologin

Create the password file (vi /etc/dovecot/users)
Copy the account name through home directory part from the passwd file you just checked, and write a line with the generated CRAM-MD5 string in place of the “x”.

demouser1:{CRAM-MD5}256f~snip~816:1000:1000::/home/demouser1/

Start the service

systemctl start dovecot.service

Enable the service to start automatically

systemctl enable dovecot.service

That completes the dovecot setup.
