Migrating a Repository from an SVN Server (svn+ssh) to a Git Server

posted: 2016-08-10

git

■Prerequisites
Git is already usable on both the server and the client

(1) Create an empty repository on the Git server.
I think you can just follow the method for your particular Git server.
(Via a command, or by creating it in GitLab, etc.)

(2) Create a local Git repository that imports the SVN repository.

$ git svn clone --prefix svn/ svn+ssh://svn.sample.com/home/svn/svnhoge githoge

Replace the following as appropriate.
[svn.sample.com]　Host name (IP address) of the SVN server
[/home/svn/svnhoge]　Path of the repository to migrate
　　*The two above are the same as what you specified when using SVN
[githoge]　Directory name of the Git repository to create

(3) Once the local repository is created, link it to the Git server

$ cd githoge  
$ git remote add origin gituser@git.sample.com:git/githoge.git

Replace the following as appropriate.
[gituser]　Account used for Git
[git.sample.com]　Host name (IP address) of the Git server
[git/githoge.git]　The Git repository created in (1)

That’s it.
