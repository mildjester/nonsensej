[Mac] Terminal Setup (iTerm2 + fish + fisherman)

posted: 2017-10-12

Mac

■Environment

iTerm2 3.2.5
fish 2.7.1
fisherman 3.1.1

■Reference

fish shell を使いたい人生だった (Japanese)

These are the steps to switch your terminal shell to iTerm2 & fish.
fish comes with a fair number of handy features out of the box, so it’s a good choice if customizing zsh feels like too much work.

Installing iTerm2

Download the zip from the official site.
https://www.iterm2.com/downloads.html

Unzipping the downloaded file gives you a file called “iTerm”; drag and drop it into Applications.
You can now launch it from Launchpad.

Changing the iTerm2 Color Scheme

With iTerm2’s default colors, directories can be hard to see, so change the color scheme.
From the iTerm2 menu bar, click through
iTerm2 > Preferences > Profiles > Colors
and choose a theme you like from Color Pareset.

You can also download and use color scheme files.
I often use a scheme called “Japanesque”.
https://github.com/aereal/dotfiles/tree/master/colors/Japanesque

Opening “Japanesque.itermcolors” in iTerm2 adds
Japanesque to the Color Pareset options above.

Installing fish

Install fish.

$ brew install fish

Check the path to fish.

$ which fish  
/usr/local/bin/fish

Add the path above to the list of shells.

$ sudo vi /etc/shells  
~Append the path you checked with the which command to the end~

Change your shell to fish.

$ chsh -s /usr/local/bin/fish

Now fish will start when you restart the terminal.

Installing fisherman

fisherman is a plugin manager for fish.

The install command is listed on fisherman’s GitHub page.
https://github.com/fisherman/fisherman

$ curl -Lo ~/.config/fish/functions/fisher.fish --create-dirs https://git.io/fisher

If no version information appears after running the command above, try restarting the terminal.

Changing the fish Theme

You can change fish’s appearance by changing its theme.
The following page is a good reference for the available themes.
https://github.com/oh-my-fish/oh-my-fish/blob/master/docs/Themes.md

I use a theme called “bobthefish” and install it with the following steps.

$ fisher add oh-my-fish/theme-bobthefish  
$ git clone https://github.com/powerline/fonts.git  
$ fonts/install.sh  
$ rm -rf fonts

After running the commands above, configure the iTerm2 profile.
On the profile settings screen, click “Text > Font > Change Font”.

Select All Fonts under Collection, and choose any font named “… for Powerline”.
Personally, I like “Meslo LG M for Powerline”.
Change the font size as needed.

The theme change is now complete.

Adding Plugins

There are many plugins available;
here are the ones I use.

z

Lets you jump to directories selected from your history.
[Installation]

$ fisher add z

[Usage]
Type z {string} and press Tab.
It searches your history for directories matching {string} and moves there.
If you leave {string} empty, your recent history is shown.

bd

Makes it easy to move to parent (or ancestor) directories.
[Installation]

$ fisher add 0rax/fish-bd

[Usage]
Type $ bd and press Tab to show a list of parent directories;
just select one and press Enter to move there.

peco

Makes searching your command history easy.

[Installation]

$ brew install peco  
$ fisher add oh-my-fish/plugin-peco

After running the commands above, add the following to the fish config file.

vim ~/.config/fish/config.fish  
~Add the following (create the file if it doesn't exist)~  
function fish_user_key_bindings  
  bind \cr 'peco_select_history (commandline -b)'  
end

Note: If “function fish_user_key_bindings” is already defined,
just add the bind… line inside it.

Once done, restart the terminal.

[Usage]
Press “Ctrl + R” to open the command history search screen.
You can pick from recent commands, or type a string to narrow the history down to commands containing it.

ghq

A plugin that makes managing git repositories easier.

[Installation]

$ brew install ghq  
$ fisher add yoshiori/fish-peco_select_ghq_repository

After running the commands above, add the following to the fish config file.

vim ~/.config/fish/config.fish  
~Add the following (create the file if it doesn't exist)~  
function fish_user_key_bindings  
  bind \c] peco_select_ghq_repository  # added  
end

Note: If “function fish_user_key_bindings” is already defined,
　just add the bind… line inside it.
　For example, if you have also installed peco above, config.fish will look like this.

function fish_user_key_bindings  
  bind \cr 'peco_select_history (commandline -b)'  
  bind \c] peco_select_ghq_repository  # added  
end

Once done, restart the terminal.

[Usage]
Press “Ctrl + ]” to select a git repository managed by ghq.
Selecting a repository takes you to its directory.

I won’t cover how to use the ghq command itself, so please look it up separately.
