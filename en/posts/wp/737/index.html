[Mac] Installing NetBeans

posted: 2017-10-13

NetBeans
Mac

■Environment

macOS Sierra 10.12.6
NetBeans 8.2

With built-in code completion and FTP features,
I personally find it one of the easiest free IDEs to use.
Also, the NetBeans cat is cute.

■Downloading & Installing the JDK & NetBeans

There is a package that bundles the JDK and NetBeans, so download that.
http://www.oracle.com/technetwork/java/javase/downloads/jdk-netbeans-jsp-142931.html

[Note]
If you have already installed the JDK, you only need to download NetBeans itself from the following site.
https://netbeans.org/downloads/
When downloading from this site, you can install a package tailored to the languages you use.

Double-click the downloaded dmg file to mount it,
then double-click the pkg file inside to launch the installer.

Follow the installer and the installation is complete.
NetBeans is added to Launchpad.

■NetBeans Settings

[Basic Settings]

Click “NetBeans > Preferences” in the top menu to open the settings screen.
The tabs below are probably the only ones you’ll usually touch.
Anyone tweaking the other tabs is probably at a level that needs no explanation, so I’ll skip them.

General Tab

You can specify the browser NetBeans opens and configure proxy settings.
If you’re not sure, leave the defaults.

Editor Tab

You can specify source code formatting and configure the warnings NetBeans shows.
Whether to indent with tabs or spaces, how deep indentation can go before a warning, and so on.
Change them to suit your preferences or your team’s coding conventions.
For items you don’t understand, the defaults should be fine.

Fonts & Colors Tab

As the name says, you can configure the fonts and colors used in NetBeans.
Change any colors that are hard to read.

Keymap Tab

Shortcut key settings. Basically, the defaults should be fine.
It’s worth looking through it once to see what shortcuts are available.

Appearance Tab

General settings for how the IDE looks.
You can change the theme under “Look and Feel”, so change it if there’s a theme you like.
* Changes to Look and Feel require restarting the IDE.

[Installing Plugins]

Install plugins for the languages you want to use.
Click “Tools > Plugins” in the NetBeans top menu to open the plugin manager.

You can install new plugins from the “Available Plugins” tab.

If You Like Dark Themes

There is a plugin called “Dark Look And Feel Themes”.
Installing it adds more choices to “Look and Feel” in the basic settings,
so change it from the settings screen.
Personally, I like “Dark Nimbus”.

If You Use PHP

If you develop in PHP, the “PHP” plugin is a must.
There are also helper plugins for frameworks and testing tools, so install those as needed.
