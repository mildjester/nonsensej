[Linux Mint] Changing the Keymap

posted: 2018-04-13

LinuxMint

■Environment

Linux Mint 18.3 cinnamon 64bit

Xmodmap Settings

Create a file called .Xmodmap directly under your home directory and write the settings in it.

[Contents of .Xmodmap]

Disabling Middle-Click Paste

With a ThinkPad keyboard, I often move the pointer while holding the middle button,
and it annoyingly pastes things now and then, so I disable it.

Add the following to .Xmodmap.

pointer = 1 9 3 4 5 6 7 8 2 10

Turning PageUp & PageDown into Shift

I don’t use PageUp & PageDown, and hitting them by accident scrolls the screen,
so I turn them into Shift.

Add the following to .Xmodmap.

keycode 112 = Shift_R  
keycode 117 = Shift_R  
add Shift = Shift_R

Turning Caps Lock into Ctrl

I don’t use Caps Lock either, and hitting it by accident switches to uppercase,
so I turn it into Ctrl.

Add the following to .Xmodmap.

remove Lock = Caps_Lock  
keysym Caps_Lock = Control_L  
add Control = Control_L

[Applying .Xmodmap]

After writing .Xmodmap, apply it with the following command.

$ xmodmap ~/.Xmodmap

However, typing this command at every login is tedious,
so set it to run automatically.

(1) First, create a shell script of your choice containing xmodmap ~/.Xmodmap. Don’t forget to make it executable.
(2) Open “System Settings > Startup Applications”.
(It may be labeled differently depending on your language settings.)
(3) Add a “Custom Command” and select the shell script created in (1).

Making Hankaku/Zenkaku Switching Mac-like

The “Hankaku/Zenkaku” key on a standard Japanese keyboard is a toggle,
so it’s hard to use when you can’t tell whether you’re currently in half-width (direct) or full-width (Japanese) input.

So I assign the following rarely used keys Mac-style:
Muhenkan key: switch to half-width input
Henkan key: switch to full-width input
Katakana/Hiragana key: I hit it by accident, so this also switches to full-width input

First, open “Mozc Settings” from the menu.

Next, click “Edit” under Keymap in the General tab.

The list of key settings is displayed. Change them as follows and click OK.
Hiragana: Activate IME
Henkan: Activate IME
Katakana: Activate IME
Muhenkan: Deactivate IME
* There are multiple entries, one per mode

Now it behaves like a Mac.
