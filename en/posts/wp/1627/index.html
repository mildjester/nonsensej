Placing Multiple reCAPTCHA Buttons in the Same Form

posted: 2018-10-26

javascript

This is how to place multiple submit buttons in a reCAPTCHA-enabled form on a web page.
It assumes you verify by extracting g-recaptcha-response from the POST data.

If you simply place multiple submit buttons, it doesn’t work properly.
For example, if you create a form like this:

<script>  
function mySubmit(){  
  document.getElementById("myForm").submit();  
}  
</script>  
  
<form id="myForm" action="/hoge">  
  <button class="g-recaptcha" data-sitekey="各自のサイトキー" data-callback="mySubmit">送信1</button>  
  〜いろいろ〜  
  <button class="g-recaptcha" data-sitekey="各自のサイトキー" data-callback="mySubmit">送信2</button>  
</form>

A reCAPTCHA element like the following is generated right above the 送信1 (Submit 1) button.

<div>  
  <div class="grecaptcha-badge" 〜略〜 >  
    <div class="grecaptcha-logo">  
      <iframe src="https://www.google.com/recaptcha/〜略〜 ></iframe>  
    </div>  
    <div class="grecaptcha-error"></div>  
    <textarea id="g-recaptcha-response" name="g-recaptcha-response" 〜略〜 ></textarea>  
  </div>  
</div>

A similar element is also generated right above the 送信2 (Submit 2) button.
The differences from the Submit 1 element are the iframe contents and the textarea id.
It seems the textarea id gets a sequential number appended as the number of buttons increases.

<div>  
    <div class="grecaptcha-badge" 〜略〜 >  
        <div class="grecaptcha-logo">  
            <iframe src="https://www.google.com/recaptcha/〜略〜 ></iframe>  
        </div>  
        <div class="grecaptcha-error"></div>  
        <textarea id="g-recaptcha-response-1" name="g-recaptcha-response" 〜略〜 ></textarea>  
    </div>  
</div>

As is, the POST data contains parameters with the same name, so it doesn’t work correctly.

So we delete the reCAPTCHA element tied to the button that wasn’t clicked.
Specifically, the code looks like this:

<script>  
function mySubmit(delId){  
  document.getElementById(delId).parentNode.remove()  
  document.getElementById("myForm").submit();  
}  
function mySubmit1() {  
  mySubmit("g-recaptcha-response-1")  
}  
function mySubmit2() {  
  mySubmit("g-recaptcha-response")  
}  
</script>  
  
<form id="myForm" action="/hoge">  
  <button class="g-recaptcha" data-sitekey="各自のサイトキー" data-callback="mySubmit1">送信1</button>  
  〜いろいろ〜  
  <button class="g-recaptcha" data-sitekey="各自のサイトキー" data-callback="mySubmit2">送信2</button>  
</form>

Now the reCAPTCHA parameter is no longer duplicated in the POST data,
so verification works correctly.
