PHPExcel Usage Notes

posted: 2017-02-07

PHP

Notes on using “PHPExcel”, which can generate Excel files in PHP
* These are just notes on what I actually used, so they don’t cover all features.

To install, either use composer or download the archive and
extract it to a directory of your choice.
Then just require the following.
/path/where/you/put/it/PHPExcel/Classes/PHPExcel.php
/path/where/you/put/it/PHPExcel/Classes/PHPExcel/IOFactory.php

The actual source code is as follows

/**  
 * Create a new PHPExcel object  
 */  
$excel = new PHPExcel();  
  
/**  
 * Create a sheet and change its name  
 */  
$sheetIndex = 0; // Sheet numbers start at 0  
$excel->setActiveSheetIndex($sheetIndex);  
$sheet = $excel->getActiveSheet();  
$sheet->setTitle('SampleSheet01');  
  
/**  
 * Enter data into cells  
 */  
// Basic input  
$rowCnt = 1; // Row numbers start at 1  
$clmCnt = 0; // Column numbers start at 0  
$text = 'セルに書き込む内容だよ';  
$sheet->setCellValueByColumnAndRow($clmCnt, $rowCnt, $val);  
  
// Input as a string  
$rowCnt++; // Move down one row  
$clmCnt++; // Move right one column  
$text = '000001'; // Unless typed as a string, this becomes "1" instead of "00001"  
$sheet->setCellValueExplicitByColumnAndRow($clmCnt, $rowCnt, $val, PHPExcel_Cell_DataType::TYPE_STRING);  
  
/**  
 * Cell formatting  
 */  
// Set the sheet's default font  
$sheet->getDefaultStyle()->getFont()->setName('ＭＳ Ｐゴシック')->setSize(11);  
  
// Set the background color  
$bgcolor = '000000'; // Specify in hex  
$sheet->getStyleByColumnAndRow($clmCnt, $rowCnt)->getFill()->setFillType(PHPExcel_Style_Fill::FILL_SOLID);  
$sheet->getStyleByColumnAndRow($clmCnt, $rowCnt)->getFill()->getStartColor()->setRGB($bgcolor);  
  
// Set the font color  
$fontcolor = 'FFFFFF'; // Specify in hex  
$sheet->getStyleByColumnAndRow($clmCnt, $rowCnt)->getFont()->getColor()->setARGB($fontcolor);  
  
// Make it bold  
$sheet->getStyleByColumnAndRow($clmCnt, $rowCnt)->getFont()->setBold(true);  
  
// Draw a border (double line) only on top of a cell (specified by row/column number)  
$sheet->getStyleByColumnAndRow($clmCnt, $rowCnt)->getBorders()->getTop()->setBorderStyle(PHPExcel_Style_Border::BORDER_DOUBLE);  
// Draw borders (single line) all around cells (specified by range)  
$sheet->getStyle('A1:B3')->getBorders()->getAllBorders()->setBorderStyle(PHPExcel_Style_Border::BORDER_THIN);  
  
  
// Set the column width  
$sheet->getColumnDimension('A')->setWidth(14.5);  
// Auto-size the column width (* this should work, but it often doesn't)  
$sheet->getColumnDimension( PHPExcel_Cell::stringFromColumnIndex($clmCnt))->setAutoSize(true);

That’s all
