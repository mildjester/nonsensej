Cisco IOS Switch Cheat Sheet

posted: 2017-05-02

Cisco

Enter privileged mode

enable

*Can be abbreviated as en

View the current configuration

# show interfaces      *to view all  
# show interfaces GigabitEthernet0/X  *to view a specific interface only  
# show vlan

*“GigabitEthernet0/X” can be abbreviated as “Gi0/X”

Enter configuration mode

# configure terminal

*Can be abbreviated as conf terminal

(In configuration mode) Disable Smart Install

(config)# no vstack

(In configuration mode) Change the privileged mode password

(config)# enable password {new password}

(In configuration mode) Enter interface configuration mode

(config)# interface GigabitEthernet0/X

(In interface configuration mode) Shut down / bring up

(config-if)# shutdown  
(config-if)# no shutdown

(In interface configuration mode) Switch VLAN

(config-if)# switchport mode access  
(config-if)# switchport access vlan {vlan number}

Exit each mode

(any mode)# exit

Save the configuration

# write memory

*If you don’t run this at the end, your settings will be reverted after a reboot.
