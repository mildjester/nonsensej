[Mac] Setting Up fish + oh-my-fish + peco

posted: 2017-04-20

Mac

Environment

OS X ElCapitan 10.11.6

Installing fish

Install fish with brew.

brew install fish

*For installing brew itself, see this post.

Next, add fish to the list of shells.

vim /etc/shells  
# Add the following line  
/usr/local/bin/fish

Next, set fish as your default shell.

chsh -s /usr/local/bin/fish

Installing oh-my-fish

Just run the following command.

curl -L http://get.oh-my.fish | fish

Installing peco

peco can be installed with brew and the omf command.

brew install peco  
omf install peco

Once installed, add the peco settings to the fish config file.
If the fish config file doesn’t exist, create it.

vim ~/.config/fish/config.fish  
# Add the following lines  
function fish_user_key_bindings  
    bind \cr peco_select_history  
end

That completes the setup.
