Building a Mail Server (Part 1 - postfix)

posted: 2015-08-06

CentOS

■Environment
CentOS 7
postfix 2.10.1

Mail accounts use the accounts registered in passwd.
Create mail-only accounts with the following command. (SSH login disabled)

useradd -s /sbin/nologin demouser1

Install what’s needed

yum -y install postfix cyrus-sasl cyrus-sasl-plain cyrus-sasl-md5

Edit the main configuration file (vi /etc/postfix/main.cf)
Changed settings below

myhostname = mail.sample.com  
mydomain = sample.com  
myorigin = $mydomain  
inet_interfaces = all  
mynetworks = 192.168.0.0/23, 127.0.0.0/8  
relay_domains = $mydestination  
home_mailbox = Maildir/  
smtpd_banner = $myhostname ESMTP unknown

Added settings below
*The SSL certificate’s private key is assumed to have no password

smtpd_sasl_auth_enable = yes  
smtpd_sasl_security_options = noanonymous  
smtpd_recipient_restrictions =   
    permit_mynetworks,  
    permit_sasl_authenticated,  
    reject_unauth_destination  
smtpd_tls_cert_file = /etc/pki/sample/sample.crt  
smtpd_tls_key_file = /etc/pki/sample/sample.key  
smtpd_tls_CAfile = /etc/pki/sample/sampleCA.crt  
smtpd_tls_loglevel = 1  
smtpd_use_tls = yes

Edit the master configuration file (vi /etc/postfix/master.cf)
Changed settings below

submission inet n       -       n       -       -       smtpd  
  -o syslog_name=postfix/submission  
  -o smtpd_sasl_auth_enable=yes  
  -o smtpd_client_restrictions=$mua_client_restrictions  
  -o milter_macro_daemon_name=ORIGINATING  
smtps     inet  n       -       n       -       -       smtpd  
  -o smtpd_tls_wrappermode=yes

Edit the SASL authentication configuration file (vi /etc/sasl2/smtpd.conf)
Changed settings below

mech_list: plain login cram-md5 digest-md5

Add an account to the SASL authentication file
You’ll be asked for the password to set when running the following command; enter it

saslpasswd2 -c -u sample.com demouser1

##################### Reference #####################
To check users registered in the SASL authentication file, use the following command

sasldblistusers2

To delete a user registered in the SASL authentication file, use the following command

saslpasswd2 -d -u sample.com demouser1

Change the group of the SASL authentication file to postfix

chgrp postfix /etc/sasldb2

Start the services

systemctl start postfix.service  
systemctl start saslauthd.service

Enable the services to start automatically

systemctl enable postfix.service  
systemctl enable saslauthd.service

That completes the postfix setup.
