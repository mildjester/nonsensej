Installing Zabbix 3.2 on CentOS 7.3

posted: 2017-02-14

CentOS
zabbix

■Environment

CentOS 7.3
zabbix 3.2
PHP 7.1
MySQL 14.14
Apache 2.4

(1) Install the repository for installing zabbix with yum

# yum install http://repo.zabbix.com/zabbix/3.2/rhel/7/x86_64/zabbix-release-3.2-1.el7.noarch.rpm

(2) Install zabbix itself

# yum install \  
zabbix-server-mysql \  
zabbix-web-mysql \  
zabbix-web \  
zabbix-agent \  
zabbix-get \  
zabbix-sender \  
zabbix-web-japanese

*If you use PostgreSQL instead of MySQL, just change “mysql” above to “pgsql”.

(3) Configure MySQL

# mysql  
mysql> CREATE USER 'zabbix'@'localhost' IDENTIFIED BY 'zabbixpassword';  
mysql> CREATE DATABASE zabbix CHARACTER SET utf8;  
mysql> GRANT ALL ON zabbix.* to 'zabbix'@'localhost';  
mysql> quit  
# zcat /usr/share/doc/zabbix-server-mysql-3.2.1/create.sql.gz | mysql -uroot zabbix

Use any password you like.
You can also change the DB name and user name if you want.

(4) Configure Zabbix

# vim /etc/zabbix/zabbix_server.conf  
Set the following items  
LogFileSize=10  
DBPassword=zabbixpassword

If you changed the DB name and user name in step (3), update the corresponding settings here as well.

(5) Start the services

# systemctl start zabbix-server  
# systemctl start zabbix-agent  
# systemctl restart httpd

The installation is now complete.
Access https://hostname/zabbix to open zabbix and begin the initial setup.
The initial login ID/PASS is “Admin/zabbix”.

After logging in, you can change the language and password from the person icon in the upper right.

When I did this, the following PHP warning appeared on the dashboard.
“A non well formed numeric value encountered”
