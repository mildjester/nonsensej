(2) Installing zsh + prezto

Installing prezto basically follows the official instructions.
https://github.com/sorin-ionescu/prezto

First, switch the shell to zsh. On a Mac, zsh should already be installed.

zsh

Next, download the source from GitHub.

git clone --recursive https://github.com/sorin-ionescu/prezto.git "${ZDOTDIR:-$HOME}/.zprezto"

Next, configure zsh to use prezto.
Paste the following into the terminal and run it. (No need to create a script file; pasting directly into the terminal is fine.)

setopt EXTENDED_GLOB  
for rcfile in "${ZDOTDIR:-$HOME}"/.zprezto/runcoms/^README.md(.N); do  
  ln -s "$rcfile" "${ZDOTDIR:-$HOME}/.${rcfile:t}"  
done

Finally, make zsh your default shell.

chsh -s /bin/zsh

Restart the terminal and you’re on zsh + prezto.

(3) Making Command History Easier to Search with peco

First, install peco.

brew install peco

Then just add the following to .zshrc.

function peco-history-selection() {  
    BUFFER=`history -n 1 | tail -r  | awk '!a[$0]++' | peco`  
    CURSOR=$#BUFFER  
    zle reset-prompt  
}  
zle -N peco-history-selection  
bindkey '^R' peco-history-selection

It takes effect after restarting the terminal or reloading zshrc with the following command.
Ctrl+R opens the history search screen.

source .zshrc
