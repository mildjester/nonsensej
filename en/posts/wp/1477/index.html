Running Unit Tests on Pull Requests with CircleCI

posted: 2018-08-14

CircleCI
git

Use CircleCI to run unit tests
when a pull request is opened on GitHub.

This assumes the source code is PHP and the unit tests use phpunit.

Signing Up for Circle CI

Go to the Circle CI homepage and click Sign Up in the upper right.

It looks like you can log in with a GitHub or Bitbucket account.
This time I logged in with my GitHub account.

You’ll be asked whether to allow the integration, so click Authorize circleci.

Creating a Project in Circle CI

Once your account is created, click Add Projects to create a project.

Click Set Up Project for the repository you want to link.

Configure the environment of the target repository.
Click the one that applies.

Scroll down to see the next steps.

First, create .circleci/config.yml in the repository.
For now, the content of config.yml is what I copied with Copy To Clipboard (as of 2018/8/11),
with the following changes.
(1) Change the Docker image
Change the Docker image to one close to your server’s environment.
Check Docker Hub for details on which images are available.
https://hub.docker.com/r/circleci/
(Apparently it also works with images other than the official circleci ones if there’s another Docker image you want to use.)

Note that circleci/php:7.1.5-browsers, written in the sample config.yml, does not exist.
If you run the sample as is, you get the following error.

Error response from daemon: manifest for circleci/php:7.1.5-browsers not found

(2) Change the phpunit command
If you installed phpunit via composer or similar, the command will be different, so change it.

Here is the resulting config.yml

# PHP CircleCI 2.0 configuration file  
#  
# Check https://circleci.com/docs/2.0/language-php/ for more details  
#  
version: 2  
jobs:  
  build:  
    docker:  
      # specify the version you desire here  
      #- image: circleci/php:7.1.5-browsers  
      - image: circleci/php:7.1-fpm-node-browsers  
  
      # Specify service dependencies here if necessary  
      # CircleCI maintains a library of pre-built images  
      # documented at https://circleci.com/docs/2.0/circleci-images/  
      # - image: circleci/mysql:9.4  
  
    working_directory: ~/repo  
  
    steps:  
      - checkout  
  
      # Download and cache dependencies  
      - restore_cache:  
          keys:  
          - v1-dependencies-{{ checksum "composer.json" }}  
          # fallback to using the latest cache if no exact match is found  
          - v1-dependencies-  
  
      - run: composer install -n --prefer-dist  
  
      - save_cache:  
          paths:  
            - ./vendor  
          key: v1-dependencies-{{ checksum "composer.json" }}  
  
      # run tests!  
      #- run: phpunit  
      - run: vendor/phpunit/phpunit/phpunit tests/

Push the config.yml you created to the master branch,
then click “Start building” on the Circle CI screen from earlier.
Registration is now complete.

From now on, when you open a pull request on the repository, the phpunit tests run automatically.
Also, by default, CircleCI results are sent to the email address you registered with CircleCI.
