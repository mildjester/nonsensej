Fixing mysql Functions That Error in PHP 7

posted: 2016-01-20

PHP
MySQL

When I updated from PHP 5.X to PHP 7, the mysql functions were throwing errors,
so here are notes on what I did to fix them.

  • Change function names from “mysql_xxxx()” to “mysqli_xxxx()”.
  • If a function’s arguments are “1st argument: value” and “2nd argument: mysql object”,
    reverse the order. (Make the mysql object the 1st argument)
    *The mysql object here means the return value of “mysqli_connect”.
  • Pass the mysql object as the argument to mysqli_error().
    Beyond this, functions that needed no arguments as “mysql_xxxxx()” may require
    the mysql object as an argument as “mysqli_xxxxx()”.
