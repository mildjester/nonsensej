Installing CentOS 7 on an HP ProLiant MicroServer Gen8

posted: 2016-12-01

CentOS

■Work Environment

・OS X El Capitan 10.11.6

 

■Steps

Preparing CentOS 7

First, download the CentOS ISO image.
Download the “Everything ISO” from here.
https://www.centos.org/download/

Write the downloaded ISO to a USB drive as a bootable USB.

  1. Insert the USB drive into the Mac.
  2. Check the disk number of the USB drive with the following command.
$ diskutil list
  1. Initialize the USB drive with the following command.
$ diskutil eraseDisk MS-DOS NOTITLE /dev/diskX  
\* "NOTITLE" is the name of the USB drive to create (any name)  
\* diskX is the disk number checked in step 1.
  1. Unmount the USB drive for writing.
$ diskutil unmountDisk /dev/diskX
  1. Write the ISO.
$ cd {location of the CentOS ISO}  
$ sudo dd if=CentOS-7-x86_64-Everything-1511.iso of=/dev/diskX bs=4028  
\* This takes quite a while to complete
  1. Make the USB drive safe to remove.
$ diskutil eject /dev/diskX

Preparing the RAID Controller

Next, download the RAID controller driver for the Gen8.
Without it, you can’t use the RAID feature built into the HP server.
http://downloads.linux.hpe.com/SDR/repo/spp/RedHat/7/x86_64/current/
Download “hpvsa-1.2.14-113.rhel7u2.x86_64.dd.gz” from here.
*Adjust the “rhel7u2” part to match the CentOS version you’re installing.

After downloading, write it to a separate USB drive from the one with CentOS.
The Mac automatically mounts a USB drive when inserted, so unmount it from Disk Utility
and run the following commands.
(First initialize and unmount the USB drive using the same steps as for the ISO.)

$ cd {location where you downloaded the RAID driver}  
$ gunzip hpvsa-1.2.14-113.rhel7u2.x86_64.dd.gz  
$ sudo dd if=hpvsa-1.2.14-113.rhel7u2.x86_64.dd of=/dev/diskX  
$ diskutil eject /dev/diskX

Running the Installation

Insert both USB drives into the server and boot it.
(Configure the BIOS beforehand to allow booting from USB.)

After a while, the CentOS text appears along with a screen for choosing the installation method.
Press Esc here to get a “boot:” prompt, and enter the following.

linux modprobe.blacklist=ahci inst.dd

As the installation proceeds, a screen for selecting the disk containing the driver appears.
First enter r to reload the disk list, then enter the number of the corresponding disk.

Next, a list of drivers is displayed and you’re asked to choose which to install,
so enter the number of the corresponding driver.
Then enter c to continue.

Finally, the disk list is displayed again; remove the USB drive containing the RAID controller driver
and enter r.
The USB drive with the RAID controller driver should disappear, and the USB with the ISO should appear at the top,
so just enter c to continue.

The rest is a normal installation.
Answer the questions displayed and you’re done.
