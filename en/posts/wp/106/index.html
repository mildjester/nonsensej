sshd Settings on CentOS 7 (Security)

posted: 2015-10-19

CentOS

For ssh login to the server, we’ll configure the following:

  • Change the ssh port
  • Disable root login
  • Restrict which accounts can su to root

■Environment
CentOS 7.1.1503
Openssh 6.6.1

The following settings change the port number and disable root login.
Modify the following lines (add them if they don’t exist).

(/etc/ssh/sshd_config)

Port 1234　*any number  
PermitRootLogin no

Create an account in the “wheel” group.

# useradd testuser　*any account (not needed if using an existing account)  
# usermod -g wheel -G wheel testuser

The following setting limits the group that can su to root to “wheel”.
Modify the following line (add it if it doesn’t exist).

(/etc/pam.d/su)

auth            required        pam_wheel.so use_uid

That completes the configuration, but before closing the terminal you used, open a new terminal
and confirm that you can ssh in and su with the account you added to the wheel group.
If you close the configuring terminal before confirming and the configuration failed, in the worst case you won’t be able to get root privileges.
