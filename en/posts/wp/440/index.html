Installing fish on CentOS 7

posted: 2017-02-17

CentOS

I tried installing fish, which seems to be popular lately.

■Environment

CentOS 7.3
fish 2.3.1

If you don’t have the epel repository, install it.

yum -y install epel-release

Install fish with yum.

yum -y install fish

To use fish just for now, simply type fish as a command.

fish

To use fish permanently, run chsh.

chsh -s /usr/bin/fish　｛ユーザ名｝

 

Now fish is ready to use.

〜Reference〜

On CentOS 6.x, you can apparently install fish as follows.

wget -P /etc/yum.repos.d/ http://download.opensuse.org/repositories/shells:fish:release:2/CentOS_6/shells:fish:release:2.repo  
yum -y install fish

[Installing oh-my-fish]

While I’m at it, I’ll install oh-my-fish too.
The git version installable via yum on CentOS 7 is 1.8.x (as of April 2017),
but oh-my-fish requires git 1.9.5 or later,
so I’ll compile it from source.

Install what’s needed to compile from source.
In my environment it was the following, but install whatever your environment needs.
You should be able to find it by looking up how to compile git from source.

yum install curl-devel expat-devel gettext-devel  openssl-devel zlib-devel perl-ExtUtils-MakeMaker autoconf gettext gcc

Download the source code

cd /tmp/  
wget https://www.kernel.org/pub/software/scm/git/git-2.9.3.tar.gz  
tar xzf git-2.9.3.tar.gz

*Check the latest source here
https://www.kernel.org/pub/software/scm/git/

Install git.
Without the configure option “–with-curl”, the oh-my-fish installation will fail.

cd git-2.9.3  
make configure  
./configure --with-curl  
make  
make install

The git commands are placed under “/usr/local/bin”,
so add it to your PATH if it isn’t already.

set -U fish_user_paths $fish_user_paths /usr/local/bin  
git --version  
git version 2.9.3

Finally, install oh-my-fish and you’re done.

curl -L https://get.oh-my.fish | fish

For details on installing oh-my-fish, see here.
https://github.com/oh-my-fish/oh-my-fish

[Installing peco]

While I’m at it, I’ll install peco too.

Download the peco binary from GitHub and make it available.

cd /tmp/  
wget https://github.com/peco/peco/releases/download/v0.5.1/peco_linux_amd64.tar.gz  
tar xzf peco_linux_amd64.tar.gz  
mv peco_linux_amd64/peco /usr/local/bin/.

Load peco into fish with oh-my-fish.

omf install peco

Finally, edit the fish config file.

vim ~/.config/fish/config.fish  
# Content to add  
function fish_user_key_bindings  
    bind \cr peco_select_history  
end

That completes the setup.
