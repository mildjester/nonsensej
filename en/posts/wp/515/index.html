How to Install Composer

posted: 2017-04-11

Mac
Composer

■Environment

macOS Sierra 10.12.4
CentOS 6.8

I installed Composer on my work Mac and a CentOS server, so here are my notes.

[Mac]

You can install it with brew.

brew install homebrew/php/composer

※※※※※※※※※※※※※※※※※※※※※※※※※※※※※
Added December 2018
The command above now produces an error.
It can now be installed with the following command

brew install composer

※※※※※※※※※※※※※※※※※※※※※※※※※※※※※

[CentOS]

Fetch the installer with CURL and move the generated executable to a directory on your PATH.

curl -sS https://getcomposer.org/installer | php  
mv composer.phar /usr/bin/composer

That’s all
