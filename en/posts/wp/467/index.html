[Corporate] Notes on Filing Local Taxes with eLTAX

posted: 2017-03-10

法人事務

I filed the final local tax return for my (dormant) corporation using eLTAX, so here are the steps.
Even if your corporation isn’t dormant, the steps should be mostly the same.
*For e-Tax (national taxes), see here

■What You Need

・Windows PC
・IC card reader
・PDFs of the documents to attach to the tax return, such as financial statements

■Steps

(1) Register for eLTAX

Register for eLTAX by following this page.
http://www.eltax.jp/www/contents/1398146092894/index.html (Japanese)
The electronic certificate doesn’t have to be the corporation’s; the representative’s personal one is fine.
The My Number card includes an electronic certificate, so using that is probably the quickest.

Note that the “local government” you select on the submission destination screen is the prefecture, not the city/ward/town/village.

(2) Download the eLTAX Software

You can download the eLTAX software “PCdesk” from the site in step (1),
so download and install it.

(3) Set a PIN in PCdesk

After launching PCdesk, first go to “1: User Information Menu > User Information”
and change the PIN.

(4) Create the Tax Return in PCdesk

Create the return via “3: Create Filing Data > Create New Filing Data”.
The filing type is “Final return”, and the only document to create is the “Interim/Final Return”.

You can attach documents from “Forms/Attachments List” in the menu at the bottom of the return creation screen,
so also attach the full set of financial statements you sent via e-Tax.

(4) Send the Tax Return from PCdesk

Sign it via “3: Create Filing Data Menu > Sign Filing Data”,
and send it via “3: Create Filing Data Menu > Send Filing Data”.

That completes filing with eLTAX.
