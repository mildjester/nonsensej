[Ubuntu] Changing Home Directory Names from Japanese to English

posted: 2015-08-27

ubuntu

When you install the Japanese edition of Ubuntu, the directory names in your home directory are in Japanese.
Japanese names are inconvenient when working on the command line, so change them to English.
e.g.) 音楽 -> Music

Open a terminal and run the following command.

LANG=C xdg-user-dirs-gtk-update

A confirmation dialog appears; press the “Update Names” button.
The directory names are now in English.

After restarting the PC, a confirmation dialog appears again,
so check “Don’t ask me this again” and press “Keep Old Names”.
From now on, the directory names stay in English after restarts.
