[PHP] Adding Custom Validation in Laravel 5

posted: 2017-04-11

PHP
Laravel

■Environment

Laravel 5.1

These are the steps I took to add custom validation in Laravel 5.

First, create a service provider. This time I’ll name it “ValidatorServiceProvider”.
Running the following command generates “/app/providers/ValidatorServiceProvider.php”.

php artisan make:provider ValidatorServiceProvider

Add the created service provider to “/config/app.php”.

    "providers" => [  
〜〜　省略　〜〜  
        App\Providers\ValidatorServiceProvider::class,  
〜〜　省略　〜〜  
    ],

Write the validation rule in the created service provider.
For example, suppose employee numbers follow these rules:
・The first character is “A” or “Z”
・The second character onward is a 6-digit number

Registering this validation rule under the name “shainbangou” looks like this.

namespace App\Providers;  
  
use Illuminate\Support\ServiceProvider;  
use Validator;  
  
class ValidatorServiceProvider extends ServiceProvider  
{  
    public function boot()  
    {  
        Validator::extend('shainbangou', function($attr, $value, $param) {  
            return preg_match('/^[A|Z][0-9]{6}$/', $value);  
        });  
    }  
}

Next, set the error message.
Assume the employee number is set in the view with the variable name empId.
[/resources/lang/ja/validation.php]

return [  
〜〜　省略　〜〜  
    'custom' => [  
        'empId' => [  
            'shainbangou' => '社員番号が間違っています。（A/Z + 数字6桁）.',  
        ],  
    ],  
〜〜　省略　〜〜  
    'attributes' => [  
        'empId' => '社員番号',  
    ],  
];

Now the new rule “shainbangou” can be used in validation in controllers and elsewhere.
