Installing a Group Management Plugin on Redmine 2.3.2

posted: 2017-02-27

ruby

I installed a group management plugin on Redmine, but it didn’t work properly,
so here are notes on where I got stuck.
*Note
I’m a PHP developer who knows nothing about Ruby on Rails and made some quick fixes,
so this may look odd to Rails experts. I’d appreciate any corrections.

■Environment
CentOS 6.5
Redmine 2.3.2
ruby 2.0.0
rails 3.2.13

https://github.com/fathomssen/redmine_group_manager
Basic installation follows README.rdoc.

(1) The ORDER BY clause is wrong

It raised an error saying the order clause was invalid, so I fixed line 9 of app/models/gmanager.rb.
[Before]

mem = Member.where(:project_id => pid).order(user_id: :asc)

[After]

mem = Member.where(:project_id => pid).order("user_id asc")

(2) It doesn’t work if any group has no owner

Right after installation, no group has an owner assigned,
and apparently when no owner is set, the user with ID=1 in the users table becomes the owner.
(See line 28 of app/helpers/gmanagers_helper.rb.)

In my environment the user with ID=1 had already been deleted,
so I created a new user with ID=1 to act as the ultimate administrator.
If you already have an ultimate administrator with a different ID, modifying the helper above should also work.
(I don’t recommend using an individual’s ID, since it causes trouble when that person leaves.)

(3) The group edit tab only appears for Redmine administrators

A group edit tab is supposed to appear on each project page,
but right after installing the plugin, the tab was only shown to Redmine administrators.
If you want project managers to use the group edit feature, you need to grant the group edit permission beforehand
via “Administration > Roles and permissions” in the Redmine admin menu.
It may be written in the docs if you read carefully, but English is hard for me so I only skimmed. Sorry.

(4) Columns in the group member list are in the wrong order

When displaying the group member list from each project’s group edit tab,
the order of custom field names and values didn’t match.
So I added sorting to make them match.

Apply the same fix to lines 34 and 48 of app/models/gmanager.rb.
[Before]

keys = CustomField.where(:type => 'UserCustomField')

[After]

keys = CustomField.where(:type => 'UserCustomField').order(:id)

Also fix line 49 of app/models/gmanager.rb.
[Before]

values = User.find(id).custom_values

[After]

values = User.find(id).custom_values.order(:custom_field_id)

Now it works.

- Bonus -

This plugin can only add people who belong to a project to a group.
I wanted to be able to add users who don’t belong to the project as well,
so I modified the plugin substantially.

The plugin modified to allow adding members who don’t belong to the project
is here.
https://github.com/mildjester/redmine_group_manager
