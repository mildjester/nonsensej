Building a Local Test Environment for CakePHP2

posted: 2018-06-10

PHP
CakePHP

Environment

CakePHP 2.10.10

Belatedly, there was a chance I’d use CakePHP2 at work,
so I built a local environment to study it.

The environment uses Docker, with the following three containers.

  • nginx
  • php-fpm
  • MySQL

[Reference] The finished result is here
https://github.com/mildjester/my-training-cakephp

CakePHP’s documentation is published under the name “Book”,
so I’ll proceed using it as a reference.
(CakePHP uses cooking-themed names throughout, so is it a recipe book?)
https://book.cakephp.org/2.0/ja/index.html (Japanese)

Installing CakePHP

According to the Book, CakePHP2 can be downloaded from the official site,
but the current official site had no link that looked downloadable.
So I downloaded it from GitHub.
When I checked, the latest 2.x version was “2.10.10”, so I downloaded that archive.
https://github.com/cakephp/cakephp/tags

Extracting the downloaded archive gives you the basic CakePHP2 structure.
Put this into the Docker environment so it runs there.
For the Docker environment, see here.
https://github.com/mildjester/my-training-cakephp/tree/master/docker

Starting Docker in this state displays the CakePHP initial screen.

Initial Setup

The initial screen above shows various warnings and such,
so let’s address them.

Database Configuration

There is a file named /app/Config/database.php.default; copy it into the same directory as database.php.
The copied file contains the database settings, so fill in the information for the DB you are building.
Also create the DB and user in MySQL to match the DB information you enter here.
(MySQL operations are omitted.)

Modifying Core

/app/Config/core.php sets the security-related Salt and CipherSeed.
Leaving them at their defaults is not good, so change them.

Configure::write('Security.salt', 'DYhG93b0qyJfIxfs2guVoUubWwvniR2G0FgaC9mi'); // Use any alphanumeric characters  
Configure::write('Security.cipherSeed', '76859309657453542496749683645'); // Use any digits

DebugKit Setup

There is a DebugKit for CakePHP, so install it.
https://github.com/cakephp/debug_kit/tree/2.2

First, install it with Composer and move the generated plugin under /app/Plugin.

composer require cakephp/debug_kit "^2.2.0"  
mv Plugin/DebugKit app/Plugin/.

If you don’t have Composer locally, you can run it inside the php-fpm Docker container instead.
With the Docker environment in this example, you can enter the container with the following command.

docker-compose -f cakedock/docker-compose.yml exec --user=www-data workspace sh  
# Alternatively, the above command is wrapped in a Makefile, so you can also enter with the following command  
make workspace

Next, around line 69 of /app/Config/bootstrap.php there is a place to write plugin loading settings,
so add the setting to load DebugKit there.

CakePlugin::load('DebugKit');

With this done, the warnings on the initial screen should all be green.

From here, proceed with your own development.
