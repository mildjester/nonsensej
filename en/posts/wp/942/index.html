[CentOS] Building a VPN Server with OpenVPN & LDAP

posted: 2017-12-20

CentOS

Environment

CentOS 7.4
OpenVPN 2.4.4

Reference sites

ServerWorld: https://www.server-world.info/query?os=CentOS_7&p=openvpn (Japanese)
cloudpack: https://cloudpack.media/73 (Japanese)

*Prerequisites

The LDAP server is assumed to be already set up

Server-side steps

■Installation

Install the required packages.

yum --enablerepo=epel install openvpn openvpn-auth-ldap easy-rsa net-tools bridge-utils

■Generating certificates

Move to the easy-rsa directory and generate the certificates.

cd /usr/share/easy-rsa/2.0

CA certificate

First, edit the vars file.

vim vars

The contents are as follows. (Comment lines and blank lines are omitted)

export EASY_RSA="`pwd`"  
export OPENSSL="openssl"  
export PKCS11TOOL="pkcs11-tool"  
export GREP="grep"  
export KEY_CONFIG=`$EASY_RSA/whichopensslcnf $EASY_RSA`  
export KEY_DIR="$EASY_RSA/keys"  
export PKCS11_MODULE_PATH="dummy"  
export PKCS11_PIN="dummy"  
export KEY_SIZE=2048  
export CA_EXPIRE=3650  
export KEY_EXPIRE=3650  
export KEY_COUNTRY="JP"         #Country  
export KEY_PROVINCE="Tokyo"     #Prefecture  
export KEY_CITY="Shibuya-ku"    #City  
export KEY_ORG="AAA-Company"    #Organization name  
export KEY_EMAIL="fooo@aaa.com" #Email address  
export KEY_OU="BTeam"           #Team name etc. (optional)  
export KEY_NAME="EasyRSA"

Generate the CA certificate.

source ./vars  
./clean-all  
./build-ca  
~You'll be asked various questions, but pressing Enter for all of them seems fine~

Server certificate

Generate the server certificate.

./build-key-server server  
~You'll be asked various questions, but pressing Enter for them is basically fine~  
~You'll be asked Yes/No along the way; enter "y" there~

Diffie Hellman (DH)

Generate the DH parameters.

./build-dh

Moving the certificates

Move the generated certificates to the OpenVPN directory.

cp keys/ca.crt /etc/openvpn/.  
cp keys/server.crt /etc/openvpn/.  
cp keys/server.key /etc/openvpn/.  
cp keys/dh2048.pem /etc/openvpn/.

■OpenVPN settings

Configure the OpenVPN server.

cp /usr/share/doc/openvpn-2.4.4/sample/sample-config-files/server.conf /etc/openvpn/server.conf  
vim /etc/openvpn/server.conf

The contents are as follows. (Comment lines and blank lines are omitted)

port 1194  
proto tcp  
dev tun  
ca ca.crt  
cert server.crt  
key server.key  
dh dh2048.pem  
server 192.168.10.0 255.255.255.0        #Subnet mask of the OpenVPN server  
route 192.168.10.0 255.255.255.0         #Subnet mask assigned to clients = can be the same as server  
push "redirect-gateway def1"             #Clients route all traffic through the VPN  
push "dhcp-option DNS 192.168.10.254"    #DNS server setting  
keepalive 10 120  
status /var/log/openvpn-status.log  
log         /var/log/openvpn.log  
log-append  /var/log/openvpn.log  
verb 3  
plugin    /usr/lib64/openvpn/plugin/lib/openvpn-auth-ldap.so "/etc/openvpn/auth/ldap.conf"  
client-cert-not-required  
username-as-common-name

Also configure the connection to the LDAP server.

vim /etc/openvpn/auth/ldap.conf

The contents are as follows. (Comment lines and blank lines are omitted)

<LDAP>  
    URL     ldap://ldap.sample.com   #URL of the LDAP server  
    Timeout     15  
    TLSEnable   no  
    FollowReferrals yes  
</LDAP>  
<Authorization>  
    BaseDN      "ou=People,dc=sample,dc=com" #DN of the login account information on the LDAP server  
    SearchFilter    "(&(uid=%u))"  
    RequireGroup    false  
</Authorization>

■iptables settings

For clients connected via VPN to communicate externally through the VPN server, you need to set up masquerading with iptables.
Create scripts so that iptables is configured when openvpn starts.

Startup script

#!/bin/bash  
  
# Clear settings  
/etc/openvpn/openvpn-shutdown  
  
# Masquerade settings (change the IP address and Ethernet interface to match your environment)  
iptables -t nat -A POSTROUTING -s 192.168.10.0/24 -o eno1 -j MASQUERADE  
  
# Allow outgoing traffic from the VPN server  
iptables -I OUTPUT -o tun+ -j ACCEPT  
iptables -I FORWARD -o tun+ -j ACCEPT

Shutdown script

#!/bin/bash  
  
# Function to delete iptables rules  
delete() {  
    rule_number=`iptables -L $target --line-numbers -n -v|grep tun.|awk '{print $1}'|sort -r`  
    for num in $rule_number  
    do  
        iptables -D $target $num  
    done  
}  
  
# Delete incoming rules  
target='INPUT'  
delete  
  
# Delete forwarding rules  
target='FORWARD'  
delete  
  
# Delete outgoing rules  
target='OUTPUT'  
delete

■Starting

systemctl start iptables  
systemctl start openvpn  
sh /etc/openvpn/openvpn-startup

Client-side steps

■Getting Tunnelblick

Download & install it from the following site.
https://tunnelblick.net/downloads.html

■VPN settings

Download the ca.crt generated on the server to the client, and create sample.ovpn in the same directory.
*You can use any name for the “sample” part above. It becomes the connection name in Tunnelblick.

Make the contents of sample.ovpn as follows.

client  
  
auth-user-pass  
  
dev    tun  
proto  tcp  
  
ca     ca.crt  
  
remote xxx.xxx.xxx.xxx 1194 #xxx is the IP address the client uses to access the VPN server

Double-clicking the created ovpn file launches Tunnelblick and sets up the VPN configuration.

■VPN connection

Launch Tunnelblick and select “Connect sample” from the menu bar icon to connect.
