Apache Security Settings

posted: 2016-10-12

Apache

If you use Apache with the default settings, various server information is exposed.
To hide it, you need to edit the configuration file.

File to modify: /etc/httpd/conf/httpd.conf

1. Don’t Show File Listings

If a public directory has no default file such as index.html,
specifying that directory’s URL shows a file listing.

To prevent this, add a hyphen to Indexes as below.

<Directory "/var/www/html">  
    ~omitted~  
    # Options Indexes FollowSymLinks  
    Options -Indexes FollowSymLinks  
    ~omitted~  
</Directory>

1. Hide Only the Version Number on Error Pages

Just change ServerTokens from “OS” to “Prod”

# ServerTokens OS  
ServerTokens Prod

2. Hide the “Apache” Label on Error Pages

Just change ServerSignature from “On” to “Off”

# ServerSignature On  
ServerSignature Off
