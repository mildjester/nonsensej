SSH into a Linux Server with Private Key Authentication

posted: 2016-08-01

CentOS

■Environment

CentOS 7.2

■Steps

  1. Generate a private key and public key
    Do the following on your local PC.
    The same command should work on both Mac and Linux.
$ ssh-keygen -t rsa -b 4096  
Generating public/private rsa key pair.  
Enter file in which to save the key (/Users/hoge/.ssh/id_rsa):  
=>Specify the path and file name to generate (if left blank, the file name in parentheses is used)  
Enter passphrase (empty for no passphrase):  
=>Password for the generated key. Press Enter with it blank if not needed  
Enter same passphrase again:  
=>Re-enter the key password

A public key (.pub extension) is also generated in the same directory as the private key,
so view its contents with cat. (It’s handy to copy it since you’ll use it later)

  1. Store the public key on the server
    Do the following on the server you’re logging in to
$ mkdir ~/.ssh  
$ vim ~/.ssh/authorized_keys

Paste the contents of the public key generated in step 1 into this “authorized_keys” file.

You should now be able to log in with private key authentication.
If you can’t connect, also check the following settings.

  1. [Only if you can’t connect] Check the sshd settings
    Do the following on the server you’re logging in to
$ vim /etc/ssh/sshd_config

Check that the settings are as follows

RSAAuthentication yes  
PubkeyAuthentication yes  
AuthorizedKeysFile     .ssh/authorized_keys

*The first two may be commented out
