Making WordPress Multilingual

posted: 2018-04-24

Wordpress

■Environment

Wordpress 4.9.5
MultilingualPress 2.11.1

■Steps

First, install the MultilingualPress plugin.

After installing, when you try to activate the plugin, a message says you need to enable Multisite.

The linked page describes the steps to convert to Multisite.
https://multilingualpress.org/docs/install-wordpress-multisite/

First, edit wp-config.php in the directory where WordPress is installed and enable Multisite.

define('WP_DEBUG', false);  
  
define('WP_ALLOW_MULTISITE', TRUE);  <=add this  
  
/* 編集が必要なのはここまでです ! WordPress でブログをお楽しみください。 */  
  
/** Absolute path to the WordPress directory. */  
if ( !defined('ABSPATH') )  
    define('ABSPATH', dirname(__FILE__) . '/');

Next, deactivate all plugins, open “Tools > Network Setup” in the admin screen, and click “Install”.

You’ll then be instructed to modify wp-config.php again, so modify it as instructed.

define('WP_DEBUG', false);  
  
define('WP_ALLOW_MULTISITE', TRUE);  
  
define('MULTISITE', true);                          <=add this  
define('SUBDOMAIN_INSTALL', true);                  <=add this  
define('DOMAIN_CURRENT_SITE', 'your-domain.com');   <=add this  
define('PATH_CURRENT_SITE', '/');                   <=add this  
define('SITE_ID_CURRENT_SITE', 1);                  <=add this  
define('BLOG_ID_CURRENT_SITE', 1);                  <=add this  
  
/* 編集が必要なのはここまでです ! WordPress でブログをお楽しみください。 */  
  
/** Absolute path to the WordPress directory. */  
if ( !defined('ABSPATH') )  
    define('ABSPATH', dirname(__FILE__) . '/');

You’re also instructed to add the following to .htaccess, so do that too.

RewriteEngine On  
RewriteBase /  
RewriteRule ^index\.php$ - [L]  
  
# add a trailing slash to /wp-admin  
RewriteRule ^wp-admin$ wp-admin/ [R=301,L]  
  
RewriteCond %{REQUEST_FILENAME} -f [OR]  
RewriteCond %{REQUEST_FILENAME} -d  
RewriteRule ^ - [L]  
RewriteRule ^(wp-(content|admin|includes).*) $1 [L]  
RewriteRule ^(.*\.php)$ $1 [L]  
RewriteRule . index.php [L]

If you use nginx, .htaccess has no effect, so add the following to nginx.conf instead.

rewrite ^/wp-admin$ /wp-admin/ redirect;  
if (!-e $request_filename){  
    rewrite ^/(wp-(content|admin|includes).*) /$1 break;  
    rewrite ^/(.*\.php)$ /$1 break;  
    rewrite ^(.*)$ /index.php break;  
}

When writing the nginx config, I referred to the output of this converter.
