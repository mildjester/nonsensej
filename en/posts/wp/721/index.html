Creating an Instance on Google Cloud Platform

posted: 2017-10-08

GoogleService

Reference

https://www.topgate.co.jp/category/gcp (Japanese)

Launching an Instance

① Click “Compute Engine” in the left menu.

② Wait about a minute for it to load.
　Once loaded, click the “Create” button for VM instances.

③ There’s another short wait.
　When the instance creation screen appears, enter any name and select “asia-northeast1-a” as the zone. (Apparently the Tokyo region.)

Item Value
Name Give it any name.
Zone Select “asia-northeast1-a”. (Apparently the Tokyo region.)
Machine type Choose according to the specs you need. micro if you want it cheap.
Boot disk Choose the OS you want to install.
Identity and API access Seems to be the permissions granted to this instance. Leave it at the default for now.
Firewall Check these if you use HTTP or HTTPS
Management Leave at default for now
Disks Leave at default for now
Networking Leave at default for now
SSH keys Register the key from your local PC

④ Once that’s done, click the “Create” button at the bottom.
　There will be a wait while it processes; when it completes, the instance is created and assigned a global IP.
　
The instance is now up and running.
You can SSH into it from the local environment whose SSH key you registered by specifying the global IP.

ssh 999.999.999.999

*You can check the global IP address on the instance list screen.
