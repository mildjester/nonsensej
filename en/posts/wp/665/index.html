[Mac] Setting Up neovim & dein.vim

posted: 2017-07-15

Mac

■Environment

macOS Sierra 10.12.6
fish 2.6.0
nvim 0.2.0

■References

NeoVim、そしてdein.vimへ: https://qiita.com/okamos/items/2259d5c770d51b88d75b (Japanese)
Shougo’s GitHub: https://github.com/Shougo/dein.vim

I’m setting up neovim, which is said to be better than regular vim.
I’ll use dein.vim to manage plugins.

■Installing neovim

You can install it with brew.
Handy.

brew install neovim/neovim/neovim

■Configuring fish

Set the config file directory.
The following example sets .config directly under the home directory.

echo 'set -g XDG_CONFIG_HOME "$HOME/.config"' >> ~/.config/fish/config.fish

While we’re at it, make the vi and vim commands launch neovim.
This is a matter of preference, so it’s optional.

echo 'alias vi="nvim"' >> ~/.config/fish/config.fish  
echo 'alias vim="nvim"' >> ~/.config/fish/config.fish

Also, set the default color scheme for neovim.
Put the following on the first line of ~/.config/nvim/init.vim.
The directory and file above don’t exist initially, so create them.

colorscheme {好きなカラースキーム}

The available color schemes are introduced on the following site, which should be helpful.
https://qiita.com/ryoff/items/134b758afa8cc45a43d3 (Japanese)

If you restart the terminal around here, the settings above will be loaded cleanly.

■Installing dein.vim

Proceed with the installation as described on Shougo’s GitHub.

curl https://raw.githubusercontent.com/Shougo/dein.vim/master/bin/installer.sh > installer.sh  
sh installer.sh ~/.config

When the command above succeeds, it shows the content to put in .vimrc.
Modify it slightly and append it to ~/.config/nvim/init.vim.

The only change from the output of installer.sh is
uncommenting the auto-install block below.

"dein Scripts-----------------------------  
〜中略〜  
" If you want to install not installed plugins on startup.  
if dein#check_install()  
  call dein#install()  
endif  
〜中略〜  
"End dein Scripts-------------------------

After this, plugins will be installed the next time you start nvim,
and the basic setup is complete.

■Adding Plugins

Let’s add some dein plugins.
It seems you can also manage them in Toml, but for now I’ll describe adding them directly to ~/.config/nvim/init.vim.

The NERD Tree

https://github.com/scrooloose/nerdtree

A plugin that displays the directory hierarchy (tree) on the left side of the editor.
(It makes it feel like an IDE.)

Add the following below the line that says " Add or remove your plugins here: in ~/.config/nvim/init.vim.

call dein#add('scrooloose/nerdtree')

Add the following to the end of ~/.config/nvim/init.vim.

" The NERD Tree  
let g:NERDTreeDirArrowExpandable = '▸'  
let g:NERDTreeDirArrowCollapsible = '▾'  
map <C-n> :NERDTreeToggle<CR>

After starting nvim, type :NERDTreeToggle or press Ctrl + n
to toggle the file tree.
*The final map command maps :NERDTreeToggle to Ctrl + n.

Indent Guides

https://github.com/nathanaelkane/vim-indent-guides

Colors indentation to make it easier to read.

Add the following below the line that says " Add or remove your plugins here: in ~/.config/nvim/init.vim.

call dein#add('nathanaelkane/vim-indent-guides')

Add the following to the end of ~/.config/nvim/init.vim.

"Indent Guide  
let g:indent_guides_enable_on_vim_startup = 1

■Other Recommended Settings

Adding the following settings anywhere in ~/.config/nvim/init.vim makes it easier to use.

set number "show line numbers  
set fenc=utf-8 "set file encoding  
set cursorline "underline the current line  
set hlsearch "highlight search terms  
set mouse=a "enable mouse  
set clipboard+=unnamed "also copy yanked text to the clipboard
