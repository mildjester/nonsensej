[Linux Mint] Mining BitZeny with cpuminer + wpool

posted: 2018-04-20

LinuxMint

■Environment

Linux Mint 18.3 cinnamon 64bit

Installing cpuminer

The basic flow is as described on the cpuminer GitHub page.
https://github.com/macchky/cpuminer

Install the prerequisites first.
*libjansson4 is not mentioned on the official page, but without it minerd fails with an error.

apt install build-essential libcurl4-openssl-dev libjansson4

Download the cpuminer binary and extract the executable.

wget https://github.com/macchky/cpuminer/releases/download/v2.6.0/ZNYminer260.zip  
unzip unzip ZNYminer260.zip  
chmod +x ZNYminer260/linux/minerd  
sudo mv ZNYminer260/linux/minerd /usr/local/bin/.  
rm -rf unzip ZNYminer260*

Registering a BitZeny Wallet

Create a wallet for receiving BitZeny.
You can create a wallet on the following site.
https://bitzeny.jp (Japanese)

After creating an account and logging in, you can see your wallet address.

Starting mining

Start mining using minerd.
Running the following command listed on wpool starts mining.
Press Ctrl+C to stop mining.
https://wpool.work/ (Japanese)

minerd -a yescrypt -o stratum+tcp://wpool.work:15022 -u {BitZeny Walletで取得したアドレス}
