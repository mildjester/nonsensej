How to Configure a COMODO SSL Certificate in Apache

posted: 2015-10-20

Apache

Configuring a COMODO certificate after purchase was complicated, so I wrote it up.
The purchase procedure should be clear from the SSL vendor’s site, so I’ll skip it.

■Environment
CentOS 7.1.1503
httpd 2.4.6-31.el7.centos.1
mod_ssl 1:2.4.6-31.el7.centos.1
openssl 1:1.0.1e-42.el7.9

■Requirements
The private key created when purchasing the certificate (assumed to be yourdomain_com.key)
The certificates sent by email after purchase
・yourdomain_com.crt
・COMODORSADomainValidationSecureServerCA.crt
・COMODORSAAddTrustCA.crt
・AddTrustExternalCARoot.crt

First, upload all of the above to the server you are configuring.
Any location is fine, but in this example they are stored under “/etc/pki/comodo/”.

Next, concatenate the three certificates from the email whose file names do not contain your domain name.
You can concatenate them with the following command. Be sure to keep the order shown below.
The name of the concatenated file (yourdomain_com.ca_bundle in the example below) is up to you.

# cat COMODORSADomainValidationSecureServerCA.crt COMODORSAAddTrustCA.crt AddTrustExternalCARoot.crt > yourdomain_com.ca_bundle

Edit Apache’s SSL configuration file and modify the following lines.
(/etc/httpd/conf.d/ssl.conf)

SSLCertificateFile /etc/pki/comodo/yourdomain_com.crt  
SSLCertificateKeyFile /etc/pki/comodo/yourdomain_com.key  
SSLCertificateChainFile /etc/pki/comodo/yourdomain_com.ca_bundle

Reload the Apache configuration.

# systemctl reload httpd

The SSL settings should now be applied.
If it doesn’t work, try restarting Apache.

# systemctl restart httpd
