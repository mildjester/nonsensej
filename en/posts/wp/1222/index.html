[Linux Mint] Enabling Japanese Input

posted: 2018-04-13

LinuxMint

■Environment

Linux Mint 18.3 cinnamon 64bit

These are the steps for when Linux Mint was installed in English.
If you installed it in Japanese, Japanese input should work from the start.

Setup Steps

Enable Japanese input with Fcitx + Mozc.

First, open “System Settings > Input Method”.

Under “Language support” there is Japanese; click its Install button.

After installation, Fcitx becomes selectable under “Input method”. Select it,
then restart the machine.

After restarting, open Fcitx Configuration from the Menu.
It shows up once you type about “Fc” into the search bar.

Click “+” to add an Input Method.

A list of input methods appears. Select Mozc and click OK.

Mozc is added to the Input Methods, so remove the original Keybord - Japanese with the delete (x) button.

Japanese input now works.
You can switch between Japanese and English with the Hankaku/Zenkaku key.
