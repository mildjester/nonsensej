■Installing the Font

Install “Ricty Diminished”, a Japanese-compatible font with a good reputation for programming.
It really is easy to read. It’s good in terms of character width and how easy characters are to tell apart (like the letter O vs. zero).

First, download the font set.
You can find the archive to download on this page.
*(Added 2019/11/14) The URL had changed, so I updated it.
http://www.yusa.lab.uec.ac.jp/~yusa/ricty_diminished.html (Japanese)

$ wget http://www.yusa.lab.uec.ac.jp/~yusa/ricty_diminished/ricty_diminished-4.1.1.tar.gz
$ tar xf ricty_diminished-4.1.1.tar.gz

Next, move the downloaded fonts to the font directory.
[For Mac]

$ mv RictyDiminished*.ttf ~/Library/Fonts/.  
$ brew install fontconfig

[For Ubuntu and Linux Mint]

$ mkdir -p ~/.fonts  
$ mv RictyDiminished*.ttf ~/.fonts/.

Finally, load the fonts

$ fc-cache -vf  
$ rm -f ricty_diminished-4.1.1.tar.gz

Now specifying Ricty Diminished in your IDE or similar will apply it.
A slightly fancier(?) font called Ricty Diminished Discord also becomes available, so pick whichever you prefer.

■Bonus

A font called “Cica” is also well regarded, so I’ll introduce it too.
https://github.com/miiton/Cica

Like Ricty, it has good character width and legibility, and compared to Ricty it’s a bit rounder and cuter.

You can install it with the following steps.

$ wget https://github.com/miiton/Cica/releases/download/v2.1.0/Cica_v2.1.0.zip  
$ unzip Cica_v2.1.0.zip  
$ mkdir -p ~/.fonts  
$ mv Cica-*.ttf ~/.fonts/.  
$ sudo fc-cache -fv  
$ rm -f Cica_v2.1.0.zip
