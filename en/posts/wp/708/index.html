I’d been curious about the trendy editor “Atom” for a while, but

  • it’s heavy for a text editor
  • it has too few features for an IDE

so I had kept my distance.

However, an IDE version of Atom has apparently come out, so I gave it a try.

■Steps

1. Get Atom

Download and install Atom 1.21.0 (beta) from the following site.
https://atom.io/beta

*I looked at several introduction pages, and 1.21.0 seems to be recommended.
　I also tried 1.20.0 (stable), and it did indeed behave questionably.

2. Install the Required Packages

After launching Atom, go to the top menu
Packages > Settings View > Install Packages/Themes
and search for and install the following.

  • atom-ide-ui
  • ide-php
  • ide-go

3. Try It Out

The first time you open Go source code, you’ll be asked whether to install the packages “ide-go” depends on,
so install them.
You’ll also get a message that “linter” and “atom-ide-diagnostics” conflict,
so click “Disable linter” below that message to resolve the conflict.

With that, it looks ready to use.
Go-to-definition and completion worked well enough to be practical.
It also started up faster than other free IDEs (Eclipse and NetBeans).

Installing Other Packages

There are lots of handy packages unrelated to the IDE, so I installed some.
Below are the packages I actually tried.

■file-icons
Changes icons to match each file’s extension.
By the way, to associate a new extension with Atom, click “Atom Beta > Config” in the top menu
and edit config.cson.

[Example: the following makes the “.inc” extension recognized as a PHP file]

"*":  
  core:  
    customFileTypes:  
      "source.php": [  
        "inc"  
      ]

The part corresponding to “source.php” is shown in a popup when you press “cmd + opt + P” with a PHP file open.
The same operation should work for files with other extensions.

■pigments
Automatically highlights color codes in their actual color.

■show-ideographic-space
Makes full-width spaces visible.

■git-plus
Lets you do git operations without a terminal, apparently!

■merge-conflict
Makes resolving git conflicts easier.

■highlight-selected
Highlights all occurrences of the selected word in the source code.
Selecting apparently means double-clicking. Handy for finding the same variable.

■linter-php
A package that checks syntax.
It tells you things like when opening and closing brackets don’t match.
It prompts you to install various related packages, so install those too.
*Atom IDE apparently also ships with a syntax-checking package(?), and a warning appears when they conflict.
　I couldn’t tell whether the IDE’s built-in one was actually detecting errors, so I disabled it.
　(The warning has a Disable button, so just click it)

■project-manager
A package for managing multiple projects.
Makes switching projects easy.
[Adding a project to manage]
　With the project you want to add open, select “packages > Project Manager > Save Project” from the top menu.
[Opening a managed project]
　Press “Ctrl + Command + P” to show the list, then select one.
　Selecting “packages > Project Manager > List Project” from the top menu does the same.
