[Ubuntu] Installing Flash Player

posted: 2015-08-27

ubuntu

Steps for installing Flash Player for browsers on Ubuntu.

■For Firefox
Download Flash Player from Adobe.
When I wrote this post, I downloaded “install_flash_player_11_linux.x86_64.tar.gz”.

Extract the downloaded file, go into the resulting directory,
and copy the required files.

sudo cp -a libflashplayer.so /usr/lib/chromium-browser/libs/.  
sudo cp -a usr/* /usr/.

■For Chromium
You can install it with just the following commands.

<del datetime="2016-06-21T14:36:14+00:00">sudo apt-get install pepperflashplugin-nonfree</del>  
<del datetime="2016-05-04T14:36:14+00:00">sudo update-pepperflashplugin-nonfree --install</del>

*(Edited 2016/6/21) Installing with the commands above no longer gets the latest Flash Player.
　It can be downloaded from Adobe’s official site, so get it from there.
　https://get.adobe.com/jp/flashplayer/?no_redirect (Japanese)
