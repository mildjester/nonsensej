[Laravel] "Class 'CreateFoooTable' not found" on migrate

posted: 2017-04-11

PHP
Laravel

■Environment

Laravel 5.1

How to fix the error “Class ‘CreateFoooTable’ not found”
when running Laravel’s “migrate:rollback” or “migrate:refresh”.

This seems to be caused by the files in the “/database/migrations” directory used by migrate
not being autoloaded.

To fix it, run the following command in the project’s root directory to regenerate the autoload files.

composer dump-autoload

*For installing composer, see here.

If you can’t install composer on the server, run the above command on your work PC;
the “/vendor” directory will be updated, so upload it to the server.

That’s all.
