Installing PHP 7.2 on a Mac

posted: 2019-02-14

Mac
PHP

Environment

  • macOS Mojave 10.14.2
  • fish 2.7.1
  • Homebrew 2.0.1
  • PHP 7.2.15

Install PHP 7.2 on a Mac using Homebrew.
If Homebrew isn’t installed, see the following.
[Mac] Installing Homebrew

First, search for PHP 7.2 in Homebrew.

$brew search php72
==> Formulae
php@7.2

Now that we know the package, install it.

$ brew install php@7.2
~lots omitted~
If you need to have php@7.2 first in your PATH run:
  echo 'set -g fish_user_paths "/usr/local/opt/php@7.2/bin" $fish_user_paths' >> ~/.config/fish/config.fish
  echo 'set -g fish_user_paths "/usr/local/opt/php@7.2/sbin" $fish_user_paths' >> ~/.config/fish/config.fish
~some omitted~

Right before the installation finishes, instructions like the above are printed, telling you to add some settings.
I use fish as my shell, so the commands look like the above; if you use bash or zsh, they will be different.

Apply the settings as instructed.

$ echo 'set -g fish_user_paths "/usr/local/opt/php@7.2/bin" $fish_user_paths' >> ~/.config/fish/config.fish
$ echo 'set -g fish_user_paths "/usr/local/opt/php@7.2/sbin" $fish_user_paths' >> ~/.config/fish/config.fish

Now restart the terminal or reload the config file, and the PHP version will be 7.2.

$ php -v
