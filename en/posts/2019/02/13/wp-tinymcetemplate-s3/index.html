[WordPress] Using S3 Images in TinyMCE Templates

posted: 2019-02-13

Wordpress

Environment

  • Wordpress 4.8.3
  • TinyMCE Templates 4.8.1
  • WP Offload Media Lite 2.0

Problem

When all WordPress images are managed on S3 with WP Offload Media Lite, even if you upload and register images inside a template created with TinyMCE Templates, the images can’t be seen when you insert the template while editing a post.
*Assumes images on the web server are configured to be deleted.

Cause

WP Offload Media Lite keeps both the “path on S3” and the “path if the file were local” for every image file.
WP Offload Media Lite then replaces image paths in the data as follows.

When Saving Data

If the image paths in the POST data contain a “path on S3”, they are replaced with the “path if the file were local” before saving to the DB.
(S3 → local replacement)

When Loading Data

If the image paths in data loaded from the DB contain a “path if the file were local”, they are replaced with the “path on S3” before being displayed.
(Local → S3 replacement)

However, for TinyMCE Templates, the “S3 → local replacement” runs when the template is saved, but the “local → S3 replacement” does not run when the template is loaded.

So when the template is loaded, the image paths remain the “path if the file were local”, and since no such image exists locally, the images aren’t displayed.

Solution

Add a filter for saving data in function.php so that the “local → S3 replacement” also runs when a TinyMCE template is saved.

In other words, although a bit wasteful, saving a TinyMCE template now runs “S3 → local → S3 replacement”.

function replace_s3_image_on_tinymcetemplates($content){
  if ($content['post_type'] !== 'tinymcetemplates' || !class_exists('Amazon_S3_And_CloudFront') || !class_exists('AS3CF_Local_To_S3')) {
    return $content;
  }

  $s3PluginPath = str_replace('themes/'.get_template(), 'plugins/amazon-s3-and-cloudfront/wordpress-s3.php', __DIR__);
  $as3cf = new Amazon_S3_And_CloudFront($s3PluginPath);
  $localToS3 = new AS3CF_Local_To_S3($as3cf);
  $content['post_content'] = $localToS3->filter_post($content['post_content']);
  
  return $content;
}
add_filter('wp_insert_post_data','replace_s3_image_on_tinymcetemplates');

This is a fairly brute-force approach, so if anyone knows a better way, please let me know.
