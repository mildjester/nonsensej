Running Commands as Another User on Linux

posted: 2019-10-10

Linux

Environment

Amazon Linux AMI release 2013.03

It’s a bit late, but I wanted to organize what I know about the sudo command, so I wrote this.

First, the basics: to run a command as the root user, type sudo {command}.

$ sudo id
uid=0(root) gid=0(root) 所属グループ=0(root)

If you want to act as a user other than root, specify it with the -u option.

$ sudo -u apache id
uid=48(apache) gid=48(apache) 所属グループ=48(apache)

If you frequently act as a specific user,
defining a function in .bashrc or similar makes it easier.
(This is what I most wanted to write about.)

# Run a command as the apache user
sudoa () {
    sudo -u apache $*
}
# Run a git command as the apache user
agit() {
    sudo -u apache git $*
}

With this, typing agit pull
runs git pull as the apache user.

You can also write simple scripts like the following.

hoge() {
    sudo -u yamada sh -c '
        NAME=`id | grep -o -E "\([^)]+\)" | grep -o -m 1 -E "[^\()]+"`
        echo "hello ${NAME}!"
    '
}

The result looks like this.

$ hoge
hello yamada!
