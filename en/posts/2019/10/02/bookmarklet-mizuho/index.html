Automatically Entering a Password with a Bookmarklet

posted: 2019-10-02

bookmarklet
javascript

Extracting 4 digits from the 6-digit second PIN when making a transfer on Mizuho Direct was tedious,
so I used a bookmarklet to display the 4 digits I need to enter.

For an explanation of bookmarklets and how to make them, see here.
How to Make a Bookmarklet

Trying it on Mizuho Direct

When you reach the screen for entering the second PIN during a transfer on Mizuho Direct,
run the following JavaScript to display the second PIN.

var secondPass = '123456'; // Put your 6-digit second PIN here
var orderNum = 0;
var pickPw = '入力するパスワード: ';

// Process the 4 requested digits of the second password in order
for (var i = 1; i<=4; i++) {
    // Check which digit of the second password is being asked for
    orderNum = Number(document.getElementById('txtScndPwdDgt' + i).innerHTML);
    // Extract the target digit from the second password and append it to the text
    pickPw += secondPass.substr(orderNum -1, 1)
}
// Display the 4 digits to enter
alert(pickPw);

Minify this for use as a bookmarklet and prepend javascript:.
(For how to minify, see here)

javascript:for(var t,e="入力するパスワード: ",r=1;r<=4;r++)t=Number(document.getElementById("txtScndPwdDgt"+r).innerHTML),e+="123456".substr(t-1,1);alert(e);

Then just add a new page to your browser bookmarks and enter the JavaScript above as the URL.

For sites other than Mizuho Direct, you should be able to create something similar
by inspecting the HTML elements with your browser’s developer tools.
