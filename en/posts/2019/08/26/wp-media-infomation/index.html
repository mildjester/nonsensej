[WordPress] Removing the Title and Caption Set in Image Files

posted: 2019-08-26

Wordpress

Environment

  • WordPress 4.8.3

Goal

When uploading an image file to the WordPress media library,
the image title is basically the file name,
but some image files have a title or caption already set in them.

For example, photos taken with an Olympus digital camera
may all have the title and caption “OLYMPUS DIGITAL CAMERA”,
which makes them hard to manage, and fixing them each time is a hassle.

So I’ll make WordPress ignore the values set in the image file.
(In WP, the title will then be the file name)

Solution

Just add the following to function.php.

function delete_media_title_caption( $img_meta ) {
  $img_meta['title'] = '';
  $img_meta['caption'] = '';
  return $img_meta;
}
add_filter( 'wp_read_image_metadata', 'delete_media_title_caption' );

Now the title and caption set in the file are ignored when uploading images.
