Installing Sass on Linux Mint

posted: 2019-09-29

LinuxMint

Installation

This is the installation method I eventually arrived at.
If you just want to install it, run the following.

$ apt install ruby-sass ruby-dev
$ sudo gem install listen --version '~> 3.0'

Where I Got Stuck

Some people may search by error message,
so I’ll note the steps where I got stuck.

First, I installed only sass.

$ apt install ruby-sass

Then I got an error when running watch with the sass command.

$ sass --watch ./sass:./css --style compact --no-cache
>>> Sass is watching for changes. Press Ctrl-C to stop.
LoadError: cannot load such file -- listen
Run "gem install listen --version '~> 3.0'" to get it.
  Use --trace for backtrace.

It seems listen is required for watch.
So I tried to install listen, but got an error.

$ sudo gem install listen --version '~> 3.0'
Building native extensions. This could take a while...
ERROR:  Error installing listen:
	ERROR: Failed to build gem native extension.

    current directory: /var/lib/gems/2.5.0/gems/ffi-1.11.1/ext/ffi_c
/usr/bin/ruby2.5 -r ./siteconf20190925-17707-1yh0gf6.rb extconf.rb
mkmf.rb can't find header files for ruby at /usr/lib/ruby/include/ruby.h

extconf failed, exit code 1

Gem files will remain installed in /var/lib/gems/2.5.0/gems/ffi-1.11.1 for inspection.
Results logged to /var/lib/gems/2.5.0/extensions/x86_64-linux/2.5.0/ffi-1.11.1/gem_make.out

After some research, it turned out ruby-dev was required.
https://qiita.com/kyrieleison/items/81c14780ad490049202c (Japanese)

Installing ruby-dev and then listen succeeded.

$ apt install ruby-dev
$ sudo gem install listen --version '~> 3.0'

Now the sass command works.
