Don't Use text-orientation in CSS

posted: 2019-09-14

CSS

The title is a bit clickbaity, but
I ran into a small problem, so I’m writing it down.

What I Did

I needed to write vertical text (with alphanumerics oriented upright),
so I implemented it with text-orientation as follows.

CSS

div {
    width: 30px;
    height: 290px;
    margin: 20px auto;
}
p {
    padding: 20px;
    border: 2px solid #000;
    -webkit-writing-mode: vertical-rl; /* Vertical writing */
    -ms-writing-mode: tb-rl; /* Vertical writing */
    writing-mode: vertical-rl; /* Vertical writing */
    text-orientation: upright; /* Make alphanumerics upright */
}

HTML

<div>
  <p>僕にもし子供が産まれたら<br/>世界で2番目に好きだと話そう</p>
</div>

Checking in Chrome and the like, it looked as expected.

I was satisfied with this, but it turns out IE doesn’t support text-orientation,
so the numbers were displayed sideways. (As of September 2019)

Solution

There’s a style called text-combine-upright,
so I use it to make the number part upright.

The modified source looks like this.

CSS

div {
    width: 30px;
    height: 290px;
    margin: 20px auto;
}
p {
    padding: 20px;
    border: 2px solid #000;
    -webkit-writing-mode: vertical-rl; /* Vertical writing */
    -ms-writing-mode: tb-rl; /* Vertical writing */
    writing-mode: vertical-rl; /* Vertical writing */
}
span {
    font-family: "メイリオ";
    -webkit-text-combine: horizontal; /* Make alphanumerics upright */
    -ms-text-combine-horizontal: all; /* Make alphanumerics upright */
    text-combine-upright: all; /* Make alphanumerics upright */
}

HTML

<div>
  <p>僕にもし子供が産まれたら<br/>世界で<span>2</span>番目に好きだと話そう</p>
</div>

Now the numbers are upright in IE too.

One thing to watch out for: the range wrapped with text-combine-upright is laid out horizontally.
In other words, if you put multiple characters inside the span above, you get the following.

HTML

<div>
  <p>僕にもし子供が産まれたら<br/>世界で<span>123</span>番目に好きだと話そう</p>
</div>

Result

If you want multiple alphanumerics upright and stacked vertically,
you have to wrap each character individually with text-combine-upright, which is a pain.

I hope IE supports text-orientation soon.
