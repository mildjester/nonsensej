Turning Linux Mint into a Wireless LAN Access Point

posted: 2019-04-17

LinuxMint

Environment

  • Linux Mint 19.1 “Tessa” - MATE (64-bit)

I wanted to view a page that is only accessible via VPN on a PC, Android, and iOS at the same time,
but my VPN subscription only allows one device to connect at a time.

So I connected to the VPN on the PC (Linux Mint) and shared that connection over wireless LAN.
It’s what Mac calls “Internet Sharing”.

Reference

Linuxで簡単に無線Lanアクセスポイントを作る (Japanese)

I mostly followed the reference page, but some parts didn’t work, so I modified the commands slightly.

Setup

Install the required software.

apt install util-linux procps hostapd iproute2 iw

Get the script that creates the access point.

wget https://raw.githubusercontent.com/oblique/create_ap/master/create_ap

Make it executable and move it somewhere on your PATH.

sudo chmod +x create_ap
sudo mv create_ap /usr/local/bin/.

Sharing the Network

First, check your network interfaces (NICs).

ip a

Very roughly speaking,
NICs starting with e are wired LAN, and NICs starting with w are wireless LAN.
For VPNs, the name probably includes the VPN type (ppp, etc.).
Those starting with lo or br are used internally, so you can basically ignore them.

If you’re not sure, open the details of the NIC you want to use under “Control Center > Network Connections”,
and pick the NIC whose device “XX:XX:XX:XX:XX:XX” matches.

From these NICs, decide which one to use for “outside world <-> PC” communication and which for “PC <-> smartphone” communication.

Note that these two NICs must be physically separate hardware.
For example, if your PC has only one wireless LAN NIC, it will be used for “PC <-> smartphone”,
so you’ll have to use something like wired LAN for “outside world <-> PC”.

Once you’ve decided which NICs to use, run the command as follows:

sudo create_ap {NIC for smartphones} {NIC for outside world} {SSID} {SSID password}

For example, if the NIC for smartphones is the wireless LAN wlp3s0 and the NIC for the outside world is the VPN ppp0, you can start the access point with the following command.
In this command, the SSID is MyAP and the password is MyPassword.

sudo create_ap wlp3s0 ppp0 MyAP MyPassword

After running the command, the access point’s activity log streams in the terminal.
To close the access point, press Ctrl + c.
