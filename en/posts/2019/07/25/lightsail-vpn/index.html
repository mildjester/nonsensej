Setting Up an OpenVPN Server on Lightsail

posted: 2019-07-25

AWS
VPN

Environment

  • Amazon Linux AMI release 2018.03
  • openvpn 2.4.4

References

  • LightsailでVPN Serverを構築する|memoTech (Japanese)
  • AmazonLinuxにOpenVPNサーバを構築する|ねこの足跡R (Japanese)

I had been subscribed to a domestic VPN service,
but it only allowed one device at a time and the connection was really slow,
so I decided to set up my own VPN server.

I’ll set up an OpenVPN server on AWS Lightsail
and make it accessible from Linux Mint, Android, and iPhone.

Instance Setup

Create a New Instance

On the Lightsail page, click “Create instance”.
https://lightsail.aws.amazon.com/ls/webapp/home/instances

Select the following as the instance image.

  • Linux/Unix
  • OS Only
  • Amazon Linux

Choose an instance plan based on how you plan to use the VPN.
For light personal use, the cheapest plan should be fine.

Give the instance a name and click “Create instance”.

Configure a Static IP

You’ll be taken back to the instance list.
Click “Manage” from the “︙” menu of the instance you just created.

Open the Networking tab and click “Create static IP”.

On the static IP settings screen, choose the instance to attach it to (the one you just created),
give the static IP a name, and click “Create”.

Open the Port

Open the “Networking” tab of the target instance.
Click “+ Add” under Firewall and open TCP port 1194.

Connect to Lightsail

In the instance list, click “Connect” from the “︙” menu again.

A terminal-like browser window opens; perform the following steps there.
You can also connect via ssh from your local terminal.

Set Lightsail’s Clock to Japan Time

Just in case, set the timezone to Japan.

sudo cp -p /usr/share/zoneinfo/Japan /etc/localtime
sudo service rsyslog restart
sudo service crond restart

OpenVPN Setup

Install OpenVPN

Run the following command.

sudo yum install openvpn

Create a Certificate Authority

Run the following commands.

wget https://github.com/OpenVPN/easy-rsa/releases/download/v3.0.4/EasyRSA-3.0.4.tgz
tar -xf EasyRSA-3.0.4.tgz
sudo mv EasyRSA-3.0.4 /usr/local/EasyRSA
cd /usr/local/EasyRSA/
./easyrsa init-pki
./easyrsa build-ca

You’ll be asked the following questions after running it; enter your answers.

Prompt Input
Enter PEM pass phase: Any passphrase
Verifying - Enter PEM pass phrase: Same as above
Common Name (eg: your user, host, or server name) [Easy-RSA CA]: Any domain (e.g. xxxxx.com)

Generate DH Parameters

./easyrsa gen-dh

Generate the Server Certificate and Private Key

./easyrsa build-server-full server nopass

You’ll be asked for a passphrase; enter the one you set earlier.

Generate Client Certificates and Private Keys

Run the following command for each user who will connect.
Even for the same user, if they connect simultaneously from both a PC and a smartphone, you need to generate a separate certificate and private key for each client.

./easyrsa build-client-full {client name} nopass
# e.g. ./easyrsa build-client-full client1 nopass

You’ll be asked for a passphrase; enter the one you set earlier. Use any client name that identifies the connecting user.

Check the VPN Server’s IP Address and Netmask

Run the following command.

ip a

Note the inet value of eth0 in the output.
(The xxx.xxx.xxx.xxx/xx part below)

2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 9001 qdisc pfifo_fast state UP group default qlen 1000
    link/ether 06:7a:be:17:01:aa brd ff:ff:ff:ff:ff:ff
    inet xxx.xxx.xxx.xxx/xx brd 172.26.15.255 scope global eth0
       valid_lft forever preferred_lft forever
    inet6 fe80::47a:beff:fe17:1aa/64 scope link 
       valid_lft forever preferred_lft forever

Edit the Configuration File

Copy the generated server files into the OpenVPN directory.

sudo cp pki/ca.crt /etc/openvpn/.
sudo cp pki/issued/server.crt /etc/openvpn/.
sudo cp pki/private/server.key /etc/openvpn/.
sudo cp pki/dh.pem /etc/openvpn/dh2048.pem

*Only the dh file is renamed.

Next, edit the configuration file.

sudo cp /usr/share/doc/openvpn-2.4.4/sample/sample-config-files/server.conf /etc/openvpn/server.conf
sudo vim /etc/openvpn/server.conf

The edited configuration looks like this.
Set the push "route xxx.xxx.xxx.xxx yyy.yyy.yyy.yyy" part
to the VPN server’s IP address and subnet mask you checked earlier.

$ grep -v "^$" /etc/openvpn/server.conf | grep -v "^#" | grep -v "^;"
port 1194
proto tcp
dev tun
ca ca.crt
cert server.crt
key server.key  # This file should be kept secret
dh dh2048.pem
server 10.8.0.0 255.255.255.0
ifconfig-pool-persist ipp.txt
push "redirect-gateway def1 bypass-dhcp"
push "route xxx.xxx.xxx.xxx yyy.yyy.yyy.yyy"
push "dhcp-option DNS 208.67.222.222"
push "dhcp-option DNS 208.67.220.220"
keepalive 10 120
tls-auth ta.key 0 # This file is secret
cipher AES-256-CBC
persist-key
persist-tun
status /var/log/openvpn/openvpn-status.log
log         /var/log/openvpn/openvpn.log
log-append  /var/log/openvpn/openvpn.log
verb 3
explicit-exit-notify 0

Also create the log output directory you configured.

sudo mkdir /var/log/openvpn
sudo chmod 0600 /var/log/openvpn

Create ta.key

sudo openvpn --genkey --secret /etc/openvpn/ta.key

Enable Packet Forwarding

sudo sed -i -e "s/net.ipv4.ip_forward = 0/net.ipv4.ip_forward = 1/g" /etc/sysctl.conf
sudo sysctl -p

Change Routing

sudo iptables -t nat -A POSTROUTING -s 10.8.0.0/24 -o eth0 -j MASQUERADE
sudo service iptables save

Start OpenVPN

sudo chkconfig openvpn on
sudo service openvpn start

Client Setup

Of the files generated on the VPN server, the following four are needed for client setup.

  • /usr/local/EasyRSA/pki/ca.crt
  • /usr/local/EasyRSA/pki/issued/{client name}.crt
  • /usr/local/EasyRSA/pki/private/{client name}.key
  • /etc/openvpn/ta.key

Also, Android and iPhone require a file with the .ovpn extension, so create one.
(hogehoge.ovpn)

The contents of the ovpn file are as follows.
It’s more convenient to embed the certificate and key data in the ovpn file, so we embed them.
*Replace xxx.xxx.xxx.xxx with the VPN server’s global IP address.

client
dev tun
proto tcp
remote xxx.xxx.xxx.xxx 1194
resolv-retry infinite
nobind
persist-key
persist-tun
remote-cert-tls server
key-direction 1
cipher AES-256-CBC
verb 3
<ca>
~Paste the contents of ca.crt above as-is~
</ca>
<key>
~Paste the contents of {client name}.key above as-is~
</key>
<cert>
~Paste the contents of {client name}.crt above as-is~
</cert>
<tls-auth>
~Paste the contents of ta.key above as-is~
</tls-auth>

Linux Mint

OpenVPN can be configured from the standard network settings screen,
so you can connect by setting the files above there.

Here are screenshots of the settings screens.



Android

Send the ovpn file to the Android device, e.g. as an email attachment.

Install the OpenVPN app from Google Play.
https://play.google.com/store/apps/details?id=net.openvpn.openvpn

Open the installed OVPN app and open “OVPN Profile”.
A file selection screen appears; select the ovpn file and tap “IMPORT”.

On the next screen, tap “ADD”.

That completes the setup.
Turn on the switch for the created connection to connect to the VPN.

iPhone

Send the ovpn file to the iPhone, e.g. as an email attachment.

Install the OpenVPN app from the App Store.
https://apps.apple.com/jp/app/openvpn-connect/id590379981

Download the ovpn file in your mail app and open it.
The installed OpenVPN app appears among the options to open it with; select it.

The OpenVPN app opens and shows the ovpn file you just downloaded; tap “ADD”.

Tap “ADD” on the next screen as well.
A warning popup appears; tap “Allow” to proceed.

That completes the setup.
Turn on the switch for the created connection to connect to the VPN.
