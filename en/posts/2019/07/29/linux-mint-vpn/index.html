Connecting and Disconnecting a VPN from the Command Line

posted: 2019-07-29

LinuxMint

Environment

  • Linux Mint 19.1 “Tessa” - MATE (64-bit)

Linux Mint lets you configure a VPN in the GUI, and connect and disconnect it from the GUI as well.
However, sometimes you want to control the VPN from the command line, such as while working in the terminal,
so I looked up the commands.

Checking the VPN Name

You named it yourself, so you may not need to look it up,
but you can check it with the following command.
(In the example below, “SampleVPN” is the VPN name.)

$ nmcli connection | grep vpn
SampleVPN           123abc12-1a2b-1234-12a1-1234567890ab  vpn       --

Connecting to the VPN

Connect to the VPN with the following command.

nmcli con up id {VPN name}
# Example: nmcli con up id SampleVPN

Disconnecting from the VPN

Disconnect from the VPN with the following command.

nmcli con down id {VPN name}
# Example: nmcli con down id SampleVPN

Registering Shortcut Commands

Registering aliases makes it easier.

alias up-vpn="nmcli con up id SampleVPN"
alias down-vpn="nmcli con down id SampleVPN"
