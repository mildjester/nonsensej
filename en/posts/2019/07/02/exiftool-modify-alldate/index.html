Changing the Date Taken of Images from the Command Line

posted: 2019-07-02

LinuxMint

Environment

  • Linux Mint 19.1 “Tessa” - MATE (64-bit)
  • exiftool 10.80

When you import photos using a scanner, the date taken is not set in the image file,
so I use exiftool, a tool that handles EXIF information, to change the date taken.

*This procedure just forcibly writes EXIF information,
　so it doesn’t seem to change the file format to EXIF (?).

First, install exiftool if it isn’t installed yet.

apt install exiftool

To view the current EXIF information, run the following command.
This command shows the EXIF information of all png files in the current directory.

exiftool -s ./*png
(Replace the ./*png part with the path to your image files)

Next, rewrite the date taken and other dates.
The following commands change the date taken etc. to “2019/02/23 00:00:00”.

exiftool -overwrite_original -alldates='2019:02:23 00:00:00+09:00' ./*png
exiftool -overwrite_original -TimeStamp='2019:02:23 00:00:00+09:00' ./*png

*Specifying overwrite_original makes it overwrite the files,
　so remove this option if you want to keep the original data.

Then also fix the file modification date.
If you don’t care about the file modification date, you can skip this.

exiftool -overwrite_original -FileModifyDate='2019:02:23 00:00:00+09:00' ./*png

If you check the EXIF information again, you can see that the date data has been updated.

exiftool -s ./*png
