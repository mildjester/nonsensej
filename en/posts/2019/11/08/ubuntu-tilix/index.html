Tilix: A Terminal for Linux

posted: 2019-11-08

ubuntu

Environment

  • Ubuntu 19.10

Until now I’d been using Terminator as my terminal on Ubuntu and other Linux environments,
but a terminal called Tilix looked good too, so I tried it.
I think it’s more convenient to use than Terminator.

Installation

You can install it with just the following command.

sudo apt install tilix

Settings

Clicking the three-line icon at the top right of the window shows the “Preferences” menu.
From there you can change the window colors, size, font, and so on.

Splitting Panes

There are split buttons at the top left of the window; just click them to split.
There are also shortcut keys, but the default ones are mapped to other actions on Ubuntu,
so if you want to use them, change the shortcut keys under “Preferences > Shortcuts”.
