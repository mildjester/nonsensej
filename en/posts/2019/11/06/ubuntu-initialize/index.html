Notes from installing Ubuntu 19.10 on a ThinkPad T480.

Japanese input settings

Japanese input works out of the box, but you have to switch the input source to Mozc,
so I raise the priority of the Mozc input source.

Open “Settings” from the app launcher and go to “Region & Language”.
The input sources list “Japanese” and “Japanese (Mozc)”,
so reorder them so that “Japanese (Mozc)” comes first.

You can change the order by dragging the six dots on the left edge of each input source.

Making IME ON/OFF Mac-like

Open “Mozc Settings” from the app launcher and go to the “General” tab.
Click the “Edit” button next to “Keymap style” to change the key settings.

There, assign “Activate IME” to Henkan/Hiragana/Katakana,
and assign “Deactivate IME” to Muhenkan.

Now you can toggle the IME ON/OFF like on a Mac.

Making CapsLock Ctrl and Hankaku/Zenkaku Esc

This is another Mac-like setting.
Running the following command turns CapsLock into Ctrl and makes the Hankaku/Zenkaku key act as Esc.

setxkbmap -option ctrl:nocaps,japan:hztg_escape

Turning off the tiling feature

By default, dragging a window to the edge of the screen maximizes it automatically.
I don’t need this feature, so I disable it with the following command.

gsettings set org.gnome.shell.overrides edge-tiling false

*Added 2019/12/2 On Ubuntu 19.10, the above alone did not disable tiling.
It seems you also need to run the following. (Actually, this alone seems to be enough.)

gsettings set org.gnome.mutter edge-tiling false

Installing various things

PHP

sudo apt install php7.3 composer php7.3-bcmath php7.3-common php7.3-gd php7.3-json php7.3-mbstring php7.3-mysql php7.3-xml php7.3-xmlrpc

MySQL Workbench

sudo apt install mysql-workbench mysql-client

Shutter (screenshot tool)

It’s handy because you can also draw text and arrows on existing images.

sudo add-apt-repository ppa:linuxuprising/shutter
sudo apt update
sudo apt install shutter
