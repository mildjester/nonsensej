Working with Pages That Require Session Information in Google Optimize

posted: 2019-03-07

GoogleService

Google Optimize is a free tool for running A/B tests and more.

If you specify a page that requires session information, such as a post-login page, as the Google Optimize editor page,
an error page or 404 page is shown because there’s no session information.
In such cases, the editor page’s “Interactive mode” solves the problem.

Steps

This assumes you already know the basic usage of Google Optimize.

Step 1: Set the Editor Page

First, set the editor page to a page that can be opened without session information and comes before the page you want to work on in Optimize.
You could specify the target page itself, but the editor would first show an error page when opened, which I think is inefficient.

Step 2: Navigate to the Optimize Target Page

Create a variant as usual and click the icon in the upper right of the editor that shows a cursor on a square.

This switches to interactive mode, where you can operate the site; navigate to the page you want to open in Optimize.
Once you’ve opened that page, click “Done” in interactive mode.
*Interactive mode may also end on its own when the screen transitions

Step 3: Edit

Edit the page the same way as a page that doesn’t require session information.
Nothing special about this step.

That completes the Optimize setup.
When previewing, it starts from the URL specified as the editor page, so you need to navigate to the page you edited in Optimize.
