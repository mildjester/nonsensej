Adjusting the ThinkPad TrackPoint on Linux Mint

posted: 2020-07-06

LinuxMint

Environment

  • Linux Mint 19.1 “Tessa” - MATE (64-bit)
  • ThinkPad T480

■References

Ubuntu17.10でtrackpointの速度を調整する (Japanese)

You can adjust the TrackPoint speed from “Control Center > Mouse”,
but the adjustable range is limited and I wanted a bit more sensitivity, so I’ll adjust it another way.

■Finding the Optimal Values

Tweak “sensitivity” and “speed” to find the optimal values.
In my case, sensitivity 180 and speed 60 felt just right.

$ sudo -i
# cd /sys/devices/platform/i8042/serio1/serio2
# vim sensitivity   // sensitivity
# vim speed         // speed

■Persisting the Settings

The files edited above revert on reboot,
so write a rule in a separate file.

# vim /etc/udev/rules.d/10-trackpoint.rules

The content is as follows.
Enter your optimal values for speed and sensitivity.

KERNEL=="serio2",
SUBSYSTEM=="serio",
DRIVERS=="psmouse",
ATTR{sensitivity}:="180",
ATTR{speed}:="60"

The setup is now complete.

(Bonus) Disabling Middle-Click Paste

By default, the ThinkPad’s middle click (the wheel click on a mouse) pastes, which is inconvenient since it can suddenly paste while scrolling, so disable it.

*Added July 2020
If you only want to prevent middle-click paste, you can change it in the settings.
Control Center > Mouse > Enable middlemouse paste

First, get the device name.
Running the following command shows it is “TPPS/2 IBM TrackPoint”.

$ xinput --list | grep TrackPoint
⎜   ↳ TPPS/2 IBM TrackPoint                   	id=14	[slave  pointer  (2)]

Check the device’s button mapping.
Running the following commands shows the middle click is “2” in the button mapping.

$ xinput get-button-map "TPPS/2 IBM TrackPoint"
1 2 3 4 5 6 7 
$ xinput --list "TPPS/2 IBM TrackPoint" | grep "Button labels"
Button labels: "Button Left" "Button Middle" "Button Right" "Button Wheel Up" "Button Wheel Down" "Button Horiz Wheel Left" "Button Horiz Wheel Right"

Disable the middle click.
In the button mapping, replace the number of the button you want to disable with “0”.

xinput set-button-map "TPPS/2 IBM TrackPoint" 1 0 3 4 5 6 7

To make it persistent, just add the command above to ~/.profile.
