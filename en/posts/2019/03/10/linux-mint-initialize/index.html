Initial Setup of Linux Mint

posted: 2020-07-01

LinuxMint

Environment

  • Linux Mint 19.1 “Tessa” - MATE (64-bit)
  • ThinkPad T480

*Added July 2020
I’ve added notes for Linux Mint 20 Ulyana as well.

Japanese Input Setup

Open “Control Center > Input Method” and configure Japanese.

Basically, follow the steps written there, as shown above.

  • Install the language packages (just press the install button here)
  • Set Input Method at the top of the window to Fctix
  • Log out once

*Added July 2020
Linux Mint 20 can use Fctix from the start, so logging out is not necessary.

Open “Control Center > Fctix Configuration” and leave only Mozc as the input method.
Just remove unnecessary input methods by clicking the “-” button.

It’s OK once it looks like the image above.

Language Settings

*Added July 2020
This seems unnecessary on Linux Mint 20.

Open “Control Center > Languages” and configure Japanese.

  • Set “Language” and “Region” to Japan. (They should already be.)
  • Install Japanese in “Language support”.
  • Run “Apply System-Wide” under “System locale”.

If Chrome or other apps aren’t in Japanese after installing them, repeat these steps.

Making Input Mode Switching Mac-like

It’s convenient to enable the IME with the Henkan key and disable it with the Muhenkan key, so let’s set that up.
Open “Control Center > Mozc Settings” and click Edit under “Keymap style”.

A key settings window appears; configure it there.
In the image below, the Hiragana/Katakana key is also assigned to enable the IME.

You can also import/export settings from “Edit” at the bottom right of the key settings screen,
so exporting your preferred settings makes reinstalling easier later.

Making the Hankaku/Zenkaku and CapsLock Keys More Useful

With IME switching configured as above, the Hankaku/Zenkaku key becomes unnecessary, so assign it to Esc.
I also don’t use CapsLock, so assign it to Ctrl.
Open “Control Center > Keyboard”,
and open the options for “Keyboard model” on the Layouts tab.

Here, select “CapsLock is also a Ctrl” for “Caps Lock behavior”,
and “Make Zenkaku Hankaku an additional Esc” for “Japanese keyboard options”.

Changing Software Sources

By default, software is fetched from the US, so change that.
In “Control Center > Software Sources”, clicking Main or Base opens a screen to choose the mirror,
which shows the connection speed to each mirror, so just pick a fast one.

It will usually be a CDN or a mirror in Japan.

Making Nothing Happen When Dragging a Window to the Top of the Screen

By default, dragging a window to the top of the screen automatically maximizes it.
This is inconvenient when you want to arrange multiple windows side by side, so disable it.

Open “Control Center > Windows” and uncheck “Enable window tiling” on the Placement tab.

Installing Various Packages with apt

Basic set (for vim users)

apt install vim git npm

Security software

apt install clamav clamav-daemon

PHP-related (if you use it)

apt install php7.2 composer php7.2-bcmath php7.2-common php7.2-gd php7.2-json php7.2-mbstring php7.2-mysql php7.2-xml php7.2-xmlrpc

*Added July 2020
On Linux Mint 20, php7.4 can be installed by default.

apt install php7.4 composer php7.4-bcmath php7.4-common php7.4-gd php7.4-json php7.4-mbstring php7.4-mysql php7.4-xml php7.4-xmlrpc

Note that apache2 may also be installed automatically when installing PHP,
and it may be configured to start automatically.
So turn off apache2 autostart.

sudo systemctl disable apache2

Shutter (if you use it)

Shutter is a tool that lets you easily insert text, arrows, mosaics, icons, etc. into images.
It’s like Skitch on the Mac. (Those who know, know.)

*Added 2020/7/1
The PPA etc. seemed to have changed, so I updated this.

sudo add-apt-repository ppa:linuxuprising/ppa
apt update
apt install shutter

Downloading from the Web

Download these from the web and install them.

  • Visual Studio Code
  • Station

*Note

Visual Studio Code can also be installed from the Software Manager, etc.,
but for some reason Japanese input doesn’t work with that version, so I get it from the web. (As of 2019/3/10)

Station downloads with an unfamiliar AppImage extension.
You can install it by giving it execute permission and running it from the terminal.

chmod +x browserX-1.39.2-x86_64.AppImage
./browserX-1.39.2-x86_64.AppImage

(If you think you won’t remember what it is later, you can rename it to something like Station.AppImage.)
