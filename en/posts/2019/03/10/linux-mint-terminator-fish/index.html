Installing terminator + fish + fisherman

posted: 2019-03-10

LinuxMint
ubuntu

■Environment

Linux Mint 19.1 “Tessa” - MATE (64-bit)
ubuntu 19.10

*On Ubuntu, prefix the apt commands below with sudo.

Installing terminator

Install terminator.

apt install terminator

(*Added November 2019)
Terminator is nice, but a terminal called Tilix is also good.
See here for details:
Tilix: A Terminal for Linux

Installing fish

Install fish.

apt install fish

After installing, log out once to apply the change.

Also, Terminator’s default window size is a bit awkward, so it’s worth changing.
Changing Terminator’s Default Size

Setting fish as the Default Shell

$ grep fish /etc/shells  
/usr/bin/fish   ←If this isn't shown, add the result of `which fish` to /etc/shells  
$ chsh -s /usr/bin/fish

Installing fisherman

fisherman is a plugin manager for fish.

The install command is listed on fisherman’s GitHub page.
https://github.com/fisherman/fisherman

$ curl -sL https://raw.githubusercontent.com/jorgebucaran/fisher/main/functions/fisher.fish | source && fisher install jorgebucaran/fisher
$ fisher -v
fisher, version 4.4.8

*If fisher -v doesn’t show a version, reopen the terminal. If that still doesn’t work, reboot.

Changing the Theme

You can change fish’s look by changing its theme.
The following page is a good reference for available themes.
https://github.com/oh-my-fish/oh-my-fish/blob/master/docs/Themes.md

I use a theme called “bobthefish,” installed with the following steps.

$ fisher install oh-my-fish/theme-bobthefish     # Depending on the fisher version, use fisher add instead of fisher install

bobthefish requires Powerline fonts, so install those as well.

Added 2020/09/02
In Windows Terminal, fonts installed with the commands below didn’t work well.
Install the Cascadia Code font instead.
https://docs.microsoft.com/en-us/windows/terminal/cascadia-code
Right-click the downloaded ttf file and install it to make it available.

$ git clone https://github.com/powerline/fonts.git  
$ fonts/install.sh  
$ rm -rf fonts

After running the commands above, select the installed font in your terminal app’s settings.
In terminator, right-click in the terminal, open “Preferences,”
and under “Profiles > General > Font,” change the font to one of the “XXX for Powerline” fonts.
If you can’t change the font, uncheck “Use the system fixed width font.”

Personally, I like “Meslo LG M for Powerline.”

Other Plugins

You can install many other plugins with fisherman.

■peco

Install peco.
(On Ubuntu, prefix apt with sudo)

apt install peco
fisher install oh-my-fish/plugin-peco

Added 2026/11/03 Installing peco via apt now causes garbled characters. It’s better to download the file directly. https://zenn.dev/mato/scraps/2b0c423ad9da2c (Japanese)

wget https://github.com/peco/peco/releases/download/v0.5.11/peco_linux_amd64.tar.gz
tar -xzf peco_linux_amd64.tar.gz
sudo mv peco_linux_amd64/peco /usr/local/bin/

After installing, add the following to the fish config file (~/.config/fish/config.fish).
If the fish config file doesn’t exist, create it.

function fish_user_key_bindings
  bind \cr 'peco_select_history (commandline -b)' # peco
end

[Usage]
“Ctrl + R” opens the command history search screen.
You can pick from recent commands, or type a string to narrow the history down to commands containing it.

■ghq

*You need to install golang beforehand.

The original fisherman repository for ghq is yoshiori/fish-peco_select_ghq_repository,
but with it, shells ended up opening multiple times when switching to a git repository,
so I’ve prepared a version that doesn’t open multiple shells in my own repository (mildjester/fish-peco_select_ghq_repository).

*I don’t think yoshiori’s source has a bug; it probably just doesn’t play well with Linux shells(?) now that it’s implemented the way it should be.

go install github.com/x-motemen/ghq@latest
fisher install mildjester/fish-peco_select_ghq_repository

After installing, add the following to the fish config file (~/.config/fish/config.fish).
This assumes you’re adding to the peco settings above.

function fish_user_key_bindings
  bind \cr 'peco_select_history (commandline -b)' # peco
  bind \c] peco_select_ghq_repository # ghq
end

[Usage]
Use the ghq get {git repository URL} command to fetch a new git repository locally.
(Just replace git clone with ghq get)

“Ctrl + ]” lets you select a git repository managed by ghq and move to its directory.
By default, repositories fetched with ghq get are stored under ~/ghq,
but adding the following to ~/.gitconfig lets you store them in any directory you like.

[ghq]
    root = 好きなディレクトリ
