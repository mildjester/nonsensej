Running AWS CodeDeploy from CircleCI

posted: 2019-03-04

CircleCI
AWS

Now that CodeDeploy is configured in the previous article, let’s run it from CircleCI.

The official procedure puts the source code in S3 first and then deploys it to EC2,
but I wanted to avoid S3 if possible, so I referred to this article.
CircleCI+AWS-CodedeployでStaging環境などに自動デプロイさせる (Japanese)

Preparing IAM

Create an IAM user for CircleCI.
First, give it any user name, check “Programmatic access” as the access type, and proceed to the next step.

Attach the existing policy “AWSCodeDeployFullAccess” and proceed to the next step.

Tags aren’t needed, so you can proceed to the next step as is.

Create the user.

Note down the “Access key ID” and “Secret access key” of the created user, and you’re done.
*The secret access key can only be viewed at this point, so be careful not to forget it.

Creating the CircleCI Config File

Create .circleci/config.yml in the repository with the following content.

version: 2
jobs:
  deploy:
    docker:
      - image: cdssnc/aws-cli
    steps:
      - run:
          name: "Set AWS region"
          command: aws configure set region ap-northeast-1
      - run:
          name: "Run AWS CodeDeploy"
          command: aws deploy create-deployment --application-name ${DEPLOY_APPLICATION} --deployment-group-name ${DEPLOY_GROUP} --github-location repository="${DEPLOY_REPOSITORY}",commitId="${CIRCLE_SHA1}"
workflows:
  version: 2
  build_deploy:
    jobs:
      - deploy:
          filters:
            branches:
              only: master

This only kicks off AWS CodeDeploy, so add anything else you need.

The following values are variables because they’ll be set later as CircleCI environment variables.
You can also write them directly in config.yml instead.

Variable Description
DEPLOY_APPLICATION The CodeDeploy application name set up in the previous article
DEPLOY_GROUP The CodeDeploy deployment group set up in the previous article
DEPLOY_REPOSITORY The GitHub repository to deploy (in “username/repository” format)

Once created, push it to the master branch on GitHub.

Configuring CircleCI

First, set the environment variables used in the config.yml above in CircleCI.

For basic CircleCI setup, see the following.

  • Creating an Account and Basic Setup
  • How to Set Environment Variables

Next, set the keys of the AWS IAM user you created.
Open the CircleCI project settings (click the gear button on the project screen)
and go to “PERMISSIONS > AWS Permissions” to set them.

That completes the setup.
When something is merged or pushed to the master branch, CircleCI and CodeDeploy run and deploy automatically.
