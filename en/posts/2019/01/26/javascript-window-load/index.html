window.onload Doesn't Work

posted: 2019-01-26

javascript

Problem

Code written using JavaScript’s window.onload
sometimes doesn’t run.

Cause

window.onload runs only once per page load.
If window.onload is assigned in multiple places,
only one of them is executed.

The same applies even if the code is split across multiple JS files,
so it’s easy to fall into this when window.onload is used somewhere you aren’t aware of.

Solution

Use a different way of writing it.

// Alternative example
window.addEventListener('load', function(){
    console.log('これとか')
})

// If jQuery is available
$(window).on('load', function(){
    console.log('これとか')
})
