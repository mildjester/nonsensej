Migrating Data from WordPress to Pico

posted: 2019-01-17

pico

First, this assumes you have already turned Pico into a blog.
Turning the Pico CMS into a Blog

This is quite a brute-force approach.
Please bear in mind it’s not an elegant method.

Getting Images from WordPress

First, download the full set of image files from WordPress.
Download all files under WordPress’s /wp-content/uploads/
into Pico.

In this example, we create an images directory directly under Pico
and download them there.
The hierarchy will look like pico/images/2019/01/hogehoge.png.

Getting Posts from WordPress

Retrieve post information from the WordPress DB.

Run the following SQL in MySQL Workbench
and export the result as JSON.

SELECT p.ID, p.post_date, u.user_nicename, p.post_title, p.post_content, t.tags
FROM wp_posts p
LEFT JOIN wp_users u ON u.ID = p.post_author
LEFT JOIN (
	SELECT tr.object_id AS post_id, group_concat(t.name) AS tags
	FROM wp_term_relationships tr
	LEFT JOIN wp_term_taxonomy tt ON tt.term_taxonomy_id = tr.term_taxonomy_id
	LEFT JOIN wp_terms t ON t.term_id = tt.term_id
    WHERE tt.taxonomy = 'post_tag'
	GROUP BY tr.object_id
) t ON t.post_id = p.ID
WHERE post_status = 'publish';

Next, generate Markdown post files for Pico from the exported JSON.
Running a PHP script like the following will generate
md files from the retrieved JSON file.

<?php
// Assume the exported JSON is "tmp_insert.json"
$jsonStr = file_get_contents('./tmp_insert.json');
$json = json_decode($jsonStr);

foreach ($json as $post) {
	// Description is cut from the beginning of the post body
	$description = strip_tags($post->post_content);
	$description = str_replace("\n", '', $description);
	$description = mb_substr($description, 0, 64);
	$description .= '...';

	// Fix image file paths
	$body = str_replace('https://your-wp-site.com/wp-content/uploads/', '/images/', $post->post_content);
	// Fix paths to posts
	$body = str_replace('https://your-wp-site.com/?p=', '/posts/', $body);
	// Since it's Markdown, add two spaces at the end of each line
    $body = str_replace(["\r\n", "\r", "\n"], '  '.PHP_EOL, $body);
	
	$content = <<< EOF
---
title: $post->post_title
summary: $description
tags:
    - $post->tags
date: $post->post_date
draft: false
---
$body
EOF;
	file_put_contents($post->ID.'.md', $content);
}

After that, just fine-tune the generated md files as needed.
Also, add the tags you used in WordPress under pico/content/tags.

*Note

Depending on the environment, some HTML tags apparently cause errors when written in md files.
Remove any HTML tags that cause errors or replace them with Markdown syntax.

Redirecting WordPress URLs to Pico URLs

Finally, redirect the old WordPress post URLs to the new URLs and you’re done.
(Not required, but helpful for people who land on old posts from Google search, etc.)

For Apache, it looks like this.
Write it in the configuration file or .htaccess.

<IfModule mod_rewrite.c>
    RewriteEngine On

    # Redirect from the old blog
    RewriteCond %{QUERY_STRING} p=([0-9]*)$
    RewriteRule .* /posts/%1? [R=301,L]
</IfModule>

For Nginx, write the following in the configuration file.

if ($args ~ "p=(.*)") {
    set $articleId $1;
    rewrite ^.*$ /posts/wp/$articleId? permanent;
}

Now, when https://your-site.com/?p=1234 is accessed,
it redirects to https://your-site.com/posts/1234.
If you change the post hierarchy, adjust accordingly.
