I wrote about Linux Mint 18.3 here, but on 19.1 it can now be installed easily with apt, so I’m writing it up again.

Installation Steps

Run the following commands.
(On ubuntu, prefix apt with sudo)

apt install docker.io docker-compose
sudo gpasswd -a $USER docker
service docker restart

After a reboot, the docker and docker-compose commands become available.
(Just logging out sometimes doesn’t properly apply membership in the docker group. A reboot is required.)
